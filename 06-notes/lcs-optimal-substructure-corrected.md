# LCS 最优子结构：修正证明

## 你发现的那个 Bug

之前那个 AI 在证明中使用了条件：

> $z_k \neq x_m$（字符不相等）

然后推断"Z 不包含 $x_m$"。但你的例子 `X = "aba"`, `x_m = 'a'`，`Z = "a"` 中 $z_k = 'a' = x_m$（字符相等），**但 Z 完全可以只匹配 X 的第一个 `'a'`（位置 1），根本没有使用位置 m=3 的 `'a'`。**

所以 `z_k ≠ x_m` 是一个**过强且不精确的条件**。它把"字符值相等"和"位置匹配"两个概念混为一谈了。

---

## 修正：从"字符相等"切换到"位置匹配"

根本的修正只有一处：**把条件从字符层面拉到位置层面。**

设 $X = \langle x_1, \ldots, x_m \rangle$, $Y = \langle y_1, \ldots, y_n \rangle$。

设 $Z = \langle z_1, \ldots, z_k \rangle$ 是 $X$ 和 $Y$ 的任意一个 **LCS**（最长公共子序列）。

由子序列定义，存在严格递增下标：

$$1 \leq i_1 < i_2 < \cdots < i_k \leq m$$

$$1 \leq j_1 < j_2 < \cdots < j_k \leq n$$

使得 $x_{i_t} = y_{j_t} = z_t$ 对所有 $t \in [1, k]$ 成立。

**关键定义：**

> Z 的最后一个匹配位置 $(i_k, j_k)$，是 Z 的第 k 个字符在 X 和 Y 中分别对应的下标。

---

## 定理 1（最优子结构，修正版）

### 情况 1：$x_m = y_n$

**结论：** $i_k = m$, $j_k = n$（即 Z 必须使用 X 和 Y 的最后一个位置），且 $Z[1..k-1]$ 是 $X[1..m-1]$ 和 $Y[1..n-1]$ 的 LCS。

**证明：**

**（a）证明 Z 必须使用 $x_m$ 和 $y_n$：**

假设 $i_k < m$（Z 不使用 X 的最后一个位置）。因为 $x_m = y_n$，我们可以构造 $Z' = Z \parallel x_m$（把 $x_m$ 追加到 Z 末尾）。

- $Z'$ 是 X 的子序列：因为 $i_k < m$，下标序列 $i_1 < \cdots < i_k < m$ 严格递增。
- $Z'$ 是 Y 的子序列：同理，$j_k$ 之后还有位置 n，而 $y_n = x_m$。
- $|Z'| = k + 1 > k$，与 Z 是 LCS 矛盾。

故 $i_k = m$。同理 $j_k = n$。因此 $z_k = x_m = y_n$。

**（b）证明 $Z[1..k-1]$ 是子问题的 LCS（剪切-粘贴）：**

令 $W = Z[1..k-1]$。显然 W 是 $X[1..m-1]$ 和 $Y[1..n-1]$ 的公共子序列，$|W| = k-1$。

假设 W 不是最优的——存在 $W'$ 是 $X[1..m-1]$ 和 $Y[1..n-1]$ 的公共子序列且 $|W'| > k-1$。

构造 $Z'' = W' \parallel x_m$。因为 $W'$ 取自 $X[1..m-1]$ 和 $Y[1..n-1]$，$x_m$ 在末尾，$Z''$ 是 X 和 Y 的公共子序列，且 $|Z''| > k$。与 Z 是 LCS 矛盾。$\square$

---

### 情况 2：$x_m \neq y_n$

这是你一直追问的核心情况。

**前提：** $x_m \neq y_n$。

**断言：** Z 在 X 中的最后一个匹配位置 $i_k$ 和在 Y 中的最后一个匹配位置 $j_k$，**不可能同时等于 m 和 n**。

**证明断言：** 如果 $i_k = m$ 且 $j_k = n$，则第 k 个匹配字符 $z_k = x_m = y_n$，与 $x_m \neq y_n$ 矛盾。$\square$

因此，**至少有一个成立：$i_k < m$ 或 $j_k < n$（或两者都成立）。**

我们分两个子情况（注意：它们**不是互斥的**——当两者都成立时，两个子情况同时适用）：

**子情况 A：$i_k < m$（Z 在 X 中的最后一个匹配位置不是 m）**

这意味着 Z 的所有字符在 X 中的匹配下标全部 $\leq i_k < m$，即 Z 完全来自 $X[1..m-1]$。

因此：
- Z 是 $X[1..m-1]$ 和 Y 的一个公共子序列。
- $c[m][n] = |Z| \leq c[m-1][n]$（子问题的 LCS 长度不会更短）。

**子情况 B：$j_k < n$（Z 在 Y 中的最后一个匹配位置不是 n）**

对称地：
- Z 是 X 和 $Y[1..n-1]$ 的一个公共子序列。
- $c[m][n] = |Z| \leq c[m][n-1]$。

---

**关键结论：**

由于至少一个子情况成立，我们有：

$$c[m][n] \leq \max(c[m-1][n],\; c[m][n-1])$$

另一方面，显然有：

$$c[m][n] \geq c[m-1][n] \quad \text{且} \quad c[m][n] \geq c[m][n-1]$$

（因为 $X[1..m-1]$ 和 Y 的任何公共子序列也是 X 和 Y 的公共子序列。）

所以：

$$c[m][n] = \max(c[m-1][n],\; c[m][n-1])$$

**注意：这个证明完全不依赖"$z_k \neq x_m$"（字符不等）这个条件。** 它只用了"$i_k < m$ 或 $j_k < n$"——这是位置层面的判断，与字符值无关。无论 $z_k$ 的字符值是否等于 $x_m$，只要它匹配的位置不是 m，推理就成立。

---

## 回答你的三个核心问题

### Q1：当 c[i-1][j] == c[i][j-1] 时，max 会不会出错？

不会。上面的证明是**夹逼法**：

$$下界：c[m][n] \geq \max(c[m-1][n], c[m][n-1])$$
$$上界：c[m][n] \leq \max(c[m-1][n], c[m][n-1])$$

当 $c[m-1][n] = c[m][n-1] = V$ 时，上下界都等于 V，所以 $c[m][n]$ 被夹逼在 V 上，必须等于 V。max 取出的就是 V。**这不是"猜"的，是被不等式逼出来的。**

### Q2："两者都不包含"需要作为第三种情况吗？

不需要，因为**它已经被前两种情况联合覆盖了**。

当 $i_k < m$ 且 $j_k < n$ 时（即 Z 同时不使用 $x_m$ 也不使用 $y_n$）：
- 子情况 A 适用（因为 $i_k < m$）$\implies c[m][n] \leq c[m-1][n]$
- 子情况 B 也适用（因为 $j_k < n$）$\implies c[m][n] \leq c[m][n-1]$

两者同时成立，上界比需要的更紧，但这不影响结论——我们只需要 $c[m][n] \leq \max(\cdots)$ 成立，而它在更紧的约束下当然成立。

**它不是"被遗漏"的情况——它是被双重覆盖的情况。**

### Q3：你的例子 X="aba", Y="aef" 怎么解释？

| X | a | b | a |
| Y | a | e | f |

- $m = 3$, $x_3 = 'a'$；$n = 3$, $y_3 = 'f'$。$x_m \neq y_n$。
- LCS Z = "a"，k = 1，$z_1 = 'a'$。

Z 在 X 中有两种匹配方式：
1. **匹配 X[1]**（位置 1）：此时 $i_1 = 1 < 3 = m$，属于子情况 A。Z 是 $X[1..2]$ = "ab" 和 Y = "aef" 的公共子序列。$c[m][n] \leq c[m-1][n] = c[2][3]$。✓
2. **匹配 X[3]**（位置 3）：此时 $i_1 = 3 = m$，但 $j_1 \neq n$（Y 中匹配的是位置 1，不是 3）。属于子情况 B。Z 是 X = "aba" 和 $Y[1..2]$ = "ae" 的 LCS。$c[m][n] \leq c[m][n-1] = c[3][2]$。✓

**无论 Z 选择哪种匹配方式，至少一个子情况成立，不等式 $c[m][n] \leq \max(\cdots)$ 永远为真。**

这就是为什么"字符相等"不碍事——我们看的是**匹配位置**，不是字符值。

---

## 总结：那个 AI 到底错在哪

他用 `z_k ≠ x_m`（字符不等）来判定"Z 不使用 x_m"，这在 X 有重复字符时是**充分但不必要**的条件——即使 `z_k = x_m`（字符相等），Z 也可能匹配的是更早位置出现的相同字符，根本没碰 x_m。

正确的判定条件是：**$i_k < m$**（匹配位置，而非字符值）。切换到位置层面后，所有逻辑豁然开朗，不存在任何歧义。
