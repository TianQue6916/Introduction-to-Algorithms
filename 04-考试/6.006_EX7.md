## Problem 2.（16 points）Exact Edges（精确边数）

### 题干

> Given a weighted, directed graph $G = (V, E, w)$ with positive and negative edge weights, and given a particular vertex $v \in V$, describe an $O(k|E|)$-time algorithm to return the minimum weight of any cycle containing vertex $v$ that also has exactly $k$ edges, or return that no such cycle exists. Recall that a cycle may repeat vertices/edges.

**译**：给定一个带正负边权的有向图 $G = (V, E, w)$（weighted directed graph，加权有向图），以及一个特定顶点 $v \in V$，请描述一个 $O(k|E|)$ 时间的算法，返回**包含顶点 $v$ 且恰好含 $k$ 条边**的任意环（cycle）的最小权重；若不存在这样的环则返回"不存在"。注意：这里的环允许重复经过顶点 / 边。

**核心概念**：
- **Weighted directed graph（加权有向图）**：每条边带一个实数值权重、且边有方向（从一顶点指向另一顶点）的图。
- **Cycle（环 / 回路）**：从某顶点出发、经过若干条边后回到自身的一条路径。本题特别强调 cycle 可重复顶点/边，即它本质是一条**闭游走（closed walk）**，不是通常意义的简单环。

### 解答

**（1）一句话本质（idea）**

这是典型的 **动态规划（Dynamic Programming, DP）** 问题。定义状态为"从 $v$ 出发、走了恰好 $j$ 条边后到达顶点 $u$ 的最小权重"，用按边数逐层递推的方式把问题从"恰好 $k$ 条边"一层层推出来。由于我们只需"回到 $v$"这一目标，最终答案是第 $k$ 层的 $dp[v][k]$（用 $j$ 条边从 $v$ 回到 $v$ 的最小权重）。

**（2）算法（pseudocode 的 LaTeX 版）**

设 $n = |V|$，$m = |E|$。定义二维表：

```math
dp[j][u] = \min\left\{\, \text{weight of a walk from } v \text{ to } u \text{ using exactly } j \text{ edges} \,\right\}
```

（$dp[j][u]$ = 从 $v$ 到 $u$、恰好经过 $j$ 条边的游走的最小权重，若不存在则为 $+\infty$。）

```math
\begin{aligned}
& \textbf{function } \text{ExactEdgeCycle}(G, v, k)\\
& \quad dp[0][v] \leftarrow 0;\quad dp[0][u] \leftarrow +\infty \ \forall u \neq v\\
& \quad \textbf{for } j = 1 \textbf{ to } k \textbf{ do}\\
& \qquad \textbf{for each } u \in V \textbf{ do}\ dp[j][u] \leftarrow +\infty\\
& \qquad \textbf{for each edge } (x, y) \in E \textbf{ do}\\
& \qquad\quad dp[j][y] \leftarrow \min\bigl(dp[j][y],\ dp[j-1][x] + w(x,y)\bigr)\\
& \quad \textbf{if } dp[k][v] < +\infty \textbf{ then return } dp[k][v]\\
& \quad \textbf{else return } \text{``no such cycle''}
\end{aligned}
```

**（3）为什么这样走（每一步的中文解释）**

- **状态设计**：一个"恰好 $k$ 条边、回到 $v$"的环，等价于一条"从 $v$ 出发、经过 $k$ 条边、终点也是 $v$"的游走。游走允许重复顶点/边，正好符合题目"cycle may repeat vertices/edges"的要求，因此无需额外维护"访问过哪些顶点"的集合，状态空间保持很小。

- **转移**：若已知"从 $v$ 出发、$j-1$ 条边到达 $x$"的最小权重 $dp[j-1][x]$，那么再走一条边 $(x,y)$，就能得到一条"$j$ 条边到达 $y$"的游走，权重为 $dp[j-1][x] + w(x,y)$。对每个 $y$ 取所有进入它的边的最小值，即得到 $dp[j][y]$。这本质是对**所有边做一轮松弛（relaxation）**。

- **为什么这等价于 Bellman–Ford（贝尔曼–福特）的单源最短路径松弛**：Bellman–Ford 算法在第 $j$ 轮松弛后，$dist[j][u]$ 正是"从源点出发、经过至多 $j$ 条边的最短路径"。这里我们把"至多"收紧为"恰好"，通过初始化只给 $dp[0][v]=0$ 且强制每层重算来实现。因为允许负边但我们要的是"恰好 $k$ 条边"，不能用普通的 Dijkstra（要求非负边权）。

- **终止与答案**：做完 $k$ 轮后，$dp[k][v]$ 就是"从 $v$ 出发、恰好 $k$ 条边回到 $v$"的最小权重。若它仍为 $+\infty$，说明不存在这样的环。

**（4）正确性证明（循环不变式 / 归纳假设）**

**归纳假设（对 $j$ 归纳）**：在算法完成第 $j$ 轮（外层循环迭代 $j$ 次）之后，对所有 $u \in V$，$dp[j][u]$ 恰好等于"从 $v$ 到 $u$、恰好经过 $j$ 条边的游走的最小权重"（不存在则为 $+\infty$）。

- **基例（$j=0$）**：从 $v$ 到 $v$ 用 0 条边的游走权重为 0；从 $v$ 到任意 $u \neq v$ 用 0 条边不存在游走，故 $dp[0][u]=+\infty$。初始值正确。

- **归纳步**：假设第 $j-1$ 层正确。对任意一条"从 $v$ 到 $y$、恰好 $j$ 条边"的游走 $W$，把它的最后一条边记为 $(x,y)$，则去掉这条边后得到一条"从 $v$ 到 $x$、恰好 $j-1$ 条边"的游走，其权重 $W' \le W - w(x,y)$（若 $W$ 是最优的，则 $W'$ 也是从 $v$ 到 $x$ 用 $j-1$ 条边的最优值 $dp[j-1][x]$，否则替换 $W'$ 可得更优的 $W$，矛盾）。因此 $W = dp[j-1][x]+w(x,y)$。反过来，对每条边 $(x,y)$，$dp[j-1][x]+w(x,y)$ 都是一条合法的"恰好 $j$ 条边到 $y$"的游走权重。算法对每条边取 $\min$，故 $dp[j][y]$ 等于所有这类游走的最小值。归纳成立。

**（5）复杂度分析（写出递推式并解出来）**

外层循环执行 $k$ 次，每次内层遍历所有 $m = |E|$ 条边做常数次操作：

```math
T(k) = k \cdot O(|E|) = O(k|E|)
```

（其中初始化 $dp[0]$ 需 $O(|V|)$，被 $O(k|E|)$ 吸收，因为 $k \ge 1$ 且图一般有 $|E| \ge |V|-1$ 的连通性量级。）因此总时间为 $O(k|E|)$，空间为 $O(k|V|)$（可滚动数组优化到 $O(|V|)$，只需保留上一层）。

## Problem 3.（18 points）Color Cost（颜色代价）

### 题干

> A 3-color labeling of a graph maps each edge to either red, green, or blue. The color cost of a 3-color labeled path is its path weight plus a positive integer $w_c$ every time the path changes color.
> For example, in the graph below (having four vertices $\{a, b, c, d\}$, a blue edge $(a, b)$ with weight $w_1$, a red edge $(b, c)$ with weight $w_2$, and another blue edge $(c, d)$ with weight $w_3$) the path $(a, b, c, d)$ has color cost $w_1 + w_2 + w_3 + 2w_c$, because the path changes color twice.
> Given a 3-color labeling $c : E \to \{\text{red}, \text{green}, \text{blue}\}$ of a connected, weighted, undirected graph $G = (V, E, w)$ containing only positive edge weights, and given two vertices $s, t \in V$, describe an efficient algorithm to return a path from $s$ to $t$ having minimum color cost.
> (By "efficient", we mean that faster correct algorithms will receive more points than slower ones.)

**译**：图的 **3-颜色标注（3-color labeling）** 把每条边映射为红（red）、绿（green）或蓝（blue）之一。一条 3-颜色标注路径的**颜色代价（color cost）** 等于它的路径权重，加上每次路径**改变颜色**时额外付出一个正整数 $w_c$。
例如下图（有四个顶点 $\{a,b,c,d\}$：一条蓝色边 $(a,b)$ 权重 $w_1$，一条红色边 $(b,c)$ 权重 $w_2$，另一条蓝色边 $(c,d)$ 权重 $w_3$），路径 $(a,b,c,d)$ 的颜色代价是 $w_1 + w_2 + w_3 + 2w_c$，因为这条路径改变了两次颜色。

（图：$a \xrightarrow{\text{blue } w_1} b \xrightarrow{\text{red } w_2} c \xrightarrow{\text{blue } w_3} d$）

给定一个连通、加权、**无向（undirected）**、且边权均为正（positive edge weights）的图 $G=(V,E,w)$ 的一个 3-颜色标注 $c:E\to\{\text{red},\text{green},\text{blue}\}$，以及两个顶点 $s,t\in V$，请描述一个**高效**算法，返回从 $s$ 到 $t$ 的**颜色代价最小**的路径。
（"高效"意味着：更快且正确的算法比更慢的得分更高。）

**核心概念**：
- **Undirected graph（无向图）**：边没有方向，$(u,v)$ 与 $(v,u)$ 表示同一条边。
- **Shortest path（最短路径）**：两点之间权重和最小的路径。本题是带额外"换色惩罚"的最短路径变体。

### 解答

**（1）一句话本质（idea）**

颜色只有 3 种，我们把"顶点 + 当前路径最后一条边的颜色"作为新的状态，构造一个**规模放大 3 倍的状态图**，把"换色惩罚"转化为普通边权，然后用 **Dijkstra（迪杰斯特拉）** 算法求最短路径。因为原图边权均为正、$w_c$ 也为正，新图所有边权仍非负，Dijkstra 可用。

**（2）算法（pseudocode 的 LaTeX 版）**

对每个顶点 $u$ 和每种颜色 $c \in \{\text{red},\text{green},\text{blue}\}$，建立状态 $\langle u, c\rangle$，表示"到达顶点 $u$，且路径上最后一条（进入 $u$ 的）边的颜色为 $c$"。源点 $s$ 无前驱边，单独建一个状态 $\langle s, \bot\rangle$（$\bot$ 表示"尚无颜色"）。

构造新图 $G'$，边如下：

```math
\begin{aligned}
&\text{对每条原边 } e=(u,v) \text{，设其颜色为 } c(e) \text{、权重为 } w(e):\\
&\quad \langle u, c'\rangle \to \langle v, c(e)\rangle \ \text{的权重 } = w(e) + [\, c' \neq c(e)\,]\cdot w_c \\
&\quad \langle v, c'\rangle \to \langle u, c(e)\rangle \ \text{的权重 } = w(e) + [\, c' \neq c(e)\,]\cdot w_c
\end{aligned}
```

其中 $[\cdot]$ 是**艾弗森括号（Iverson bracket）**：条件成立取 1，否则取 0。对源点，$\langle s,\bot\rangle$ 出发时"换色"恒不罚（把 $\bot$ 视作与任意颜色都不相等也不相等的特殊值，实际实现里直接让第一跳的 $[\cdot]=0$）。

```math
\begin{aligned}
& \textbf{function } \text{MinColorCost}(G, c, w, s, t, w_c)\\
& \quad \text{在 } G' \text{ 上以 } \langle s,\bot\rangle \text{ 为源点运行 Dijkstra}\\
& \quad \textbf{return } \min\bigl(\ dist(\langle t,\text{red}\rangle),\ dist(\langle t,\text{green}\rangle),\ dist(\langle t,\text{blue}\rangle)\ \bigr)
\end{aligned}
```

**（3）为什么这样走（每一步的中文解释）**

- **为什么引入"最后一条边的颜色"这个状态**：换色惩罚 $w_c$ 只依赖于"当前这条边"与"上一条边"的颜色是否相同。因此，只记录顶点位置不够，必须额外记住"我是沿什么颜色的边到达这个顶点的"，才能判断下一步是否要罚 $w_c$。

- **为什么 3 种颜色恰好够**：颜色总数恒为 3，状态数 $3|V| + 1$，仍是线性规模，不会爆炸。

- **为什么能用 Dijkstra**：新图 $G'$ 的每条边权为 $w(e) + [\cdot]w_c$。$w(e)>0$、$w_c>0$，所以所有边权严格为正，满足 Dijkstra 要求的非负边权条件。若原图允许负权或 $w_c$ 为负，Dijkstra 不再适用，需换成 Bellman–Ford；这里恰好避开了。

- **为什么要取三种颜色的最小值**：到 $t$ 的最优路径的最后一条边可能是红/绿/蓝任意一种，我们无法预知哪种最优，故三种状态都算一遍取最小。

**（4）正确性证明（循环不变式 / 归纳假设）**

**引理（状态图保真）**：原图中一条从 $s$ 到 $t$ 的路径 $P$（颜色代价为 $\text{cost}(P)$）与 $G'$ 中一条从 $\langle s,\bot\rangle$ 到某个 $\langle t,c\rangle$ 的路径一一对应，且两者权重相等。

- **对应关系**：把 $P$ 的顶点序列 $s=u_0,u_1,\dots,u_\ell=t$ 与边颜色序列对应到 $G'$ 中 $\langle u_0,\bot\rangle, \langle u_1,c_1\rangle,\dots,\langle u_\ell,c_\ell\rangle$（其中 $c_i$ 是边 $(u_{i-1},u_i)$ 的颜色）。相邻状态间的 $G'$ 边权 $w(e_i)+[c_{i-1}\neq c_i]w_c$ 恰好把"边权 + 换色惩罚"逐段累加，累加结果正是 $\text{cost}(P) = \sum_i w(e_i) + w_c\cdot\#\{\text{换色次数}\}$。

- **最小性**：既然对应是保权双射，原图最小颜色代价 = $G'$ 中从 $\langle s,\bot\rangle$ 到 $\{t\}\times\{3\text{ 色}\}$ 的最短距离。Dijkstra 的正确性（标准结论，可直接引用：Dijkstra 在非负边权图上返回单源最短路径）保证了该距离被正确算出。

**（5）复杂度分析（写出递推式并解出来）**

$G'$ 有 $N = 3|V|+1$ 个顶点、$M = 2\cdot 3|E| = 6|E|$ 条边（每条无向边拆成两条有向边，再乘以 3 种"前色"状态）。用二叉堆（binary heap）实现的 Dijkstra：

```math
T = O((N + M)\log N) = O\bigl((3|V| + 6|E|)\log(3|V|)\bigr) = O\bigl((|V|+|E|)\log|V|\bigr)
```

（初始化建堆与每次松弛的 $\log N$ 开销合并即得。）空间 $O(|V|+|E|)$。

## Problem 4.（18 points）Orkscapade（兽人历险）

### 题干

> Ranger Raargorn needs to deliver a message from her home town of Tina's Mirth to the town of Riverdell, but the towns of Midgard have been overrun by an army of $k$ Orks. Raargorn has a map of the $n$ towns and $3n$ roads in Midgard, where each road connects a pair of towns in both directions. Scouts have determined the number of Orks $r_i \ge 1$ stationed in each town $i$ (there is at least one Ork stationed in each town). Describe an $O(k)$-time algorithm to find a path from Tina's Mirth to Riverdell on which Raargorn will encounter the fewest total Orks in towns along the way. Partial credit will be awarded for slower correct algorithms, e.g., $O(k \log k)$ or $O(nk)$.

**译**：游侠 Raargorn（Raargorn）需要把一条消息从她的家乡 Tina's Mirth（蒂娜的欢愉）送到 Riverdell（河谷）镇，但 Midgard（中庭）的城镇已被一支 $k$ 个兽人（Orks）的军队占领。Raargorn 有一张 Midgard 的地图，上面有 $n$ 个城镇和 $3n$ 条道路（road），每条道路双向连接一对城镇。侦察兵已确定驻扎在每个城镇 $i$ 的兽人数量 $r_i \ge 1$（每个城镇至少驻扎一个兽人）。请描述一个 $O(k)$ 时间的算法，找到一条从 Tina's Mirth 到 Riverdell 的路径，使 Raargorn 沿途**在城镇中遇到的兽人总数最少**。更慢但正确的算法（如 $O(k\log k)$ 或 $O(nk)$）可得部分分。

**核心概念**：
- **Shortest path（最短路径）**：本题的"权重"是经过城镇的兽人数 $r_i$，且经过的城镇都要算（含起点/终点城镇），等价于给每个**顶点**赋权的（顶点加权）最短路。

### 解答

**（1）一句话本质（idea）**

问题等价于"顶点加权（vertex-weighted）最短路径"。注意到每个城镇至少 1 个兽人，故总兽人数 $k \ge n$（更精确地 $k = \sum_i r_i$）。既然 $k \ge n$，而道路只有 $3n = O(n) = O(k)$ 条，图的规模整体被 $k$ 支配。我们把顶点权转化为边权后，因为兽人数 $r_i \ge 1$ 恒为正，可直接用 **Dijkstra（迪杰斯特拉）** 在线性规模图上求解，总时间 $O(k)$。

**（2）算法（pseudocode 的 LaTeX 版）**

把"经过城镇 $i$ 就付出 $r_i$ 个兽人"转化为边权：对每条道路 $(u,v)$，从 $u$ 到 $v$ 走这条边要付出 $r_v$（进入 $v$ 需"遇到" $v$ 镇的兽人）。加上起点付出 $r_{s}$，终点也要付一次（终点是目标镇，到达即"遇到"）。

```math
\begin{aligned}
& \textbf{function } \text{Orkscapade}(G, r, s, t)\\
& \quad \text{把每条无向道路 } (u,v) \text{ 视为两条有向边 } u\to v \text{（权 } r_v \text{）与 } v\to u \text{（权 } r_u \text{）}\\
& \quad dist \leftarrow \text{Dijkstra}(G, s) \quad \text{（顶点权 } r \text{ 作为边权）}\\
& \quad \textbf{return } dist[t] + r_s
\end{aligned}
```

（等价地，也可直接对"顶点权"做 Dijkstra：初始化 $dist[s]=r_s$，每次松弛 $dist[v] = \min(dist[v], dist[u] + r_v)$。）

**（3）为什么这样走（每一步的中文解释）**

- **为什么是顶点加权最短路**：题目说的是"沿途经过的城镇里兽人总数"，不是"道路上的兽人"。因此每个城镇的 $r_i$ 是挂在**顶点**上的代价。标准技巧是把顶点权下放到"进入该顶点的边"上，转化为普通边权最短路。

- **为什么 $O(k)$ 而不是 $O(n\log n)$ 或 $O(k\log k)$**：这是本题的关键洞察。条件 $r_i \ge 1$ 推出 $k = \sum_i r_i \ge n$；而边数 $m = 3n = O(n) = O(k)$。于是图的顶点数、边数都是 $O(k)$。

- **为什么不用 $O(nk)$ 的朴素 Bellman–Ford 也能满足**：普通 Dijkstra 是 $O((n+m)\log n) = O(k\log k)$；而题目给 $O(k\log k)$ 作为"更慢也能拿部分分"的上界。要拿到满分 $O(k)$，需要**线性时间**的最短路。因为这里边权是正整数（兽人数 $\ge 1$）且最大权、权值范围受控，可以用**基数/桶排序（bucket / radix）优先队列**（Dial's algorithm，迪杰斯特拉的桶优化），或因为边权 $r_i$ 是整数且总和为 $k$，用"桶"按距离值分桶实现 $O(n+m) = O(k)$。

- **为什么 Dijkstra 正确**：所有代价 $r_i \ge 1 > 0$，满足非负权条件（这里其实无负权，比允许负权更安全），Dijkstra 保证得到最短（最少兽人）路径。

**（4）正确性证明（循环不变式 / 归纳假设）**

**引理（顶点权转边权）**：设路径 $P = (s=v_0, v_1,\dots,v_\ell=t)$，其"顶点兽人总数"为 $\sum_{i=0}^{\ell} r_{v_i}$。我们构造的边权图中，这条路径的边权和为 $\sum_{i=1}^{\ell} r_{v_i}$（每条进入边的权）。两者相差固定常数 $r_s$。因此：

```math
\min_P \Bigl(\sum_{i=0}^{\ell} r_{v_i}\Bigr) = r_s + \min_P \Bigl(\sum_{i=1}^{\ell} r_{v_i}\Bigr)
```

两边的极小化是同一个 $P$，故"顶点兽人总数最小"的路径与"边权图中最短路"相同（相差常数 $r_s$ 不影响 argmin）。

**Dijkstra 不变式**：Dijkstra 维护集合 $S$ 中顶点已确定最短距离。其循环不变式（可直接引用标准结论）为：每次从优先队列取出最小 $dist$ 值的顶点 $u$ 时，$dist[u]$ 即 $s$ 到 $u$ 的真正最短距离（因为所有边权非负，任何未确定顶点经 $u$ 绕行都不可能更短）。最终 $dist[t]$ 正确。

**（5）复杂度分析（写出递推式并解出来）**

用桶优化（Dial's algorithm）实现优先队列：距离值范围是 $[0, k]$ 内的整数，维护 $k+1$ 个桶，每轮取最小非空桶的顶点做松弛。

```math
T = O(n + m + k) = O(k)
```

理由：$m = 3n$，$n \le k$（因 $r_i\ge1$），故 $n+m+k = n + 3n + k = O(n+k) = O(k)$。空间 $O(n + k) = O(k)$。

## Problem 5.（18 points）Count Cycles（数环）

### 题干

> A cycle-sparse graph is any weighted directed simple graph $G = (V, E, w)$ for which every vertex $v \in V$ is reachable from at most one simple$^{1}$ negative-weight cycle in $G$. Given a cycle-sparse graph, describe an $O(|V|^3)$-time algorithm to return the number of negative-weight cycles in $G$.
> $^{1}$Recall a cycle is simple if visits any vertex at most once.

**译**：一个 **cycle-sparse（环稀疏）图** 是任意一个加权有向简单图 $G=(V,E,w)$，满足：对每个顶点 $v\in V$，$G$ 中**至多一个**简单负权环可以到达 $v$。给定一个 cycle-sparse 图，请描述一个 $O(|V|^3)$ 时间的算法，返回 $G$ 中**负权环（negative-weight cycle）的个数**。
$^{1}$ 回顾：环是**简单（simple）** 的，如果它访问每个顶点至多一次。

**核心概念**：
- **Negative-weight cycle（负权环）**：总权重严格为负的有向环。它的存在意味着最短路径无定义（可无限次绕环降低权重）。
- **Simple cycle（简单环）**：不重复经过顶点的环。
- **Reachable（可达）**：存在从某个顶点/结构到 $v$ 的有向路径。
- **Floyd–Warshall（弗洛伊德–沃舍尔）**：求全源最短路径的动态规划算法，$O(|V|^3)$。

### 解答

**（1）一句话本质（idea）**

负权环可由 Floyd–Warshall 算法检测：环 $v_i \to v_{i+1} \to \dots \to v_{i-1} \to v_i$ 是负权环当且仅当它有一条边的权重 $w(v_{i-1},v_i)$ 满足 $dist_{i-1}[v_i][v_{i-1}] + w(v_{i-1},v_i) < 0$（即"绕一圈回来更短"）。利用 Floyd–Warshall 的中间结果，我们可以**枚举并识别出所有负权环**；再由 cycle-sparse 的"至多一个环可达每个顶点"这一限制，把识别出的环按"最小顶点"归类去重，最终**计数**。核心技巧是用"环的代表元（最小编号顶点）"来确保每个简单负权环只被数一次。

**（2）算法（pseudocode 的 LaTeX 版）**

```math
\begin{aligned}
& \textbf{function } \text{CountNegativeCycles}(G)\\
& \quad \text{用 Floyd–Warshall 计算 } D[u][v] = \text{最短路径权重（含中间顶点编号 } \le k \text{ 的中间值 } D^{(k)} \text{ 均保留）}\\
& \quad \text{count} \leftarrow 0\\
& \quad \textbf{for } i = 1 \textbf{ to } n \textbf{ do}\\
& \qquad \text{找出所有以 } i \text{ 为最小顶点编号的负权环 } C\\
& \qquad \text{count} \leftarrow \text{count} + (\text{此类环的个数，去重后})\\
& \quad \textbf{return } \text{count}
\end{aligned}
```

具体识别"以 $i$ 为最小顶点"的负权环：枚举环上除 $i$ 外的顶点集合与顺序。更直接的实现是——

```math
\begin{aligned}
& \textbf{function } \text{CountNegativeCycles}(G)\\
& \quad n \leftarrow |V|;\ \text{count} \leftarrow 0\\
& \quad \text{用 Floyd–Warshall 计算 } d^{(k)}_{ij} \text{（允许中间顶点编号 } \le k \text{ 的最短路）}\\
& \quad \textbf{for } i = 1 \textbf{ to } n \textbf{ do}\\
& \qquad \textbf{for each } \text{负权环 } C \text{ 以 } i \text{ 为最小顶点编号}:\\
& \qquad\quad \text{count} \leftarrow \text{count} + 1\\
& \quad \textbf{return } \text{count}
\end{aligned}
```

其中"以 $i$ 为最小顶点编号的负权环"的枚举，利用 Floyd–Warshall 的中间矩阵 $d^{(i-1)}$：环 $C = (v_1,\dots,v_\ell)$ 以 $i$ 为最小编号、且内部顶点编号都 $< i$ 时，可通过检查

```math
d^{(i-1)}[v_j][v_{j-1}] + w(v_{j-1}, v_j) < 0
```

的边来判断该环是否负权（因为 Floyd–Warshall 到第 $i-1$ 步时，$d^{(i-1)}[v_j][v_{j-1}]$ 正是"只用编号 $\le i-1$ 的中间顶点"从 $v_j$ 到 $v_{j-1}$ 的最短路，即绕环其余部分的最短代价）。

**（3）为什么这样走（每一步的中文解释）**

- **为什么用 Floyd–Warshall**：要数**所有**负权环，需要全源信息（任意两顶点间、绕过任意中间顶点的最短路径），这正是 Floyd–Warshall 的产物，且它的时间复杂度正好是题目要求的 $O(|V|^3)$。Bellman–Ford 只能检测"从某源可达的"负环，还要跑 $|V|$ 次才覆盖全源，复杂度同样 $O(|V|\cdot|V||E|)=O(|V|^3)$ 量级，但 Floyd–Warshall 更直观地保留中间矩阵。

- **负权环的判定条件为什么成立**：环 $C=(v_1,\dots,v_\ell)$ 是负权环，等价于"沿环走一圈的权重 $<0$"。把环在某条边 $(v_{j-1},v_j)$ 处断开，则环权重 $= (\text{从 } v_j \text{ 绕到 } v_{j-1} \text{ 的路径权重}) + w(v_{j-1},v_j)$。这条"绕回去的路径"的权重 $\ge d^{(i-1)}[v_j][v_{j-1}]$（最短路径不大于任何具体路径）。因此 $d^{(i-1)}[v_j][v_{j-1}] + w(v_{j-1},v_j) < 0$ 当且仅当存在一个负权环经过这条边（取等路径即环）。

- **为什么需要 cycle-sparse 假设**：这是**正确计数**的关键。若无此假设，一个顶点可能被多个负权环"叠加影响"，导致 Floyd–Warshall 的 $d[u][u]<0$ 无法区分"几个环"。cycle-sparse 保证"每个顶点至多被一个简单负权环可达"，从而每个负权环都有唯一的、可区分的"代表顶点（环内最小编号）"，我们按代表顶点归类就能无遗漏、无重复地数出每个环。

- **为什么要"以 $i$ 为最小顶点编号"这个代表元**：若不规定代表元，同一个环会被它的每个顶点各数一次（重复 $\ell$ 次）。规定"环内编号最小的顶点"作为唯一代表，则每个简单负权环恰好被数一次。

**（4）正确性证明（循环不变式 / 归纳假设）**

**Floyd–Warshall 不变式（标准，可直接引用）**：在第 $k$ 轮后，$d^{(k)}[i][j]$ 等于"从 $i$ 到 $j$、所有中间顶点编号都 $\le k$ 的最短路径权重"。基例 $k=0$ 时只有直接边；归纳步通过 $d^{(k)}[i][j]=\min(d^{(k-1)}[i][j], d^{(k-1)}[i][k]+d^{(k-1)}[k][j])$ 保持。

**计数正确性（归纳 + 代表元唯一性）**：

- **不遗漏**：任意简单负权环 $C$，设其最小顶点编号为 $i$。$C$ 去掉顶点 $i$ 后的其余部分，中间顶点编号都 $< i$（因为 $i$ 是最小），故在 Floyd–Warshall 的第 $i-1$ 轮，$d^{(i-1)}$ 已能表达"绕环其余部分"的最短路。由判定条件，$C$ 会在代表元 $i$ 处被检测到。故每个负权环都被数到。

- **不重复**：每个简单负权环的唯一最小编号顶点 $i$ 是确定且唯一的，算法按 $i$ 归类恰好各数一次；不同环的最小编号顶点可能相同，但它们是**不同的环**（不同顶点集合/顺序），在枚举中被分别识别。cycle-sparse 保证每个顶点至多关联一个环，避免"一个顶点被多个环共享导致的歧义"，确保识别结果与环一一对应。

因此算法返回的 count 恰好等于负权环总数。

**（5）复杂度分析（写出递推式并解出来）**

Floyd–Warshall 的三重循环：

```math
T(n) = \sum_{k=1}^{n}\sum_{i=1}^{n}\sum_{j=1}^{n} O(1) = O(n^3) = O(|V|^3)
```

识别环节：对每个顶点 $i$ 检查若干条边（总 $O(n^2)$ 量级），被 $O(n^3)$ 吸收。总时间 $O(|V|^3)$，空间 $O(|V|^2)$。

## Problem 6.（18 points）Bellham's Fjord（贝尔汉姆峡湾）

### 题干

> Gralexandra Bellham wants to drive her electric car in Norway from location $s$ in Oslo to a scenic Fjord at location $t$. She has a map of the $n$ locations in Norway and the $O(n)$ one-way roads directly connecting pairs of them.
> - Each location $x$ is marked with its (positive or negative) integer height $h(x)$ above sea-level.
> - Her car has regenerative braking allowing it to generate energy while going downhill. Each road from location $x$ to $y$ is marked with the integer energy $J(x, y)$ that the electric car will either spend (positive) or generate (negative) while driving along it.
> - By the laws of physics, $J(x, y)$ is always strictly greater than the difference in potential energy between locations $x$ and $y$, i.e., $J(x,y) > m \cdot g \cdot (h(y) - h(x))$, where $m$ and $g$ are the mass of the car and the acceleration due to gravity respectively.
> Her car battery has very large energy capacity $b > 2nk$ where $k$ is the maximum $|J(x,y)|$ of any road. Assuming she departs $s$ at half capacity, $\lfloor b/2 \rfloor$, describe an $O(n \log n)$-time algorithm to determine the maximum amount of energy Bellham can have in her battery upon reaching $t$. Partial credit will be awarded for slower correct algorithms, e.g., $O(n^2)$.

**译**：Gralexandra Bellham（格拉丽珊德拉·贝尔汉姆）想开她的电动汽车在挪威从奥斯陆（Oslo）的 $s$ 地前往一处风景峡湾（Fjord）$t$ 地。她有一张地图，包含挪威的 $n$ 个地点，以及 $O(n)$ 条**直接连接**这些地点的**单向道路（one-way road）**。
- 每个地点 $x$ 标有其（可为正或负的）整数海拔高度 $h(x)$（相对海平面）。
- 她的车有**再生制动（regenerative braking）**，下坡时可产生能量。每条从 $x$ 到 $y$ 的道路标有一个整数能量 $J(x,y)$，表示沿此路行驶时电动车会**消耗（正）或产生（负）**的能量。
- 根据物理定律，$J(x,y)$ 恒严格大于 $x$、$y$ 两地的势能差，即 $J(x,y) > m\cdot g\cdot(h(y)-h(x))$，其中 $m$、$g$ 分别是车的质量与重力加速度。
她的车电池容量非常大，$b > 2nk$，其中 $k$ 是任意道路 $|J(x,y)|$ 的最大值。假设她以半满电量 $\lfloor b/2\rfloor$ 从 $s$ 出发，请描述一个 $O(n\log n)$ 时间的算法，求 Bellham 到达 $t$ 时电池里**最多**能有多少能量。更慢但正确的算法（如 $O(n^2)$）可得部分分。

**核心概念**：
- **Directed acyclic graph（DAG，有向无环图）**：不含环的有向图。本题的物理约束保证图是 DAG（见下）。
- **Longest path（最长路径）**：权重和最大的路径。在 DAG 上可用拓扑排序 + DP 在线性（这里 $O(n\log n)$ 由排序决定）时间内求解。

### 解答

**（1）一句话本质（idea）**

先证明**图是无环的（DAG）**：由物理条件 $J(x,y) > m g (h(y)-h(x))$ 推出，沿任意有向环走一圈的净能量 $> 0$（因为高度变化相消，环上高度差之和为 0）。既然绕任何环都要净消耗能量（$>0$），最优路径永远不会绕环，故问题化为 **DAG 上的最长路径（maximum-weight path）**，用拓扑排序 + 动态规划求解，$O(n\log n)$ 由排序主导。

**（2）为什么图是 DAG（关键论证）**

对任意有向环 $C = x_1 \to x_2 \to \dots \to x_\ell \to x_1$，其总能量消耗为：

```math
\sum_{i=1}^{\ell} J(x_i, x_{i+1}) > m g \sum_{i=1}^{\ell} \bigl(h(x_{i+1}) - h(x_i)\bigr) = m g \cdot 0 = 0
```

其中中间等号是因为 $\sum_i (h(x_{i+1})-h(x_i)) = h(x_{\ell+1}) - h(x_1) = 0$（$x_{\ell+1}=x_1$，首尾相接，高度差互相抵消）。

因此**任何有向环的总能量消耗都严格大于 0**，即走一圈净消耗能量。既然电池能量有限且目标是**最大化**到达 $t$ 时的能量，任何最优解都不会包含一个"净消耗"的子环——把环去掉，能量反而更多。所以最优路径必为**简单路径**，图等价于 DAG（我们只需在 DAG 上做最长路；即便原图有环，也不会被最优解采用）。

**（3）算法（pseudocode 的 LaTeX 版）**

```math
\begin{aligned}
& \textbf{function } \text{MaxEnergy}(G, J, s, t, b)\\
& \quad \text{对顶点做拓扑排序（topological sort）}\\
& \quad E[s] \leftarrow \lfloor b/2 \rfloor;\quad E[u] \leftarrow -\infty\ \forall u \neq s\\
& \quad \textbf{for each } u \text{ in 拓扑序 } \textbf{ do}\\
& \qquad \textbf{for each } \text{出边 } (u,v) \textbf{ do}\\
& \qquad\quad E[v] \leftarrow \max\bigl(E[v],\ E[u] - J(u,v)\bigr)\\
& \quad \textbf{return } E[t]
\end{aligned}
```

（这里 $E[u]$ 表示"到达 $u$ 时电池的最多能量"；沿边 $u\to v$ 行驶消耗 $J(u,v)$ 能量，故 $E[u] - J(u,v)$ 为到达 $v$ 时的能量；若 $J(u,v)$ 为负，则是"下坡产生能量"，$E[u]-J(u,v) > E[u]$，即能量增加，符合再生制动的物理意义。）

**（4）为什么这样走（每一步的中文解释）**

- **为什么化为最长路**：目标是最大化 $t$ 处的电量。电池从 $s$ 的半满出发，每走一条边 $u\to v$ 电量变为 $E - J(u,v)$。因此沿一条路径 $P$，到达 $t$ 的电量为：

```math
E[t] = \lfloor b/2 \rfloor - \sum_{e \in P} J(e) = \lfloor b/2 \rfloor + \Bigl(-\sum_{e \in P} J(e)\Bigr)
```

最大化 $E[t]$ 等价于最大化 $-\sum_e J(e)$，即最小化 $\sum_e J(e)$（总消耗），也就是求一条**"能量消耗最小的路径"**；反过来也可表述为"权重为 $-J$ 的最长路径"。因为 $-J$ 可为正可为负，但图是 DAG，最长路在 DAG 上可线性求解。

- **为什么不用 Dijkstra（负权存在）**：$-J(u,v)$ 可能是负的（上坡消耗能量），故边权有正有负，Dijkstra 不适用。而 DAG 上拓扑序 DP 天然支持任意符号的边权，这是更合适的工具。

- **为什么 $b > 2nk$ 保证不会"没电抛锚"**：从 $s$ 到 $t$ 的任意简单路径最多 $n-1$ 条边，每条边能量变化幅度 $\le k$，故整条路径能量最多偏离 $\lfloor b/2\rfloor$ 不超过 $nk < b/2$。因此半满出发足以覆盖任何简单路径的净消耗，不会中途耗尽，也就无需在 DP 里额外约束"电量非负"。（这是题目设 $b>2nk$ 的用意：让"电量上限"这一约束在最优解下不会触顶，可以放心做无约束最长路。）

- **为什么拓扑排序可行**：图是 DAG（第 2 步已证），拓扑序保证处理 $u$ 时，所有能到达 $u$ 的前驱都已被处理，$E[u]$ 已是最终最优值。

**（5）正确性证明（循环不变式 / 归纳假设）**

**归纳假设（按拓扑序）**：当处理到顶点 $u$ 时，$E[u]$ 已等于"从 $s$ 出发、沿任意路径到达 $u$ 时电池的最大能量"。

- **基例**：$s$ 是拓扑序首个（或 $s$ 之前的顶点 $E=-\infty$ 且不可达 $t$ 无需考虑），$E[s]=\lfloor b/2\rfloor$ 正确。

- **归纳步**：任意到达 $u$ 的路径 $P$，设其倒数第二条边为 $(x,u)$。则 $P$ 的前缀是到达 $x$ 的路径，其最大能量为 $E[x]$（由归纳假设，因 $x$ 在拓扑序中先于 $u$，已被处理）。故经 $(x,u)$ 到达 $u$ 的最大能量为 $E[x]-J(x,u)$。算法对 $u$ 的所有入边取 $\max$，得到 $E[u]$ 的正确值。归纳成立。

**（6）复杂度分析（写出递推式并解出来）**

拓扑排序（用 DFS 或 Kahn 算法）$O(n+m)$；DP 每条边处理一次 $O(n+m)$；边数 $m = O(n)$（题目给定）。故：

```math
T = O(n + m) = O(n) \quad \text{（若用计数排序 / 线性拓扑）}
```

但题目要求并给出 $O(n\log n)$：若拓扑排序用比较排序（如基于键的排序）实现则为 $O(n\log n)$。两种都正确，$O(n\log n)$ 是更稳妥的上界：

```math
T = O(n \log n)
```

空间 $O(n)$。
