**Problem 2. [40 points] Decision Problems（判定问题）（10 部分）**

对于下列每个问题，圈选 **T（True，真）** 或 **F（False，假）**，并在方框内简要说明理由（一句话或一幅图即可）。每题 4 分：答案 2 分，理由 2 分。若答案与理由都留空，可得 1 分。

**(a) T F** 判断 $2^{2n} \in \Theta(2^n)$。

**解答：** False（假）。该命题等价于断言 $k^2 \in O(k)$，其中 $k = 2^n$。指数中的常数在渐近意义下是有影响的！

**(b) T F** 若 $T(n) = \tfrac{4}{9}\,T\!\left(\tfrac{3}{2}n\right) + n^2$，且 $T(1) = \Theta(1)$，则 $T(n) = O(n^2)$。

**解答：** False（假）。这是 Master Theorem（主定理）Case II 的一个例子：取

```math
a = \frac{4}{9}, \quad b = \frac{3}{2}, \quad f(n) = n^2,
```

且有

```math
n^{\log_b a} = n^{\log_{3/2}(4/9)} = n^{2} = \Theta(n^2 \log^0 n).
```

因此该递推式解为 $T(n) = \Theta(n^2 \log n)$，它不是 $O(n^2)$。

> 注：原文公式碎片中 `log3/2 9/4`、`n = Θ(n log0 n)` 等即上述重建后的指数关系，由主定理唯一确定。验证（主定理标准形 $T(n)=aT(n/b)+f(n)$）：原式为 $T(n)=\tfrac49 T(\tfrac32 n)+n^2$，即 $n/b=\tfrac32 n$，故 $b=\tfrac23$；又 $a=\tfrac49$。因 $(\tfrac23)^2=\tfrac49$，所以 $\log_b a=\log_{2/3}\tfrac49=2$，于是 $n^{\log_b a}=n^2$。而 $f(n)=n^2=\Theta(n^2\log^0 n)$，正好落在 Case II，故 $T(n)=\Theta(n^2\log n)$，并非 $O(n^2)$。

**(c) T F** 在一个初始为空的数据结构上，执行 $n$ 次 $O(1)$ 的 amortized（摊还）操作，最坏情况总耗时 $O(n)$。

**解答：** True（真）。这正是 amortization（摊还分析）的定义。

## 第 4 页

**(d) T F** 给定一个包含 $n$ 个可比较（comparable）元素的数组 $A$，用 merge sort（归并排序）对它排序。在排序过程中，$A$ 中的每个元素与 $A$ 中 $O(\log n)$ 个其他元素作过比较。

**解答：** False（假）。反例：在最后一次 merge（归并）步骤中，两个已排好序的半边数组，各自大小为 $\Theta(n)$，其中一个数组里的某个元素可能会与另一个列表中的**全部**元素作比较。

**(e) T F** 给定一个存储 $n$ 个具有可比较 key（键）元素的 binary min-heap（二叉最小堆），可以只用 $O(n)$ 次比较就构建出一个包含同样元素的 Set AVL Tree（集合型 AVL 树）。

**解答：** False（假）。若存在这样的算法 $A$，我们就能在 $O(n)$ 时间内对一个可比较元素数组排序，这与比较排序（comparison sort）的 $\Omega(n \log n)$ 下界相矛盾。具体地：我们可以先用 $O(n)$ 次比较从数组构建一个 binary min-heap，再用 $A$ 以 $O(n)$ 次比较构建一个 Set AVL Tree，最后返回它的遍历顺序（traversal order），即为排序结果。

**(f) T F** 给定一个有向图 $G = (V, E)$，从顶点 $s \in V$ 出发运行 breadth-first search（广度优先搜索，BFS）。在处理某个顶点 $u$ 时，若某个 $v \in \mathrm{Adj}^+(u)$（$u$ 的出邻接点集）已被处理过，则 $G$ 含有一个 directed cycle（有向环）。

**解答：** False（假）。BFS 不能用于检测有向环。反例：$V = \{s, a, b, t\}$，$E = \{(s, t), (s, a), (a, b), (b, t)\}$。从 $s$ 运行 BFS，先处理第 0 层的 $\{s\}$，再处理第 1 层的 $\{a, t\}$，再处理第 2 层的 $\{b\}$。处理顶点 $b$ 时，顶点 $t \in \mathrm{Adj}^+(b)$ 已被处理过，然而 $G$ 是一个 DAG（有向无环图，directed acyclic graph——即不含任何有向环的有向图）。

**(g) T F** 在带权图 $G = (V, E, w)$ 上从顶点 $s \in V$ 运行 Bellman-Ford 算法。若存在一个 witness（见证顶点）$v \in V$，即 $\delta_{|V|}(s, v) < \delta_{|V|-1}(s, v)$，则 $v$ 在 $G$ 的一个 negative-weight cycle（负权环）上。

**解答：** False（假）。witness 只保证它能从某个负权环**到达**；它本身未必在负权环上。

**(h) T F** 当应用于 weighted complete graphs（带权完全图，即每个顶点到其他每个顶点都有边的图）时，Floyd–Warshall 与 Johnson 算法求解 all-pairs shortest paths（全源最短路径）具有相同的渐近运行时间。

**解答：** True（真）。完全图是 dense（稠密）的，即 $|E| = \Theta(|V|^2)$，所以 Johnson 算法运行时间为 $O(|V|^2 \log |V| + |V||E|) = O(|V|^3)$，与 Floyd–Warshall 相同。

**(i) T F** 若存在一个多项式时间算法求解 0-1 Knapsack（0-1 背包），则也存在一个多项式时间算法求解 Subset Sum（子集和）。

**解答：** True（真）。Subset Sum 是 0-1 Knapsack 的特殊情形。具体地，可以在线性时间内把一个 Subset Sum 实例 $(A, T)$ 转换成等价的 0-1 Knapsack 实例：对 $A$ 中每个整数 $a_i$ 设置一个物品 $i$，其 size（体积）$s_i = a_i$、value（价值）$v_i = a_i$，背包容量为 $T$；然后用 0-1 Knapsack 的多项式时间算法求解该实例。

**(j) T F** 假设一个 decision problem（判定问题）$A$ 有一个 pseudopolynomial-time（伪多项式时间）算法。若 $P \ne NP$，则 $A$ 不能在多项式时间内求解。

**解答：** False（假）。一个问题可以**同时**拥有伪多项式时间算法和多项式时间算法。事实上，任何多项式时间算法同时也是伪多项式时间算法！

## Problem 3. [24 points] Sorting Sorts（各种排序）

**题意**：本题考察在**特殊结构数组**上，如何借助对输入性质的分析，把排序时间从通用的 $O(n \log n)$ 压到线性 $O(n)$。核心是「先识别数组满足的结构条件，再拆分成可各自快速处理的子问题，最后用 merge 合并」。

---

### (a) [12 points]

**题目（原文）**：

An integer array A is k-even-mixed if there are exactly k even integers in A, and the odd integers in A appear in sorted order. Given a k-even-mixed array A containing n distinct integers for $k = \lfloor n/\lg n \rfloor$, describe an O(n)-time algorithm to sort A.

**题目（译文）**：

一个整数数组 $A$ 称为 **k-even-mixed**（k 偶混合的），如果 $A$ 中**恰好有 $k$ 个偶数**，并且 $A$ 中的**奇数已经按升序排列**。给定一个 k-even-mixed 数组 $A$，其中包含 $n$ 个互不相同的整数，且 $k = \lfloor n/\lg n \rfloor$，请描述一个 $O(n)$ 时间算法来排序 $A$。

> 补充说明（判据解析）：这里的「k-even-mixed」不是通用算法教材里的标准术语，而是本题自定义的定义，判定标准就是两点——（1）偶数个数恰为 $k$；（2）奇数部分已有序。抓住这两点即可解题。

**答案**：

**本质（idea）**：奇数本来就有序，无需再排；真正的「脏活」只剩对 $k$ 个偶数排序。而 $k = \lfloor n/\lg n \rfloor$ 远小于 $n$，所以花 $O(k \log k)$ 时间排偶数，再线性合并，总时间就是 $O(n)$。

**算法（pseudocode）**：

```math
\begin{aligned}
&\text{Algorithm SortKMixed}(A, n):\\
&\quad E \leftarrow \text{空数组}\\
&\quad O \leftarrow \text{空数组}\\
&\quad \text{for } x \text{ in } A:\\
&\qquad \text{if } x \text{ is even: } E.\text{append}(x)\\
&\qquad \text{else: } O.\text{append}(x)\\
&\quad \text{MergeSort}(E)\\
&\quad A \leftarrow \text{Merge}(E, O)
\end{aligned}
```

**复杂度分析（含递推式）**：

- 第一步扫描 $A$，把偶数和奇数分别收集到 $E$ 与 $O$，其中 $|E| = k$、$|O| = n - k$，扫描耗时 $O(n)$。
- 因为奇数在 $A$ 中原本就有序，所以收集进 $O$ 后 $O$ 仍然有序，**无需排序**。
- 对偶数数组 $E$ 用归并排序 Merge Sort，其递推式为 $T(k) = 2\,T(k/2) + O(k)$，由主定理（$a = b = 2$，$f(n) = O(n)$，$n^{\log_b a} = n$，属情况二）得 $T(k) = O(k \log k)$。
- 代入 $k = \lfloor n/\lg n \rfloor$：

```math
O(k \log k) = O\!\left(\frac{n}{\lg n} \cdot \log\frac{n}{\lg n}\right)
= O\!\left(\frac{n}{\lg n}(\lg n - \lg\lg n)\right)
= O\!\left(n - \frac{n \lg\lg n}{\lg n}\right)
= O(n)
```

  **为什么这一步放缩成立**：$\log\frac{n}{\lg n} = \lg n - \lg\lg n < \lg n$，因此 $k \log k < k \lg n = \frac{n}{\lg n} \cdot \lg n = n$，所以整个量被 $n$ 上界压住，是 $O(n)$ 而非 $O(n \log n)$。
- 最后用归并排序的 merge 步骤，把有序的 $E$ 和有序的 $O$ 合并回 $A$，耗时 $O(n)$。

综上，总时间 $O(n) + O(k \log k) + O(n) = O(n)$。

**正确性（循环不变式）**：

- 不变式：在「先分别收集」阶段结束时，$O$ 保存了 $A$ 中全部奇数且保持其在 $A$ 中的原始相对顺序（因为奇数组自身有序，扫描顺序即有序顺序）；$E$ 保存了全部偶数。
- 归纳假设：MergeSort 对 $E$ 排序正确（归并排序的标准归纳可证）。合并阶段，Merge 的两个输入数组 $E$、$O$ 各自有序，故 Merge 的标准不变式（输出前缀是两输入最小元素的递增序列）保证最终 $A$ 整体有序。
- 终止：所有元素恰好被处理一次（奇数进 $O$、偶数进 $E$），合并后 $A$ 长度仍为 $n$，元素无遗漏、无重复，故排序正确。

**Common Mistakes（常见错误）**：

- 使用 insertion sort（插入排序）——即使奇数有序，直接插入排序仍可能 $O(n^2)$。
- 拆成非常数个子数组再试图合并——拆太碎反而无法保证线性时间。
- 用 binary search（二分查找）把偶数插入奇数，但伴随线性移位——查找快、移位仍是 $O(n)$ 每次，累计 $O(nk)$。
- 使用 radix sort（基数排序）或 counting sort（计数排序）——数值范围可能太大，不满足这两种排序的前提。

### (b) [12 points]

**题目（原文）**：

Let A be an array of n pairs of positive integers $(x_i, y_i)$ with $x_i, y_i < n^2$ for all $i \in \{0, \ldots, n-1\}$. The power of pair $(x, y)$ is the integer $x + ny$. Describe an O(n)-time algorithm to sort the pairs in A increasing by power.

**题目（译文）**：

设 $A$ 是一个由 $n$ 个正整数二元组 $(x_i, y_i)$ 构成的数组，且对所有 $i \in \{0, \ldots, n-1\}$ 都有 $x_i, y_i < n^2$。二元组 $(x, y)$ 的 **power**（势）定义为整数 $x + ny$。请描述一个 $O(n)$ 时间算法，把 $A$ 中的二元组按 power **递增**排序。

> 补充说明（判据解析）：power $= x + ny$ 中，$y$ 每增 1，power 就增加 $n$；而 $x < n^2$，当 $y$ 增大后 $x$ 的变化无法跨过 $y$ 的档位。这正是可以「按元组分量拆开排」的关键。

**答案**：

**本质（idea）**：因为 $x$ 和 $y$ 都被 $O(n^2)$ 上界约束，所以可以用 radix sort（基数排序）在 $O(n)$ 内做稳定排序；而 power 对 $y$ 的敏感度远高于 $x$，所以对 $y \ge 2$ 的部分用「先按 $x$ 排、再按 $y$ 排」的 tuple sort 即可得到按 power 排序的结果。唯一要单独处理的边角是 $y = 1$。

**算法（pseudocode）**：

```math
\begin{aligned}
&\text{Algorithm SortByPower}(A):\\
&\quad A_1 \leftarrow \{ (x,1) \in A \}\\
&\quad A_2 \leftarrow \{ (x,y) \in A \mid y \ge 2 \}\\
&\quad \text{RadixSort}(A_1, \text{key}=x+n)\\
&\quad \text{RadixSort}(A_2, \text{key}=x)\quad\text{(stable)}\\
&\quad \text{RadixSort}(A_2, \text{key}=y)\quad\text{(stable)}\\
&\quad A \leftarrow \text{Merge}(A_1, A_2)
\end{aligned}
```

**复杂度分析（含递推式/判据）**：

- 扫描 $A$ 把 $y = 1$ 的二元组放进 $A_1$，其余放进 $A_2$，耗时 $O(n)$。
- 对 $A_1$：每个元素的 power 为 $x + n$，而 $x < n^2$，故 power $< n^2 + n = O(n^2)$，值域被 $O(n^2)$ 约束，用 radix sort 排序耗 $O(n)$。
  - **为什么 radix sort 能 $O(n)$**：基数排序按位处理，位数为 $O(\log_{base}(n^2)) = O(\log_{base} n)$，取 $base = n$ 时只需常数轮，每轮稳定桶排 $O(n)$，总 $O(n)$。
- 对 $A_2$：用 tuple sort（元组排序），即先按 $x$ 稳定排序、再按 $y$ 稳定排序。
  - **为什么「先 x 后 y」就等价于按 power 排**：对 $y \ge 2$ 的任意两个二元组，power $= x + ny$，$y$ 每差 1 就是 $n$ 的差距，而 $|x_1 - x_2| < n^2$ 只有在 $y$ 相等时才可能影响次序。因此先按次要分量 $x$ 稳定排序、再按主分量 $y$ 稳定排序，最终就得到「先比 $y$、$y$ 相同再比 $x$」的次序，恰为 power 递增序。两次排序各自用 radix sort（$x, y < n^2$）都耗 $O(n)$。
- 最后用归并排序的 merge 步骤把有序的 $A_1$、$A_2$ 合并回 $A$，耗 $O(n)$。

总时间 $O(n)$。

**正确性（归纳/不变式）**：

- $A_1$ 内：power $= x + n$ 与 $x$ 只差常数 $n$，按 $x$ 升序即按 power 升序，排序正确。
- $A_2$ 内：tuple sort 的稳定排序保证了「主分量 $y$ 升序、次分量 $x$ 升序」，即 power 升序。
- 合并阶段：需证明 $A_1$ 与 $A_2$ 之间无需交错比较即可直接按序归并。因为 $A_1$ 全为 $y=1$，$A_2$ 全为 $y\ge 2$，$A_2$ 中最小 power 至少为 $0 + 2n = 2n$，而 $A_1$ 中最大 power 为 $(n^2-1) + n = n^2 + n - 1$，二者范围可能重叠，因此**必须用 merge 而非简单 concat**，merge 的不变式保证整体有序。
  - 这正是常见错误「Concatenating instead of merging two overlapping lists」的症结：两段 power 区间有重叠，不能直接拼接。

**Common Mistakes（常见错误）**：

- 没处理 $y = 1$ 的边角（此时 $x$ 可能比 $n$ 大或小，power 比较不能简单套 $y \ge 2$ 的档位规则）。
- 显式计算 power（$x + ny$ 可能达到指数级大小，溢出且破坏线性界）。
- 把两个区间有重叠的列表直接 concatenate（拼接）而不是 merge（归并）。

## Problem 4. [14 points] Pythagorean Quad（毕达哥拉斯四元组）

**题意**：给定数组，判断是否存在四个整数构成满足 $d = \sqrt{a^2 + b^2 + c^2}$ 的「毕达哥拉斯四元组」。关键是把一个看起来 $O(n^3)$ 甚至 $O(n^4)$ 的四数匹配问题，通过移项拆成两个「两两之和」的哈希匹配，压到 $O(n^2)$。

**题目（原文）**：

A Pythagorean Quad consists of four integers $(a, b, c, d)$ such that $d = \sqrt{a^2 + b^2 + c^2}$. Given an array A containing n distinct positive integers, describe an O(n²)-time algorithm to determine whether four integers from A form a Pythagorean Quad, where integers from A may appear more than once in the Quad. State whether your running time is worst-case, expected, and/or amortized.

**题目（译文）**：

一个 **Pythagorean Quad**（毕达哥拉斯四元组）由四个整数 $(a, b, c, d)$ 组成，满足

```math
d = \sqrt{a^2 + b^2 + c^2}
```

给定一个包含 $n$ 个**互不相同**正整数的数组 $A$，请描述一个 $O(n^2)$ 时间算法，判断能否从 $A$ 中取出四个整数构成一个 Pythagorean Quad，其中 $A$ 中的整数可以在 Quad 中**重复出现**。请说明你的运行时间是 worst-case（最坏）、expected（期望）还是 amortized（摊还）。

> 补充说明（判据解析）：这里要求的是「判断是否存在」，不是「求出所有四元组」，所以只需要一次匹配成功即可返回；这也是能压到 $O(n^2)$ 的前提。

**答案**：

**本质（idea）**：把等式变形为 $a^2 + b^2 = d^2 - c^2$。于是问题变为：找一对 $(a,b)$ 和一对 $(c,d)$，使左边两平方和等于右边两平方差。用哈希表存「所有 $(a,b)$ 对的 $a^2+b^2$」，再枚举「所有 $(c,d)$ 对」去查 $d^2-c^2$，命中即存在。两对各自都是 $n^2$ 个，故总 $O(n^2)$。

**算法（pseudocode）**：

```math
\begin{aligned}
&\text{Algorithm PythagoreanQuad}(A):\\
&\quad P \leftarrow \{ (a,b) \mid a,b \in A \}\quad \text{(n 个元素、可重复，共 } n^2 \text{ 个有序对)}\\
&\quad H \leftarrow \text{空哈希表}\\
&\quad \text{for } (a,b) \in P:\\
&\qquad H.\text{insert}(a^2 + b^2)\\
&\quad \text{for } (c,d) \in P:\\
&\qquad v \leftarrow d^2 - c^2\\
&\qquad \text{if } v \in H: \text{return TRUE}\\
&\quad \text{return FALSE}
\end{aligned}
```

**复杂度分析**：

- 构建 $P$：$A$ 有 $n$ 个元素，有序对（允许 $a=b$ 及交叉重复）共 $n^2$ 个。
- 第一阶段：对每个 $(a,b)$ 计算 $a^2+b^2$ 并插入哈希表。每个值计算是常数时间（整数平方与加法），$n^2$ 次插入是 **expected $O(n^2)$**（哈希表的平均插入 $O(1)$）。
- 第二阶段：对每个 $(c,d)$ 计算 $d^2-c^2$ 并在 $H$ 中查找，$n^2$ 次查找是 **expected $O(n^2)$**。

**运行时间类型说明**：总时间 $O(n^2)$ 是 **expected（期望）** 的——因为哈希表的插入与查找在最坏情况下可能退化到 $O(n)$ 每次（例如大量碰撞），但期望意义下是 $O(1)$ 每次，故整体是 expected $O(n^2)$。计算平方与移项本身是 worst-case $O(n^2)$（纯整数运算无随机性）。

**正确性（归纳/充要性论证）**：

- **充分性**：若返回 TRUE，则存在 $(a,b)$ 与 $(c,d)$ 使 $a^2+b^2 = d^2-c^2$，即 $a^2+b^2+c^2 = d^2$，又因 $a,b,c,d$ 均为正整数，故 $d = \sqrt{a^2+b^2+c^2}$，构成 Pythagorean Quad。
- **必要性**：若存在 Pythagorean Quad $(a,b,c,d)$，则 $a^2+b^2 = d^2-c^2$，故该值 $a^2+b^2$ 一定在哈希表 $H$ 中，枚举到 $(c,d)$ 时必然命中并返回 TRUE。
- 循环不变式：第一阶段结束后，$H$ 恰好包含所有 $P$ 中对的 $a^2+b^2$ 值；第二阶段每轮检查完 $(c,d)$ 后，要么已命中返回，要么「前若干对都不匹配」这一性质保持成立。枚举覆盖所有 $n^2$ 个 $(c,d)$，故不遗漏。

**Common Mistakes（常见错误）**：

- 计算涉及对数或平方根的非整数——应保持整数运算（移项后只在 $d$ 处涉及根号，但只需判存在，不必显式开根）。
- 把 worst-case 说成 amortized——本题是 expected，不是摊还。
- 试图写错误的 dynamic program（动态规划）——此问题本质是哈希匹配，不是 DP 结构。
- 试图写错误的 four-finger algorithm（四指针算法）——指针法无法正确处理平方项的非单调组合。

## Problem 5. [20 points] Animal Counting（动物计数）

**题意**：这是一个数据结构设计题，要求用 AVL 树 + 哈希表 + 双向链表组合，支持「加入观测、删除最旧观测、查询某物种是否 common」三类操作，分别达到 $O(\log n)$、$O(\log n)$、$O(1)$ 的目标。核心难点是用 **增广（augmentation）** 让「查询某物种在任一单区内的最大观测数」变成 $O(1)$。

**题目（原文）**：

PurpleRock Park is a wildlife reserve, divided into zones, where each zone has a park ranger who records current sightings of animals of different species over time. Old animal sightings are periodically removed from the database. A species s is common if current park records contain at least 100 sightings of species s within any single zone of the park.

Describe a database to store animal sightings, supporting the following four operations, where n is the number of sightings stored in the database at the time of the operation. State whether your running times are worst-case, expected, and/or amortized.

- initialize() — Initialize an empty database in O(1) time
- add sighting(s, i) — Record a newest sighting of species s in zone i in O(log n) time
- remove oldest() — Remove the oldest sighting stored in the database in O(log n) time
- is common(s) — Return whether species s is common based on sightings that have not yet been removed from the database in O(1) time

**题目（译文）**：

PurpleRock Park（紫岩公园）是一个野生动物保护区，被划分为若干 zone（分区），每个分区有一名公园巡护员，随时间记录不同 species（物种）动物的当前 sightings（目击观测）。旧的观测记录会被定期从数据库中删除。一个物种 $s$ 称为 **common**（常见），如果当前公园记录在**任一单个分区内**至少包含 100 条物种 $s$ 的观测。

请描述一个用于存储动物观测的数据库，支持以下四个操作，其中 $n$ 是操作发生时数据库中存储的观测数量。请说明各操作的运行时间是 worst-case、expected 还是 amortized：

- `initialize()` —— 在 $O(1)$ 时间内初始化一个空数据库
- `add sighting(s, i)` —— 在 $O(\log n)$ 时间内记录物种 $s$ 在分区 $i$ 的一条最新观测
- `remove oldest()` —— 在 $O(\log n)$ 时间内删除数据库中存储的最旧观测
- `is common(s)` —— 在 $O(1)$ 时间内返回物种 $s$ 是否 common（基于尚未从数据库删除的观测）

> 补充说明（判据解析）：「common」的定义是**任一单区**内该物种观测数 ≥ 100，即关心的是「该物种在所有分区中计数的**最大值**」。所以数据结构必须能在 $O(1)$ 内给出这个最大值——这正是增广 AVL 树的用途。

**答案**：

**本质（idea）**：每个物种 $s$ 维护一棵 AVL 树 $T_s$，按分区号 $i$ 为 key，存「该物种在该分区的观测数 $c_i$」；并用**子树最大值增广**，使根节点存的就是「该物种在任一分区的最大观测数」。全局再用哈希表 $H$ 映射物种到其树、双向链表 $L$ 维护观测的加入顺序（供删除最旧用）。这样 `is common(s)` 只需 $O(1)$ 查根节点的增广最大值。

**数据结构**：

- 哈希表（hash table）$H$：把每个物种 $s$ 映射到一棵 Set AVL 树 $T_s$。
  - **hash table（哈希表）定义**：通过哈希函数把 key 映射到桶位、支持期望 $O(1)$ 插入/查找/删除的字典结构。
- 每棵 Set AVL 树 $T_s$：存储若干二元组 $(i, c_i)$，其中 $i$ 是分区号（作为 key），$c_i$ 是该物种在分区 $i$ 的观测数。
  - **AVL tree（AVL 树）定义**：一种自平衡二叉搜索树，任意节点左右子树高度差不超过 1，保证所有基本操作 $O(\log n)$。
- 增广（augmentation）：对 $T_s$ 中每个节点 $x$，增广一个字段 $x.m$，表示「$x$ 子树内所有分区的最大观测数」。$x.m$ 可由子节点在 $O(1)$ 内维护：

```math
x.m = \max\{ x.\text{left}.m,\ x.\text{key}(=i \text{ 对应的 } c_i),\ x.\text{right}.m \}
```

- 双向链表（doubly-linked list）$L$：按观测加入顺序存储所有当前观测 $(s, i)$，最旧的在前端。

**各操作实现与复杂度**：

**`initialize()`**：初始化空 $H$ 与空 $L$，worst-case $O(1)$。

**`add sighting(s, i)`**：
1. 在 $H$ 中查 $s$ 找到 $T_s$，expected $O(1)$（若 $s$ 不在 $H$，则插入 $s \mapsto$ 空 $T_s$，expected amortized $O(1)$）。
2. 在 $T_s$ 中找分区 $i$：若 $i$ 不在，插入 $(i, 1)$；否则删掉 $(i, c_i)$ 再重插 $(i, c_i+1)$。删除/插入并维护增广，worst-case $O(\log n)$（因为物种 $s$ 最多有 $n$ 条观测，树高 $O(\log n)$）。
3. 把 $(s, i)$ 插到 $L$ 末尾，worst-case $O(1)$。

综合：本操作 $O(\log n)$ **expected amortized** 时间。

**`remove oldest()`**：
1. 从 $L$ 前端删除最旧对 $(s, i)$，worst-case $O(1)$。
2. 在 $H$ 中查 $s$ 得 $T_s$，expected $O(1)$；在 $T_s$ 中查 $i$ 并把 $c_i$ 减一。若 $c_i$ 减到 0，从 $T_s$ 删掉 $i$。若 $T_s$ 变空，从 $H$ 删掉 $s$，expected amortized $O(1)$。

综合：本操作 $O(\log n)$ **expected amortized** 时间。

**`is common(s)`**：在 $H$ 中查 $s$，返回「$s$ 是否在 $H$ 中，且 $T_s$ 根节点的增广最大值是否 ≥ 100」，expected $O(1)$。

**正确性（不变式论证）**：

- **不变式 1（增广正确性）**：对 $T_s$ 任意节点 $x$，$x.m$ 恒等于其子树内所有分区观测数的最大值。归纳地，叶子显然成立；内部节点 $x$ 的子树最大值等于「左子树最大值、$x$ 自身 key 对应值、右子树最大值」三者之最大，恰好是维护公式，故不变式在每次旋转/更新后仍成立（AVL 旋转只重排 $O(1)$ 个节点，可局部重算）。
- **不变式 2（链表与哈希一致）**：$L$ 始终按加入顺序保存所有未删除观测，$H$ 与各 $T_s$ 的计数始终与 $L$ 中现存观测一一对应。`add sighting` 与 `remove oldest` 成对地维护了这一点。
- **`is common` 的正确性**：$s$ 是否 common 定义为「存在某分区观测数 ≥ 100」，即「$T_s$ 中所有分区的计数最大值 ≥ 100」。根节点的 $x.m$ 正是整棵 $T_s$ 的最大值，故查根即可判定，无需遍历整树，$O(1)$ 正确。

**Common Mistakes**：Continued on S1（详见第 S1 页，本页截断）。

## Problem 6. [14 points] Limited Connections（受限连通）

**题干（逐字译全）**

对任意带权图 $G=(V,E,w)$ 与整数 $k$，定义 $G_k$ 为：从 $G$ 中删去所有权重大于等于 $k$ 的边之后所得到的图。

给定一个**连通**的无向带权图 $G=(V,E,w)$，其中每条边都有一个**互不相同的整数权重**，请描述一个 $O(|E|\log |E|)$ 时间的算法，确定使得 $G_k$ 不连通的最大 $k$ 值。

**解答**

**本质（idea）：** 这是"删掉权重大于等于 $k$ 的边后图是否还连通"这一单调性问题——$k$ 越大删的边越多、越容易不连通，所以可以对 $k$ 做二分查找（binary search），每次用一个线性时间的 reachability（可达性）算法判定。

先构造数组 $A$，装下 $G$ 中 $|E|$ 个互不相同的边权重，用例如归并排序（merge sort）在 $O(|E|\log |E|)$ 时间内排好序。

然后对 $k$ 二分：取 $A$ 中某个边权 $k_0$（初始取中位数权重），运行一个可达性算法（例如 Full-BFS 或 Full-DFS，full breadth-/depth-first search，全量广度/深度优先搜索）从任意一个顶点 $x\in V$ 出发，在 $O(|E|)$ 时间内算出 $x$ 能到达哪些顶点。

- 若从 $x$ 恰能到达全部 $|V|$ 个顶点，则 $G_{k_0}$ 连通，说明真正的答案 $k>k_0$，于是在更大的 $k_0$ 值上继续递归；
- 否则 $G_{k_0}$ 不连通，说明 $k\le k_0$，于是在不超过 $k_0$ 的 $k_0$ 值上继续递归。

**为什么这个二分判据正确：** 若 $G_{k_0}$ 从某个顶点 $x$ 出发能到全图，因为 $G$ 本身连通，删去边只可能减少连通性，所以"从 $x$ 可达全部顶点"等价于"$G_{k_0}$ 连通"（无向图中可达性是对称的，$x$ 能到所有人 ⟺ 所有人互相连通）。反过来，$x$ 达不到全部顶点，就一定存在某个顶点与 $x$ 不连通，即 $G_{k_0}$ 不连通。而"删去权重 $\ge k$ 的边"对 $k$ 是单调的：$k$ 越大，删掉的边越多，图越难连通。因此"最大使图不连通的 $k$"是唯一确定的边界，二分能锁定它。

**复杂度分析：** 每一步把搜索范围按一个常数比例缩小（即始终取未搜索区间的中位数权重），所以二分在 $O(\log |E|)$ 步内终止，并识别出使 $G_k$ 不连通的最大 $k$。

排序耗时 $O(|E|\log |E|)$；每次可达性判定耗时 $O(|E|)$，共做 $O(\log |E|)$ 次。故总时间为

```math
O(|E|\log |E|) + O(\log |E|)\cdot O(|E|) = O(|E|\log |E|)
```

**常见错误：**
- 对所有边权线性过滤（扫描每个 $k$），而不是用二分。
- 用 Dijkstra / Bellman-Ford 去低效地解决可达性问题（可达性只需 BFS/DFS，无需最短路径）。
- 只写一句"Use Dijkstra"了事。

## Problem 7. [14 points] On the Street（在旅途上）

**题干（逐字译全）**

朋友 Dal 和 Sean 想开车横穿全国，从 Yew Nork 到 Fan Sancrisco，白天在城市之间开车，每晚在某个城市住旅馆。全国共有 $n$ 个城市。对每个城市 $c_i$，Dal 和 Sean 整理出了：

- 在城市 $c_i$ 住一晚旅馆的正整数花费 $h(c_i)$；
- 一个列表 $L_i$，含至多 10 个从城市 $c_i$ 出发一天之内能开到的其他城市，并且对每个 $c_j\in L_i$，还有从 $c_i$ 直接开车到 $c_j$ 所需的正整数花费 $g(c_i,c_j)$。

请描述一个 $O(nd)$ 时间的算法，判断 Dal 和 Sean 是否可能在**至多 $d$ 天**内、且**沿途花费至多 $b$** 的条件下，从 Yew Nork 开到 Fan Sancrisco。

**解答**

**本质（idea）：** 把"天数"和"所在城市"一起作为状态建图，得到一个 DAG（有向无环图，directed acyclic graph——不含任何有向环的有向图），在 DAG 上做最短路径即可。

设 $C=\{c_0,\dots,c_{n-1}\}$，$c_s$ 表示 Yew Nork，$c_t$ 表示 Fan Sancrisco。构造图 $G$：

- 对每个城市 $c_i\in C$ 和每个天数 $d'\in\{0,\dots,d\}$，设一个顶点 $(c_i,d')$，含义是"在第 $d'$ 天前一夜住在城市 $c_i$"；
- 对每个城市 $c_i\in C$、每个 $c_j\in L_i$、每个 $d'\in\{0,\dots,d-1\}$，设一条有向加权边 $\big((c_i,d'),(c_j,d'+1)\big)$，权重为 $g(c_i,c_j)+h(c_j)$。

**为什么这样建模：** 从 $(c_i,d')$ 走到 $(c_j,d'+1)$，表示第 $d'$ 天从 $c_i$ 开车到 $c_j$，当晚在 $c_j$ 住下。这条边的权重 = 当天开车的花费 $g(c_i,c_j)$ + 当晚在 $c_j$ 的住宿费 $h(c_j)$，正好把一天的总开销一次性累加到路径权重里。天数字段每走一条边严格 +1，所以图必无环，是 DAG。

于是，$G$ 中从顶点 $(c_s,0)$ 到任一顶点 $(c_t,d')$（$d'\in\{0,\dots,d\}$）的路径权重，就对应一条从 Yew Nork 到 Fan Sancrisco、至多 $d$ 天（假设到达 $c_t$ 当晚也住一晚；其他假设亦可）的驾车路线的总花费。

$G$ 无环（每条边都从较小天数指向较大天数），因此运行 DAG Relaxation（DAG 松弛：按拓扑序对边做松弛以求单源最短路，topological sort 拓扑排序——给 DAG 顶点排一个使所有边都从前往后的线性顺序）来计算从 $(c_s,0)$ 出发的单源最短路径。然后判断：是否存在某个 $d'\in\{0,\dots,d\}$ 使得 $\delta\big((c_s,0),(c_t,d')\big)\le b$，若存在则返回"可行"。

**复杂度分析：** 图 $G$ 有 $O(nd)$ 个顶点、$O(nd)$ 条边（因为对每个 $i\in\{0,\dots,n-1\}$ 都有 $|L_i|\le 10$，即常数）。DAG 松弛对每条顶点/边各处理一次，故为 $O(nd)$；检查所有 $d+1$ 个目的地值耗时 $O(d)$。总计

```math
O(nd) + O(d) = O(nd)
```

**常见错误：**
- 没考虑少于 $d$ 天的路径（或考虑了多于 $d$ 天的路径）。
- 没强制"每晚都必须住旅馆"。
- 漏掉旅馆住宿费用。

## Problem 8. [18 points] RGB Graph（RGB 图）

**题干（逐字译全）**

设 $G=(V,E,w)$ 为带权有向图。设 $c:V\to\{r,g,b\}$ 为给每个顶点 $v$ 指定一个颜色 $c(v)$ 的函数，$r,g,b$ 分别代表红、绿、蓝。对 $x\in\{r,g,b\}$：

- 设 $V_x$ 为颜色为 $x$ 的顶点集合，即 $V_x=\{v\in V \mid c(v)=x\}$；
- 设 $E_x$ 为从 $V_x$ 中顶点**出发**的边集合，即 $E_x=\{(u,v)\in E \mid u\in V_x\}$。

假设图 $G$ 与着色 $c$ 满足下列性质：

1. $E$ 中每条边，要么连接两个同色顶点，要么从红顶点连到绿顶点，要么从绿顶点连到蓝顶点。
2. $|V_r|=|E_r|=O(|V|)$，且 $E_r$ 中的边具有相同的正整数权重 $w_r$。
3. $|V_g|=|E_g|=O(|V|^{0.99})$，且 $E_g$ 中的边具有非负整数权重。
4. $|V_b|=|E_b|=O(\sqrt{|V|})$，且 $E_b$ 中的边可具有正或负整数权重。

给定 $G$、$c$、一个红顶点 $s\in V_r$ 和一个蓝顶点 $t\in V_b$，请描述一个 $O(|V|)$ 时间的算法，计算 $\delta(s,t)$，即从 $s$ 到 $t$ 的最小路径权重。

**解答**

**本质（idea）：** 由性质 1，任何从 $s$（红）到 $t$（蓝）的路径，必然先走 $E_r$ 的边（红→绿），再走 $E_g$ 的边（绿→蓝），最后走 $E_b$ 的边（蓝内部）。三段天然分层，可分别用 BFS、Dijkstra、Bellman-Ford 分步求最短距离，逐段拼起来。

任何从 $s$ 到 $t$ 的路径 = 一段走 $E_r$ 中边的路径，接一段走 $E_g$ 中边的路径，再接一段（可能为空的）走 $E_b$ 中边的路径。所以我们按 $E_r$、$E_g$、$E_b$ 的顺序递增地计算 $G$ 中的最小权重距离。

**Step 1（红段，用 BFS）：** 构造无权图 $G'=(V',E')$，其边集为 $E'=E_r$，顶点集为这些边所涉及的顶点，即

```math
V' = \bigcup_{(u,v)\in E_r} \{u,v\}
```

（$V'$ 包含来自 $V_r$ 和 $V_g$ 的顶点。）从 $s$ 在 $G'$ 中跑 breadth-first search（BFS，广度优先搜索——逐层向外扩展、求无权图最短边数距离）来计算无权距离。由于 $E_r$ 中所有边权重都为 $w_r$，所以 $G$ 中从 $s$ 到任一绿顶点 $v\in V'\cap V_g$ 的最小权重距离 = $w_r$ 乘以上面算出的无权距离。

**为什么用 BFS：** $E_r$ 的边权重全部相同（都等于 $w_r$），故"最少边数"与"最小权重"等价，只需 BFS 求边数，再统一乘 $w_r$。这样避开了对 $O(|V|)$ 条边的 Dijkstra。

$G'$ 的大小为 $O(|V|)$（因 $|V_r|=|E_r|=O(|V|)$），所以此步耗时 $O(|V|)$。

**Step 2（绿段，用 Dijkstra）：** 构造加权图 $G''=(V'',E'')$，其组成为：顶点 $s$ 加一条新有向边连到 $V'\cap V_g$ 中每个绿顶点，边权为该顶点在 Step 1 中求得的距离（即从 $s$ 到它的最小路径权重），再加上 $E_g$ 的加权边及其涉及的顶点。$G''$ 中所有权重都为正，所以从 $s$ 在 $G''$ 中跑 Dijkstra（Dijkstra 算法——求非负权图单源最短路径的贪心算法，每次取当前距离最小且未确定的顶点固定）计算最小权重距离。算出的到任一蓝顶点 $v\in V''\cap V_b$ 的距离，就是 $G$ 中从 $s$ 到 $v$、只走红或绿边的路径的最小权重。

**为什么这里能直接换成 Dijkstra：** Step 1 已把从 $s$ 到各绿顶点的最短红段距离"折叠"成一条边，$E_g$ 权重又非负，故 $G''$ 是正权图，Dijkstra 正确且高效。

$G''$ 的大小为 $O(1+|V_g|+|E_g|)=O(|V|^{0.99})$，所以此步耗时

```math
O(|V|^{0.99}\log |V|^{0.99}) = O(|V|^{0.99}\cdot 0.99\log |V|) = O(|V|)
```

（因为 $|V|^{0.99}\log|V| = o(|V|)$，被 $O(|V|)$ 覆盖。）

**Step 3（蓝段，用 Bellman-Ford）：** 构造加权图 $G'''=(V''',E''')$，其组成为：顶点 $s$ 加一条新有向边连到 $V''\cap V_b$ 中每个蓝顶点，边权为该顶点在 Step 2 中求得的距离（即从 $s$ 到它的最小路径权重），再加上 $E_b$ 的加权边及其涉及的顶点。$G'''$ 中权重可能为正或负，所以从 $s$ 在 $G'''$ 中跑 Bellman-Ford（Bellman-Ford 算法——允许负权边、通过至多 $|V|-1$ 轮松弛求单源最短路径的动态规划型算法）计算加权最小距离。算出的到 $t$ 的距离即为所求 $\delta(s,t)$，即 $G$ 中从 $s$ 到 $t$ 的任意路径的最小权重。

**为什么蓝段必须用 Bellman-Ford：** $E_b$ 的边可能有负权，Dijkstra 会因负权而失效，Bellman-Ford 才能处理负权边并给出正确最短路。

$G'''$ 的大小为 $O(1+|V_b|+|E_b|)=O(\sqrt{|V|})$，所以此步耗时

```math
O(\sqrt{|V|}\cdot\sqrt{|V|}) = O(|V|)
```

（Bellman-Ford 对 $|V'''|$ 个顶点做 $|V'''|$ 轮、每轮扫 $|E'''|$ 条边，故为 $O(|V'''|\cdot|E'''|)=O(\sqrt{|V|}\cdot\sqrt{|V|})$。）

三步合计 $O(|V|)+O(|V|)+O(|V|)=O(|V|)$，满足要求。

**常见错误：** 续于 S1。

### Problem 9. [16 points] Separated Subsets（分离子集）

> **题目译文：** 对任意由整数构成的集合 $S$，以及任意正整数 $m$ 和 $k$，$S$ 的一个 $(m,k)$-separated subset（$(m,k)$-分离子集）是指 $S$ 的任意一个子集 $S_0 \subseteq S$，满足：$S_0$ 的和等于 $m$，并且 $S_0$ 中任意两个不同的整数 $a, b \in S_0$ 都满足 $|a - b| \ge k$。给定正整数 $m$ 和 $k$，以及一个包含 $n$ 个互不相同的正整数的集合 $S$，请描述一个 $O(n^2 m)$ 时间的算法，用来**计数**（count）$S$ 中 $(m,k)$-分离子集的个数。
>
> （解此题时，可以假设单个机器字（machine word）足够大，能容纳算法执行过程中计算出的任意整数。）

**Solution（解答）：**

**1. Subproblems（子问题定义）**

- 首先在 $O(n \log n)$ 时间内（例如用归并排序 merge sort）把 $S$ 中的整数按**递增**排序存入数组 $A$；
- 其中 $A = (a_0, \dots, a_{n-1})$；
- $x(i, j)$：后缀 $A[i:]$ 中 $(j,k)$-分离子集的个数；
- 其中 $i \in \{0, \dots, n\}$，$j \in \{0, \dots, m\}$。

> **为什么这样定义：** 排序之后，"任意两数之差的绝对值 ≥ k" 这个全局约束变成了一个**有序结构**上的局部约束——若已选定某个元素 $A[i]$ 进入子集，那么它之后能再被选进同一个子集的元素，必须满足与 $A[i]$ 的距离至少为 $k$。由于数组已按升序排列，这个约束等价于"下一个可选元素必须跳到某个下标 $f(i)$ 之后"，从而把"任意两两相差 ≥ k"这个看似组合爆炸的条件，压缩成一个"跳跃指针" $f(i)$。

**2. Relate（递推关系）**

- 把「使用 $A[i]$」的 $(j,k)$-分离子集的个数，与「不使用 $A[i]$」的个数相加（即对选与不选 $A[i]$ 作分类讨论）；
- 若 $A[i] \le j$ 且被使用：
  - 那么 $A[i:]$ 中所有小于 $A[i] + k$ 的整数都不能再被使用；
  - 令 $f(i)$ 为大于 $i$ 的最小下标，使得 $A[f(i)] - A[i] \ge k$；
  - 然后递归计数 $x\big(f(i),\, j - A[i]\big)$；
- 否则，$A[i]$ 不被使用，我们可以递归计数 $x(i+1, j)$。

递推式可写作：

```math
x(i, j) = \begin{cases}
x\big(f(i),\, j - A[i]\big) + x(i+1, j), & \text{若 } A[i] \le j; \\[4pt]
x(i+1, j), & \text{恒成立}.
\end{cases}
```

> **为什么这样分两类：** 这是典型的 dynamic programming（动态规划，简称 DP）——把「和为 $j$ 且两两分离」的计数，按「第 $i$ 个元素是否被选中」拆成互斥的两部分，两部分分别对应一个新的更小的子问题，最后相加。选 $A[i]$ 后，为避免与已选元素相距小于 $k$ 的冲突，只能从 $f(i)$ 处继续（跳过了所有 $A[i] + k$ 以下的元素，这正是"分离"约束在有序数组上的落地方式）；不选 $A[i]$ 则直接看 $i+1$。

**3. Topo（拓扑序 / 依赖无环性）**

- 子问题 $x(i,j)$ 只依赖于严格更大的 $i$，因此依赖关系是**无环**（acyclic）的，可以按 $i$ 从大到小（即从后缀尾部往头部）递推计算。

> **为什么无环就安全：** DP 必须保证每个子问题在被用到之前已经算好。这里每个状态只向 $i$ 更大的方向跳转，所以不存在回头依赖，天然给出一个合法的计算顺序（topological order，拓扑序）。

**4. Base（基础情形 / 边界）**

- $x(n, 0) = 1$，空子集（empty subset）的和恒为 0，因此总可达成；
- 对 $j > 0$，$x(n, j) = 0$，因为空集不可能求和得到一个正数。

> **为什么这样设边界：** $x(n, j)$ 表示后缀为空（没有任何元素可用）时的计数。和 $j=0$ 只能由"什么都不选"唯一实现（计 1 种）；而 $j>0$ 时没有任何元素可用、又要求非零和，故为 0。这个边界为整个递推提供了锚点。

**5. Original（原问题归约）**

- 答案是 $x(0, m)$，即数组 $A$（等价于集合 $S$）中 $(m,k)$-分离子集的个数。

**6. Time（时间复杂度）**

- 子问题个数：$(n+1)(m+1) = O(nm)$；
- 每个子问题的工作量：用线性扫描（linear scan）找 $f(i)$ 为 $O(n)$；
- 总时间 $O(n^2 m)$。
- （注：其实可以通过二分查找 binary search 在 $O(\log n)$ 内算出 $f(i)$，或由 $f(i-1)$ 以 amortized $O(1)$ 的均摊时间递推得到 $f(i)$，但这些优化对拿满分**不是必需**的。）

> **复杂度递推式解读：** 本题不是递归深度上的复杂度，而是状态表规模 × 单状态成本。状态共 $O(nm)$ 个；每个状态需要定位 $f(i)$，线性扫描最坏 $O(n)$；相乘得 $O(n^2 m)$。这也是题目给定的目标复杂度。

### Problem 10. [18 points] A Feast for Crowns（王冠盛宴）

> **题目译文：** Ted Snark 要为 Southeros 女王及其宾客筹办一场盛宴，任务是把他们安排在一条长条宴会桌的**同一侧**入座。
>
> - Ted 有一份 $2n$ 位宾客的名单，其中每位宾客 $i$ 有一个已知的、互不相同的正整数 $f_i$，表示该宾客在女王心中的受宠程度（favor）。
> - Ted 必须"恭敬地"安排座位：女王必须坐在正中间，左右两侧各有 $n$ 位宾客，且宾客的受宠程度必须**随远离女王而单调递减**，也就是说，坐在宾客 $i$ 与女王之间的任何宾客，其受宠程度都必须大于 $f_i$。
> - 此外，每位宾客都讨厌其他所有宾客：对任意两位宾客 $i, j$，Ted 都知道他们之间互为正整数的仇恨值（mutual hatred）$d(i,j) = d(j,i)$。
>
> 给定 Ted 的宾客信息，请描述一个 $O(n^3)$ 时间的算法，来确定一种"恭敬的"座位顺序，使得**相邻就座**的宾客两两之间的仇恨值之和最小。正确的 $O(n^4)$ 时间算法也可获得可观的部分分。

**Solution（解答）：**

**1. Subproblems（子问题定义）**

- 在 $O(n \log n)$ 时间内把宾客按受宠程度递增排序，得到 $F = (f_0, \dots, f_{2n-1})$；
- $F$ 的任意一个「划分为两个长度各为 $n$ 的子序列」的方案，都对应一种恭敬的座位安排；
- $x(i, j_L, j_R, n_L)$：把后缀 $F[i:]$ 中的 $n - i$ 位宾客恭敬地坐在女王旁边时，相邻宾客之间仇恨值之和的最小值；其中左侧已有 $n_L$ 位，右侧有 $n_R = (n - i) - n_L$ 位；宾客 $j_L < i$ 已经被坐在左侧第 $n_L + 1$ 个位置，宾客 $j_R < i$ 已经被坐在右侧第 $n_R + 1$ 个位置。
- 参数范围：$i \in \{0, \dots, 2n\}$，$j_L, j_R \in \{-1, \dots, 2n-1\}$，$n_L \in \{0, \dots, n\}$，并且要么 $j_L = i-1$、要么 $j_R = i-1$；
- 令 $d(-1, i) = d(i, -1) = 0$ 对所有 $i \in \{0, \dots, 2n-1\}$ 成立（即桌子两端尽头处没有仇恨值）。

> **为什么这样建模：** 由于「越靠近女王受宠越高、越远离越低」这一单调约束，把所有宾客按受宠程度排序后，合法的座位安排其实是一个"从两端往中间放"的过程：受宠程度最高的在女王身边，最低的在最外侧。等价地，$F$ 必须被切成两个长度 $n$ 的递增子序列，分别对应女王左、右两侧（从外侧到内侧）。因此状态只需记录"下一个要放的宾客是谁（$i$）、左/右两端**最近刚放下的那个人**是谁（$j_L$、$j_R$）、左侧还剩几个位置（$n_L$）"。特别地，约束"$j_L = i-1$ 或 $j_R = i-1$"抓住了关键事实——我们按受宠顺序逐个放，所以 $i-1$ 这个刚放下的宾客必然位于左端或右端之一。

**2. Relate（递推关系）**

- 猜测宾客 $i$ 是被安排在右端还是左端；
- 坐在 $j_L$ 旁边要付出仇恨值 $d(i, j_L)$；坐在 $j_R$ 旁边要付出仇恨值 $d(i, j_R)$。

递推式可写作：

```math
x(i, j_L, j_R, n_L) = \min \begin{cases}
d(i, j_L) + x(i+1,\, i,\, j_R,\, n_L - 1), & \text{若 } n_L > 0; \\[4pt]
d(i, j_R) + x(i+1,\, j_L,\, i,\, n_L), & \text{若 } (n-i) - n_L > 0.
\end{cases}
```

> **为什么用 min 而非加和：** 上一题（Problem 9）是计数，要把所有分支"相加"；本题是最小化，因此对"放左侧"与"放右侧"两种选择取**最小值**。两个分支分别检查还有没有左侧空位（$n_L > 0$）或右侧空位（$(n-i)-n_L > 0$），从而保证最终左、右两侧恰好各放 $n$ 位宾客。

**3. Topo（拓扑序）：** 子问题 $x(i, j_L, j_R, n_L)$ 只依赖于严格更大的 $i$，因此依赖关系无环（acyclic），可自后向前递推。

**4. Base（基础情形）：** 对所有 $j_L, j_R \in \{0, \dots, 2n\}$，$x(2n, j_L, j_R, 0) = 0$（没有任何宾客时仇恨值为 0）。

**5. Original（原问题归约）：** 答案是 $x(0, -1, -1, n)$，即恭敬地安排全部宾客时，相邻宾客仇恨值之和的最小值。

**6. Time（时间复杂度）**

- 子问题个数：虽然本问题有四个参数，但满足"$j_L = i-1$ 或 $j_R = i-1$"的子问题只有 $O(n^3)$ 个；
- 每个子问题的工作量：$O(1)$，故总时间 $O(n^3)$。

> **为什么是 $O(n^3)$ 而不是 $O(n^4)$：** 表面上看有 $i, j_L, j_R, n_L$ 四个参数，会让人误以为是 $O(n^4)$ 个状态。但约束"$j_L = i-1$ 或 $j_R = i-1$"意味着四个参数中实际上**只有三个是独立的**——给定 $i$ 后，$j_L$ 与 $j_R$ 里必有一个被 $i-1$ 锁定。因此状态空间真正的大小是 $O(n^3)$，再乘上每个状态的 $O(1)$ 转移，总复杂度 $O(n^3)$。这正是本解从"自然想到的 $O(n^4)$"降维到 $O(n^3)$ 的关键。
