### (a)

**判据（T F）**：$2^{2n} \in \Theta(2^n)$

> **原文**：T F $2^{2n} \in \Theta(2^n)$.
> （T F：$2^{2n}$ 是否属于 $\Theta(2^n)$？）

> **文字层校订**：PDF 抽取串是 `22n ∈ Θ(2n)`，两个上标的基线被压平到一行。按 span 几何可判明：`2^{2n}` 的 `2n` 字号 7.97pt、baseline 206.64，主体 `2` 字号 11.96pt、baseline 210.97（上移 4.33pt）⇒ 真上标；`\Theta` 内的 `n` 同理（baseline 206.64）。故原文确定是 $2^{2n} \in \Theta(2^n)$，无需猜测。

**答案：F（错误）。**

**理由**：$2^{2n} = (2^2)^n = 4^n$，而 $2^n$ 与 $4^n$ 的比值为

```math
\frac{2^{2n}}{2^n} = 2^{2n - n} = 2^n \to \infty \quad (n \to \infty)
```

该比值无上界，因此 $2^{2n} \ne O(2^n)$，自然也不属于 $\Theta(2^n)$。

> **补充说明（供复习）**：这里的关键点是 —— $\Theta$ 记号对**指数底数**是敏感的：$4^n$ 与 $2^n$ 只差一个常数底数，却**不属于**同一渐近类。若把 $2^{2n}$ 写成 $4^n$，直觉上容易误以为「$4$ 与 $2$ 只差常数倍」而答 T，这正是本题的陷阱。正确的判断标准是直接比较：$\frac{4^n}{2^n} = 2^n$ 无界，故不成立。反之，$2^{2n} \in \Theta(4^n)$ 才是正确的。

### (b)

**判据（T F）**：若 $T(n) = \frac{9}{4}T\left(\frac{2}{3}n\right) + n^2$ 且 $T(1) = \Theta(1)$，则 $T(n) = O(n^2)$

> **原文**：If $T(n) = \frac{9}{4}T\left(\frac{2}{3}n\right) + n^2$ and $T(1) = \Theta(1)$, then $T(n) = O(n^2)$.
> （若 $T(n) = \frac{9}{4}T\left(\frac{2}{3}n\right) + n^2$ 且 $T(1) = \Theta(1)$，那么 $T(n) = O(n^2)$ 是否成立？）

> **文字层校订**：抽取串为 `T (n) = 4 9 T 3 2 n + n2`，两个分式的分子与分母各占一行、顺序打乱。基线判定：`9` 的 baseline 383.56（分子）与 `4` 的 392.39（分母）⇒ $\frac{9}{4}$；`2` 的 383.56 与 `3` 的 392.39 ⇒ $\frac{2}{3}$；末尾 `n2` 的 `2` baseline 383.93 为上标。渲染图复核一致。

**答案：F（错误）。**

**理由**：这是 master theorem 的 **case 2**（临界情形）：$a = \frac{9}{4}$，$b = \frac{3}{2}$，于是

```math
\log_b a = \log_{3/2} \frac{9}{4} = \log_{3/2}\left(\frac{3}{2}\right)^{2} = 2
```

即 $n^{\log_b a} = n^2$ 与 $f(n) = n^2$ **同阶**，故 $T(n) = \Theta(n^2 \log n)$，不是 $O(n^2)$。

递归树给出同一结论，而且更直观：第 $i$ 层有 $\left(\frac{9}{4}\right)^i$ 个节点，每个规模 $n\left(\frac{2}{3}\right)^i$，层总代价

```math
\left(\frac{9}{4}\right)^{i}\left(n\left(\frac{2}{3}\right)^{i}\right)^{2}
= \left(\frac{9}{4} \cdot \frac{4}{9}\right)^{i} n^2 = n^2
```

$\frac{9}{4}$ 与 $\frac{4}{9}$ 互为倒数，指数增长被**平方后的规模收缩精确抵消**，每层恰好 $n^2$；层数 $=\log_{3/2} n$ ⇒ 总计 $\Theta(n^2 \log n)$。

**端点代入验证**：取 $n = \left(\frac{3}{2}\right)^k$（$k$ 层到底），则

```math
T(n) = k\,n^2 + \left(\frac{9}{4}\right)^{k}\Theta(1) = n^2 \log_{3/2} n + \Theta(1)
```

与 $\Theta(n^2\log n)$ 一致。注意叶子层总代价 $\left(\frac{9}{4}\right)^{k}\Theta(1) = n^2\cdot\Theta(1) = \Theta(n^2)$，只比主项 $n^2\log n$ 少一个 $\lg n$ 因子，不改变结论。

### (c)

**判据（T F）**：对一个初始为空的数据结构执行 $n$ 次 amortized $O(1)$ 的操作，worst-case 耗时 $O(n)$

> **原文**：Performing an $O(1)$ amortized operation $n$ times on an initially empty data structure takes worst-case $O(n)$ time.
> （对一个初始为空的数据结构，把一次 amortized $O(1)$ 的操作做 $n$ 次，最坏情况耗时 $O(n)$。）

**答案：T（正确）。**

**理由**：amortized bound 的陈述本身就是**对操作序列**的最坏情形界：若单次操作的 amortized cost 为 $O(1)$（即摊还代价 $\le c$），则由摊还记账不变式，**任意**长度为 $n$ 的合法操作序列总代价 $\le cn = O(n)$。这里的「worst-case」修饰的是「$n$ 次操作的总时间」，覆盖所有操作序列，与 amortized 的定义重合。

**别读成**：每次操作都是 worst-case $O(1)$ —— 那是更强的命题，一般不成立。dynamic array（动态数组）扩容那一次是 $\Theta(n)$，但连续 $n$ 次 push 的总代价仍是 $O(n)$。题目问的是后者。

### (d)

**判据（T F）**：对 $n$ 个可比较元素用 merge sort 排序，过程中 $A$ 中每个元素只与 $O(\log n)$ 个其他元素比较

> **原文**：Given an array $A$ containing $n$ comparable items, sort $A$ using merge sort. While sorting, each item in $A$ is compared with $O(\log n)$ other items of $A$.
> （给定含 $n$ 个可比较元素的数组 $A$，用 merge sort 排序。排序过程中，$A$ 中的每个元素与 $O(\log n)$ 个其他元素比较。）

**答案：F（错误）。**

**理由**：merge sort 中某个元素在某次 merge 里可以**反复**被比较。设根层 merge 的左半全部小于右半，则右半的当前首元素 $r$ 要与左半的每一个元素比较一次才被输出 —— 仅这一层，$r$ 就与 $\Theta(n)$ 个元素比较过。

```math
\text{根层 merge 中 } r \text{ 的比较次数} = \left\lceil \frac{n}{2} \right\rceil = \Theta(n)
```

正确的界是：merge sort 的**总**比较次数 $\le n\left\lceil \lg n \right\rceil$，即平均每个元素 $O(\log n)$ 次；但「平均」不等于「每个」。命题把平均说成了逐元素上界，故为假。

### (e)

**判据（T F）**：给定一个存有 $n$ 个可比较 key 的 binary min-heap，可以用 $O(n)$ 次比较构造一棵含相同元素的 Set AVL Tree

> **原文**：Given a binary min-heap storing $n$ items with comparable keys, one can build a Set AVL Tree containing the same items using $O(n)$ comparisons.
> （给定存有 $n$ 个可比较 key 的 binary min-heap，可以用 $O(n)$ 次比较建出一棵包含相同元素的 Set AVL Tree。）

**答案：F（错误）。**

**理由（比较模型下界）**：AVL Tree 的 shape 只由 $n$ 决定，而它的 inorder 遍历必然输出 **key 的有序序列**。于是「从 heap 用 $O(n)$ 次比较建出这棵树」会直接给出一个排序算法：

1. 任意 $n$ 个元素先用 `build-heap` 在 $O(n)$ 次比较内整理成 min-heap；
2. 本算法用 $O(n)$ 次比较建出 AVL Tree；
3. 一次 inorder 遍历（$O(n)$ 时间、**0 次比较**）输出排好序的序列。

合计 $O(n)$ 次比较的排序算法，与比较模型下界 $\Omega(n \log n)$ 矛盾。故不可能，答案 F。

> **要点**：heap 蕴含的只是**偏序**（父子有序），它不能替代排序所需的全部比较；能 O(n) 建 heap 不等于能 O(n) 排序。

### (f)

**判据（T F）**：在有向图 $G = (V, E)$ 上从 $s$ 做 BFS；处理顶点 $u$ 时若某个 $v \in \mathrm{Adj}^{+}(u)$ 已被处理，则 $G$ 含有向环

> **原文**：Given a directed graph $G = (V, E)$, run breadth-first search from a vertex $s \in V$. While processing a vertex $u$, if some $v \in \mathrm{Adj}^{+}(u)$ has already been processed, then $G$ contains a directed cycle.
> （给定有向图 $G=(V,E)$，从顶点 $s \in V$ 跑 BFS。处理顶点 $u$ 时，若某个 $v \in \mathrm{Adj}^{+}(u)$ 已被处理过，则 $G$ 含有一个有向环。）

> **文字层校订**：抽取串为 `Adj + (u)`，`+` 字号 7.97pt、baseline 428.7 相对主体 430.7 上移 ⇒ 真上标，即「出邻居集」。

**答案：F（错误）。**

**理由**：有向 BFS 中「指向已处理顶点」的边可以只是**跨层边的反向**，不构成环。反例：

```text
s -> a,  s -> b,  b -> a
```

BFS 从 $s$ 出发：第 0 层 $\{s\}$，第 1 层 $\{a, b\}$，处理顺序 $s, a, b$。处理 $b$ 时它的邻居 $a$ 已处理，条件成立，但该图是 DAG（无环）。

正确判据：需要出现**指向同层或更深层的非树边**（即 $\mathrm{dist}[v] \ge \mathrm{dist}[u]$ 且 $(u,v)$ 非树边），或指向 $u$ 的 BFS 祖先。「已处理」这一条在**无向**图里才充分 —— 无向图的每条非树边 $(u,v)$ 都与树路径 $u \leadsto v$ 构成环。

### (g)

**判据（T F）**：在带权图 $G = (V, E, w)$ 上从 $s \in V$ 跑 Bellman-Ford；若存在 witness $v \in V$ 使 $\delta_{|V|}(s, v) \lt \delta_{|V|-1}(s, v)$，则 $v$ 位于 $G$ 的一条负权环上

> **原文**：Run Bellman-Ford on a weighted graph $G = (V, E, w)$ from a vertex $s \in V$. If there is a witness $v \in V$, i.e., $\delta_{|V|}(s, v) \lt \delta_{|V|-1}(s, v)$, then $v$ is on a negative-weight cycle of $G$.
> （在带权图 $G=(V,E,w)$ 上从顶点 $s \in V$ 跑 Bellman-Ford。若存在 witness $v \in V$，即 $\delta_{|V|}(s, v) \lt \delta_{|V|-1}(s, v)$，则 $v$ 位于 $G$ 的某条负权环上。）

> **文字层校订**：$\delta$ 的「$|V|$」是**下标**（竖直基线 602.0 相对主体 597.2 下移 4.8pt），不是上标 —— 表示「至多 $|V|$ 条边的最短路径权」。

**答案：F（错误）。**

**理由**：$\delta_k(s, v)$ 表示「至多 $k$ 条边」的最短路权。若 $\delta_{|V|} \lt \delta_{|V|-1}$，只能推出**从 $v$ 可达某个负权环**（环在 $v$ 的下游），不能推出 $v$ 本身在环上。反例：

```math
s \xrightarrow{1} x, \qquad x \xrightarrow{-10} x\ (\text{自环}), \qquad x \xrightarrow{0} v
```

此时 $\delta_{|V|-1}(s, v) = 1$，而 $\delta_{|V|}(s, v) = 1 - 10 + 0 = -9$，$v$ 是 witness，但 $v$ 不在环上（环是 $x$ 的自环）。

正确陈述：$\delta_{|V|}(s, v) \lt \delta_{|V|-1}(s, v)$ ⇒ $v$ **可达**一个负权环。Bellman-Ford 的负环检测取任何 witness $v$，沿 predecessor 回溯 $|V|$ 步才落进环里 —— 回溯落点才是环上的顶点。

### (h)

**判据（T F）**：对 weighted complete graph（每个顶点与其他每个顶点之间都有边），Floyd–Warshall 与 Johnson's Algorithm 解 all-pairs shortest paths 的渐近运行时间相同

> **原文**：Floyd–Warshall and Johnson's Algorithm solve all-pairs shortest paths in the same asymptotic running time when applied to weighted complete graphs, i.e., graphs where every vertex has an edge to every other vertex.
> （对 weighted complete graph —— 即每个顶点到其他所有顶点都有边的图 —— Floyd–Warshall 与 Johnson's Algorithm 以相同的渐近运行时间求解所有点对最短路。）

**答案：T（正确）。**

**理由**：complete graph 上 $|E| = \Theta(|V|^2)$。

- Floyd–Warshall：$\Theta(|V|^3)$，与 $|E|$ 无关；
- Johnson：一次 Bellman-Ford（加超级源后 $\Theta(|V||E|)$）加 $|V|$ 次 Dijkstra。用 Fibonacci heap 时

```math
\Theta\left(|V||E| + |V|^2 \lg |V|\right)
= \Theta\left(|V|^3 + |V|^2 \lg |V|\right)
= \Theta(|V|^3)
```

两者同为 $\Theta(|V|^3)$，故「相同」。

> **限定条件**：上面的 T 依赖 Fibonacci heap。若 Johnson 用 binary heap 实现，则为 $\Theta(|V||E| \lg |V|) = \Theta(|V|^3 \lg |V|)$，此时不再相同。题目强调「complete graph」正是为了让 $|V|^2\lg|V|$ 被 $|V|^3$ 吸收 —— 密度越高，Johnson 越接近 Floyd–Warshall 的三次方量级。

### (i)

**判据（T F）**：若存在多项式时间算法解 0-1 Knapsack，则也存在多项式时间算法解 Subset Sum

> **原文**：If there is an algorithm to solve 0-1 Knapsack in polynomial time, then there is also an algorithm to solve Subset Sum in polynomial time.
> （若有多项式时间算法解 0-1 Knapsack，则也有多项式时间算法解 Subset Sum。）

**答案：T（正确）。**

**理由**：Subset Sum 多项式归约到 0-1 Knapsack。给定 Subset Sum 实例（多重集 $S$、目标和 $W$），构造 knapsack 实例：每个元素 $s_i$ 的**重量与价值都取 $s_i$**，容量取 $W$。则

```math
\text{存在子集和恰为 } W \iff \text{最大价值} \ge W
```

因为价值 $\le$ 总重量 $\le$ 容量 $\le W$，最大价值 $\ge W$ 只能等于 $W$。归约本身 $O(n)$ 时间、只调用一次 knapsack 算法 ⇒ $O(n) + \mathrm{poly}$ 仍是多项式。

### (j)

**判据（T F）**：若判定问题 $A$ 有 pseudopolynomial-time 算法，且 $P \ne NP$，则 $A$ 不能在多项式时间内求解

> **原文**：Suppose a decision problem $A$ has a pseudopolynomial-time algorithm to solve $A$. If $P \ne NP$, then $A$ is not solvable in polynomial time.
> （设判定问题 $A$ 有一个 pseudopolynomial-time 算法；若 $P \ne NP$，则 $A$ 不可在多项式时间内求解。）

**答案：F（错误）。**

**理由**：pseudopolynomial 是对**输入数值大小**的多项式（如 $O(nW)$），比 polynomial time（对**输入位数** $\lg W$ 的多项式）弱。任何 polynomial-time 可解的问题都自动是 pseudopolynomial 的（$\mathrm{poly}(n, \lg W)$ 当然也是 $\mathrm{poly}(n, W)$），所以「$A$ 有 pseudopolynomial 算法」推不出「$A$ 难」。

反例：$A$ =「给定整数 $n$，$n$ 是否为偶数」，有 $O(1)$ 算法，既 pseudopolynomial 也 polynomial，与 $P \ne NP$ 无关。pseudopolynomial 算法只说明「数值小时快」，不含 $A$ 是 NP-hard 的信息；要得到「无多项式算法」还需要额外前提「$A$ 是 **weakly** NP-hard」（如 Subset Sum、0-1 Knapsack 之于 $P \ne NP$）。

## 第 6 页 — Problem 3：Sorting Sorts

### Problem 3. [24 points] Sorting Sorts（排序算法，2 小题）

#### (a) [12 points]

> An integer array $A$ is **$k$-even-mixed** if there are exactly $k$ even integers in $A$, and the odd integers in $A$ appear in sorted order. Given a $k$-even-mixed array $A$ containing $n$ distinct integers for $k = \lceil n / \lg n \rceil$, describe an $O(n)$-time algorithm to sort $A$.
>
> （整数数组 $A$ 称为 **$k$-even-mixed**（$k$-偶混合），若 $A$ 中恰有 $k$ 个偶数，且 $A$ 中的奇数已按有序排列。给定一个 $k$-even-mixed 数组 $A$，含 $n$ 个互不相同的整数，其中 $k = \lceil n / \lg n \rceil$，请给出一个 $O(n)$ 时间的算法把 $A$ 排好序。）

> **文字层校订**：抽取串是 `k = dn/ lg ne` —— `d` 与 `e` 是 `.notdef`/私有码位对 $\lceil$ $\rceil$ 的映射（CMEX10 字体的括号补偿码位），并非字母。渲染图确认是向上取整号。

**参考解答**：

关键观察：$A$ 里**奇数已有序**（相对次序固定），只有 $k$ 个偶数的位置没定。所以问题降级为「把 $k$ 个无序的偶数插入到已序的奇数序列里」。

1. 扫一遍 $A$，把偶数抽进数组 $E$、奇数抽进数组 $O$（$O$ 已是升序）。耗时 $O(n)$。
2. 对 $E$ 排序：$|E| = k = \lceil n / \lg n \rceil$，用 merge sort 需要 $O(k\lg k)$ 次比较，

```math
k \lg k = \left\lceil \frac{n}{\lg n} \right\rceil \lg\left\lceil \frac{n}{\lg n} \right\rceil \le \frac{2n}{\lg n}\cdot \lg n = O(n)
```

3. 归并 $E$ 与 $O$：$O(n + k) = O(n)$。

总时间 $O(n)$、空间 $O(n)$。正确性：输出含 $A$ 的每个元素恰好一次且升序，即 $A$ 的排序序列。

> **本题的设计意图**：$k$ 与 $\lg k$ 的乘积被 $n$ 吸收 —— 这是「利用输入的部分结构性来打破 $\Omega(n\lg n)$ 下界」的标准手法。下界只对**完全无序**的输入成立；一旦已知一部分顺序，比较次数的下界就降到 $O(k \lg k)$ 量级的剩余熵。

#### (b) [12 points]

> Let $A$ be an array of $n$ pairs of positive integers $(x_i, y_i)$ with $x_i, y_i \lt n^2$ for all $i \in \{0, \dots, n - 1\}$. The **power** of pair $(x, y)$ is the integer $x + ny$. Describe an $O(n)$-time algorithm to sort the pairs in $A$ increasing by power.
>
> （设 $A$ 是 $n$ 个正整数对 $(x_i, y_i)$ 的数组，对所有 $i \in \{0, \dots, n-1\}$ 有 $x_i, y_i \lt n^2$。数对 $(x, y)$ 的 **power**（幂值）是整数 $x + ny$。请给出一个 $O(n)$ 时间算法，把 $A$ 按 power 递增排序。）

**参考解答**：

power 的范围：$x, y \lt n^2$ ⇒ $0 \le x + ny \le (n^2 - 1) + n(n^2 - 1) = n^3 - 1$。把 power 表示成 $n$ 进制的三位数字。令 $a = \lfloor x/n \rfloor$、$b = x \bmod n$（$a, b \lt n$），则

```math
x + ny = (a n + b) + n y = b + n(a + y)
```

再令 $t = a + y$（$t \le (n-1) + (n^2-1) = n^2 + n - 2$），把它拆成两位 $t = d + n\,c$（$d \lt n$，$c \le n$）。于是

```math
x + ny = b + n\,d + n^2\,c, \qquad b, d \lt n,\quad c \le n
```

三个数字都是 $O(n)$ 大小 ⇒ 用 **LSD radix sort**，基数 $n$，3 趟，低位到高位分别是 $b$、$d$、$c$：

1. 按 $b = x \bmod n$ 做稳定 counting sort（值域 $[0, n)$）；
2. 按 $d = \left(\left\lfloor x/n \right\rfloor + y\right) \bmod n$ 做稳定 counting sort（值域 $[0, n)$）；
3. 按 $c = \left\lfloor \left(\left\lfloor x/n \right\rfloor + y\right) / n \right\rfloor$ 做稳定 counting sort（值域 $[0, n]$）。

每趟 counting sort 的时间是 $O(n + \text{值域}) = O(n)$，因为值域是 $n$ 或 $n+1$。三趟 ⇒ $O(n)$。

正确性：LSD radix sort 对定长键正确（先排低位、稳定排序保证高位的相对次序不被破坏）；而 $(b, d, c)$ 就是 power 的 $n$ 进制三位展开，唯一确定 power ⇒ 排序键即 power。

> **为什么不能直接按 $(x \bmod n,\ \lfloor x/n \rfloor,\ y)$ 排序**：$x + ny = b + n(a + y)$ 中 $a$ 与 $y$ 是**相加**关系，不是「并置」，所以 $a$ 与 $y$ 不能各算一位 —— 中间会进位。必须先把 $a + y$ 算出来再拆位，这就是上面第 2、3 趟用 $t = a + y$ 而非分别用 $a$、$y$ 的原因。

## 第 7 页 — Problem 4：Pythagorean Quad

### Problem 4. [14 points] Pythagorean Quad（毕达哥拉斯四元组，1 小题）

> A **Pythagorean Quad** consists of four integers $(a, b, c, d)$ such that $d = \sqrt{a^2 + b^2 + c^2}$. Given an array $A$ containing $n$ distinct positive integers, describe an $O(n^2)$-time algorithm to determine whether four integers from $A$ form a Pythagorean Quad, where integers from $A$ may appear more than once in the Quad. State whether your running time is worst-case, expected, and/or amortized.
>
> （**Pythagorean Quad**（毕达哥拉斯四元组）由四个整数 $(a, b, c, d)$ 构成，满足 $d = \sqrt{a^2 + b^2 + c^2}$。给定含 $n$ 个互不相同正整数的数组 $A$，请给出一个 $O(n^2)$ 时间算法，判定 $A$ 中是否有四个整数能构成 Pythagorean Quad —— 注意 $A$ 中的整数在四元组里**可以重复出现**。请说明你的运行时间是 worst-case、expected 还是 amortized。）

> **文字层校订**：抽取串把根号与根号内容拆开了 —— `√` 单独一行在前（`p`/`P` 类私有码位），`a2+b2+c2` 在后且指数被压平（三个 `2` 的 baseline 136.79 相对主体上移）⇒ $d = \sqrt{a^2 + b^2 + c^2}$。渲染图复核一致。

**参考解答**：

把条件改写为「两个平方和相等」：

```math
d^2 = a^2 + b^2 + c^2 \iff \underbrace{d^2 - c^2}_{(c,d)} = \underbrace{a^2 + b^2}_{(a,b)}
```

于是：

1. 建 hash table $H$：对所有元素对 $(a, b) \in A \times A$（允许 $a = b$，因为四元组允许重复），把键 $a^2 + b^2$ 存入 $H$（值存一个代表对，如 $(a, b)$）。共 $O(n^2)$ 次插入。
2. 对所有元素对 $(c, d) \in A \times A$（$d \ge c$ 时可跳过），计算 $k = d^2 - c^2$；若 $k \ge 0$ 且 $k \in H$，则存在 $(a, b)$ 使 $a^2 + b^2 = d^2 - c^2$，即 $d^2 = a^2 + b^2 + c^2$ —— 找到 Quad，返回 True。

若两轮枚举都无命中，返回 False。

- 时间：两轮各 $O(n^2)$、每次 hash 查询期望 $O(1)$ ⇒ **expected $O(n^2)$**；
- 空间：hash table 存 $O(n^2)$ 个键 ⇒ $O(n^2)$。

**为什么「元素可重复」让问题变简单**：不需要区分「$a$ 与 $c$ 是否同一个下标」，只需要值集合里存在这样的四个值；枚举对子即可，不必检查下标互异。

**为什么不是 worst-case $O(n^2)$**：hash 查询最坏是 $O(n)$（全部碰撞）。想拿 worst-case 就得用平衡 BST（$O(n^2\lg n)$）或先排序（$O(n^2 \lg n)$）—— 那样就不再满足 $O(n^2)$ 了。所以本题的正确声明是 **expected**。

## 第 8 页 — Problem 5：Animal Counting

### Problem 5. [20 points] Animal Counting（动物计数，1 小题）

> PurpleRock Park is a wildlife reserve, divided into zones, where each zone has a park ranger who records current sightings of animals of different species over time. Old animal sightings are periodically removed from the database. A species $s$ is **common** if current park records contain at least 100 sightings of species $s$ within any single zone of the park.
>
> Describe a database to store animal sightings, supporting the following four operations, where $n$ is the number of sightings stored in the database at the time of the operation. State whether your running times are worst-case, expected, and/or amortized.
>
> （PurpleRock Park 是一处野生动物保护区，划分为若干 zone（区域），每个 zone 有护林员随时间记录各物种的动物目击。旧目击记录会被定期从数据库删除。若当前公园记录中某物种 $s$ 在**任意单个 zone 内**有至少 100 次目击，则称 $s$ 为 **common**（常见物种）。
>
> 请设计一个存储目击记录的数据库，支持以下四个操作，其中 $n$ 是操作执行时数据库中的目击记录数。请说明你的运行时间是 worst-case、expected 还是 amortized。）

| 操作 | 语义与要求 |
| --- | --- |
| `initialize()` | Initialize an empty database in $O(1)$ time（以 $O(1)$ 时间初始化空数据库） |
| `add sighting(s, i)` | Record a newest sighting of species $s$ in zone $i$ in $O(\log n)$ time（记录 $s$ 在 zone $i$ 的最新一次目击，$O(\log n)$ 时间） |
| `remove oldest()` | Remove the oldest sighting stored in the database in $O(\log n)$ time（删除数据库中最旧的目击记录，$O(\log n)$ 时间） |
| `is common(s)` | Return whether species $s$ is common based on sightings that have not yet been removed from the database in $O(1)$ time（基于尚未删除的目击记录，返回 $s$ 是否 common，$O(1)$ 时间） |

**参考解答**：

核心技巧：阈值是**常数 100**，所以每个 (species, zone) 对只需要记住「是否已经越过 100」，不必维护完整计数分布。

数据结构：

1. **时间轴**：所有 sighting 按插入顺序串成 doubly linked list，`head` 指向最旧的一条。每个 sighting 节点存 $(s, i)$ 并带直接指针。`remove oldest()` 删 `head`，$O(1)$ —— 满足 $O(\log n)$ 预算。
2. **计数表** `cnt[s][i]`：以 $(s, i)$ 为 key 的 balanced BST（AVL / Red-Black），值为该 (species, zone) 对现存目击数。查找 / 更新 $O(\log n)$ 最坏。
3. **common 计数器**：每个物种记一条记录，其中存整数 `cnt100`，表示该物种「计数 $\ge 100$」的 zone 个数。物种记录按物种 key 组织（与 `cnt` 共用一棵 balanced BST 的按物种分组子树，或另建一棵）。
4. `is common(s)`：$O(1)$ —— 物种先离散化为 $1..m$ 的下标（建表一次性 $O(n)$），于是直接读 `cnt100[s] > 0`。

各操作：

- `initialize()`：建空 list + 空 BST，$O(1)$。
- `add sighting(s, i)`：新建节点插入 list 尾部（$O(1)$）；`cnt[s][i] += 1`（$O(\log n)$）；若新值恰为 100，则 `cnt100[s] += 1`。
- `remove oldest()`：取 `head` 的 $(s, i)$；`cnt[s][i] -= 1`（$O(\log n)$）；若旧值恰为 100（即降到 99），则 `cnt100[s] -= 1`；从 list 删除该节点（$O(1)$）。
- `is common(s)`：`cnt100[s] > 0`，$O(1)$。

运行时间：**worst-case $O(\log n)$**（balanced BST），空间 $O(n)$。

> **为什么只需在 100 这条线上更新 `cnt100`**：`cnt100[s]` 只在某个 zone 的计数**跨越 100** 时改变 —— 从 99 加到 100、从 100 减到 99。中间的大幅波动（100→150→100）完全不影响「是否 $\ge 100$」。这正是「阈值是常数」带来的关键剪枝：把「精确计数」降级为「是否越过阈值」。
>
> **若想用 hash table 换取更快的常数**：`cnt` 用 hash table 则 add/remove 是 expected $O(1)$，但最坏 $O(n)$；题目给的是 $O(\log n)$ 预算，用 balanced BST 才拿到 worst-case 保证。

## 第 9 页 — Problem 6：Limited Connections

### Problem 6. [14 points] Limited Connections（受限连接，1 小题）

> For any weighted graph $G = (V, E, w)$ and integer $k$, define $G_k$ to be the graph that results from removing every edge in $G$ having weight $k$ or larger.
>
> Given a connected undirected weighted graph $G = (V, E, w)$, where every edge has a unique integer weight, describe an $O(|E| \log |E|)$-time algorithm to determine the largest value of $k$ such that $G_k$ is not connected.
>
> （对任意带权图 $G = (V, E, w)$ 与整数 $k$，定义 $G_k$ 为把 $G$ 中所有权重 $\ge k$ 的边删掉后得到的图。
>
> 给定连通的无向带权图 $G = (V, E, w)$，每条边的整数权重互不相同，请给出一个 $O(|E| \log |E|)$ 时间算法，求使 $G_k$ 不连通的最大的 $k$。）

> **文字层校订**：抽取串中 $G$ 后的 `k` 是下标（baseline 142.04 相对主体 138.9 下移）⇒ $G_k$，两处一致。

**参考解答**：

$G_k$ 保留的是权重 **$\lt k$** 的边（「删掉 $\ge k$」= 留下 $\lt k$）。所以 $G_k$ 不连通 $\iff$ 权重 $\lt k$ 的边不足以连通 $V$。

这正是 **Kruskal** 的停止条件。让 Kruskal 按权重升序依次加边，记下最后一条使图连通的边权 $w^{*}$（即 MST 的最大边权）。则：

- $k = w^{*}$：$G_{w^{*}}$ 保留权重 $\lt w^{*}$ 的边，恰好缺了这条桥边 ⇒ **不连通**；
- $k = w^{*} + 1$：$G_{w^{*}+1}$ 保留权重 $\lt w^{*}+1$，因权重是整数等价于保留 $\le w^{*}$，含整个 MST ⇒ **连通**。

所以答案是 $k = w^{*}$，即 **MST 的最大边权**。

```math
k^{*} = \max_{(u,v) \in \mathrm{MST}} w(u, v)
```

时间：排序 $O(|E|\lg|E|)$ + union-find 的 $O(|E| \alpha(|V|))$ ⇒ $O(|E| \log |E|)$。

> **端点验证**：取 $G$ 为三角形，边权 $1, 2, 3$。MST 取权 $1, 2$，于是 $w^{*} = 2$。$k=2$：保留权重 $\lt 2$ 的边，只有权 1，图是两段 ⇒ 不连通 ✓。$k=3$：保留权重 $\lt 3$，即权 $1, 2$，连通 ✓。答案 $k = 2$，与 MST 最大边权一致。
>
> **为什么「唯一权重」让题目变干净**：若有权重相同的边，$G_k$ 的连通性会在某个 $k$ 上跳变多步，而 Kruskal 取哪条同权边会影响「最后加入的那条」，答案的表述就要改用「使连通的最小 $k$」而非单条边的权重。

## 第 10 页 — Problem 7：On the Street

### Problem 7. [14 points] On the Street（街道问题，1 小题）

> Friends Dal and Sean want to take a car trip across the country from Yew Nork to Fan Sancrisco by driving between cities during the day, and staying at a hotel in some city each night. There are $n$ cities across the country. For each city $c_i$, Dal and Sean have compiled:
>
> - the positive integer expense $h(c_i)$ of staying at a hotel in city $c_i$ for one night; and
> - a list $L_i$ of the at most 10 other cities they could drive to in a single day starting from city $c_i$, along with the positive integer expense $g(c_i, c_j)$ required to drive directly from $c_i$ to $c_j$ for each $c_j \in L_i$.
>
> Describe an $O(nd)$-time algorithm to determine whether it is possible for Dal and Sean to drive from Yew Nork to Fan Sancrisco in at most $d$ days, spending at most $b$ on expenses along the way.
>
> （Dal 与 Sean 想开车横穿全国，从 Yew Nork 到 Fan Sancrisco：白天在城市之间开车，每晚在某城市住旅馆。全国有 $n$ 座城市。对每座城市 $c_i$，两人整理了：
>
> - 在城市 $c_i$ 住一晚的正整数旅馆费 $h(c_i)$；以及
> - 一张至多 10 项的列表 $L_i$，列出从 $c_i$ 出发一天内能开到的其他城市，并给出从 $c_i$ 直接开到 $c_j$ 的正整数油费 $g(c_i, c_j)$，对每个 $c_j \in L_i$。
>
> 请给出一个 $O(nd)$ 时间算法，判定 Dal 与 Sean 能否在**至多 $d$ 天**内从 Yew Nork 开到 Fan Sancrisco，且沿途花费**至多 $b$**。）

**参考解答**：

按天分层做 DP —— 把「天数」作为状态的一维，本质是在分层图（layered graph）上求最短路。

记 $c_0$ 为 Yew Nork、$c_{*}$ 为 Fan Sancrisco。把花费拆成「油费」与「店费」两部分，店费只在**非终点的夜晚**发生。定义

```math
D[t][c] = \text{用 } t \text{ 天从 } c_0 \text{ 到 } c\text{、且当晚住在 } c \text{（已付 } h(c)\text{）的最小总花费}
```

初始（第 1 天从 $c_0$ 直接开到的城市）：

```math
D[1][c] = g(c_0, c) + h(c)\ (c \ne c_{*}), \qquad D[1][c_{*}] = g(c_0, c_{*})
```

转移（第 $t+1$ 天从 $c$ 开到 $c_j$，且 $c_j$ 不是终点）：

```math
D[t+1][c_j] = h(c_j) + \min_{c \,:\, c_j \in L(c)}\left(D[t][c] + g(c, c_j)\right)
```

到达终点的那一天不再付店费，单独记录：

```math
\mathrm{arr}[t+1] = \min_{c \,:\, c_{*} \in L(c)}\left(D[t][c] + g(c, c_{*})\right)
```

答案：存在 $t+1 \le d$ 使 $\mathrm{arr}[t+1] \le b$ ⇒ YES，否则 NO。起点即终点的退化情形另行处理（$0$ 天、花费 $0$）。

复杂度：每天对每个城市展开其至多 10 条出边 ⇒ 每层 $O(10n)$；共 $d$ 层 ⇒

```math
O(d \cdot n \cdot 10) = O(nd)
```

空间 $O(n)$（只保留上一天的 $D$）。

> **为什么「至多 d 天」要枚举所有 $t \le d$ 而不是只看 $t = d$**：早到就没有更多花费，最优解不会停在中间城市白等（除非住店能省油费 —— 但所有费用为正，白等只会增加 $h$）。所以取 $\min_{1 \le t \le d} \mathrm{arr}[t]$，或等价的「$\exists t \le d$」判定。

## 第 11 页 — Problem 8：RGB Graph

### Problem 8. [18 points] RGB Graph（RGB 图，1 小题）

> Let $G = (V, E, w)$ be a weighted directed graph. Let $c : V \to \{r, g, b\}$ be an assignment of each vertex $v$ to a **color** $c(v)$, representing red, green, or blue respectively. For $x \in \{r, g, b\}$,
>
> - let $V_x$ be the set of vertices with color $x$, i.e., $V_x = \{v \in V \mid c(v) = x\}$; and
> - let $E_x$ be the set of edges outgoing from vertices in $V_x$, i.e., $E_x = \{(u, v) \in E \mid u \in V_x\}$.
>
> Suppose graph $G$ and coloring $c$ have the following properties:
>
> 1. Every edge in $E$ either connects two vertices of the same color, goes from a red vertex to a green vertex, or goes from a green vertex to a blue vertex.
> 2. $|V_r| = |E_r| = O(|V|)$, and edges in $E_r$ have identical positive integer weight $w_r$.
> 3. $|V_g| = |E_g| = O(|V|^{0.99})$, and edges in $E_g$ have nonnegative integer weights.
> 4. $|V_b| = |E_b| = O(\sqrt{|V|})$, and edges in $E_b$ can have positive or negative integer weights.
>
> Given $G$, $c$, a red vertex $s \in V_r$, and a blue vertex $t \in V_b$, describe an $O(|V|)$-time algorithm to compute $\delta(s, t)$, the minimum weight of any path from $s$ to $t$.
>
> （设 $G = (V, E, w)$ 是带权有向图。设 $c : V \to \{r, g, b\}$ 把每个顶点 $v$ 指派给一个**颜色** $c(v)$，分别表示红、绿、蓝。对 $x \in \{r, g, b\}$，
>
> - 记 $V_x$ 为颜色为 $x$ 的顶点集，即 $V_x = \{v \in V \mid c(v) = x\}$；以及
> - 记 $E_x$ 为从 $V_x$ 中顶点出发的边集，即 $E_x = \{(u, v) \in E \mid u \in V_x\}$。
>
> 设图 $G$ 与着色 $c$ 具有以下性质：
>
> 1. $E$ 中每条边要么连接同色的两个顶点，要么从红顶点指向绿顶点，要么从绿顶点指向蓝顶点。
> 2. $|V_r| = |E_r| = O(|V|)$，且 $E_r$ 中边具有相同的正整数权重 $w_r$。
> 3. $|V_g| = |E_g| = O(|V|^{0.99})$，且 $E_g$ 中边具有非负整数权重。
> 4. $|V_b| = |E_b| = O(\sqrt{|V|})$，且 $E_b$ 中边可以具有正或负整数权重。
>
> 给定 $G$、$c$、一个红顶点 $s \in V_r$ 与一个蓝顶点 $t \in V_b$，请给出一个 $O(|V|)$ 时间算法计算 $\delta(s, t)$，即从 $s$ 到 $t$ 的任一路径的最小权重。）

> **文字层校订**：抽取串里三处压平 —— `|V|0.99` 的 `0.99` 字号 7.97pt、baseline 287.34 相对主体 289.83 上移 ⇒ $|V|^{0.99}$；`O(p |V|)` 的 `p` 是根号的私有码位（CMEX10），与根号内容脱离 ⇒ $O(\sqrt{|V|})$；各处 `r` `g` `b` `x` 后缀的 baseline 均下移 4.8pt ⇒ **下标**（$V_r, E_r$ 等），不是上标。

**参考解答**：

性质 1 给出一条硬约束：跨色边只能 **红 → 绿 → 蓝**，不能反向、不能跳级（红不能直接到蓝）。因此任何 $s \to t$ 路径的颜色序列是

```math
\underbrace{r \cdots r}_{\text{红段}} \to \underbrace{g \cdots g}_{\text{绿段}} \to \underbrace{b \cdots b}_{\text{蓝段}}
```

路径在颜色上是**分层**的，跨色只发生两次。据此分三段求：

1. **红段**：红边权全为同一个 $w_r > 0$，所以红子图内的最短路 $= w_r \times$（BFS 层数）。从 $s$ 做一次 BFS，得所有红顶点的距离：

```math
O(|V_r| + |E_r|) = O(|V|)
```

2. **绿段**：绿边权非负 ⇒ 用 Dijkstra。初始把每个红顶点按其红段距离入队（含跨红→绿的边松弛）：$V_g$ 与 $E_g$ 都是 $O(|V|^{0.99})$，故

```math
O\left(|E_g| + |V_g| \lg |V_g|\right) = O(|V|^{0.99} \lg |V|) = o(|V|)
```

3. **蓝段**：蓝边可负 ⇒ 必须用 Bellman-Ford。因为蓝段之后不会再回到绿/红（性质 1 禁止逆序），可在蓝色子图上独立跑 BF，蓝顶点的初始距离来自绿段：$V_b, E_b$ 都是 $O(\sqrt{|V|})$，BF 是 $O(|V_b||E_b|)$：

```math
O\left(\sqrt{|V|} \cdot \sqrt{|V|}\right) = O(|V|)
```

三段相加：$O(|V|) + o(|V|) + O(|V|) = O(|V|)$。最后 $\delta(s, t)$ 取蓝段里 $t$ 的距离。

正确性要点：由于颜色分层，任何 $s\to t$ 路径都可唯一拆成「红段 + 绿段 + 蓝段」；每段内部的最短路只会用到本段颜色的边（跨色边只在段界处使用），所以三段各自独立求解后拼接即为全局最优 —— 不满足最优子结构的情形在性质 1 下已被排除。

> **本题的设计意图**：把「负权」限制在 $O(\sqrt{|V|})$ 个顶点上是整个构造的核心。Bellman-Ford 的代价是 $|V|\cdot|E|$，一旦顶点数降到 $\sqrt{|V|}$，它就退化成 $O(|V|)$；而无负权的两层分别用 BFS 和 Dijkstra，各自都被 $O(|V|)$ 预算覆盖。

## 第 12 页 — Problem 9：Separated Subsets

### Problem 9. [16 points] Separated Subsets（分离子集，1 小题）

> For any set $S$ of integers and for any positive integers $m$ and $k$, an $(m, k)$-**separated subset** of $S$ is any subset $S' \subseteq S$ such that $S'$ sums to $m$ and every pair of distinct integers $a, b \in S'$ satisfies $|a - b| \ge k$. Given positive integers $m$ and $k$, and a set $S$ containing $n$ distinct positive integers, describe an $O(n^2 m)$-time algorithm to count the number of $(m, k)$-separated subsets of $S$. (When solving this problem, you may assume that a single machine word is large enough to hold any integer computed during your algorithm.)
>
> （对任意整数集合 $S$ 与任意正整数 $m$、$k$，$S$ 的 $(m, k)$-**separated subset**（分离子集）是指任意子集 $S' \subseteq S$，满足 $S'$ 的元素和为 $m$，且 $S'$ 中任意两个不同整数 $a, b$ 满足 $|a - b| \ge k$。给定正整数 $m$、$k$，以及含 $n$ 个互不相同正整数的集合 $S$，请给出一个 $O(n^2 m)$ 时间算法，计数 $S$ 的 $(m,k)$-separated subset 个数。（解题时可假设单个机器字足够大，能容纳算法中计算的任何整数。））

> **文字层校订**：抽取串里的 `S0` 是 $S'$（撇号被识别成 `0`，`0` 的 baseline 下移）⇒ $S'$；`O(n2m)` 的 `2` baseline 上移 ⇒ $O(n^2 m)$。

**参考解答**：

先排序：设 $S$ 排序后为 $a_1 \lt a_2 \lt \cdots \lt a_n$（这消灭了「无序对」的重复计数）。

DP 状态：$f[i][s]$ = 以 $a_i$ 为**最大元素**、元素和恰为 $s$ 的 $(m,k)$-separated 子集个数。

转移：若 $a_i$ 是子集的最大元素，则前一个被选元素 $a_j$ 必须满足 $a_i - a_j \ge k$（因为已排序，$a_j \lt a_i$）：

```math
f[i][s] = \left[\, a_i = s \,\right] + \sum_{j : a_j \le a_i - k} f[j][\,s - a_i\,]
```

其中 $[\,a_i = s\,]$ 是单位子集 $\{a_i\}$（不选前驱）。

答案：

```math
\sum_{i=1}^{n} f[i][m]
```

复杂度：状态 $O(nm)$；朴素转移对每个状态枚举 $O(n)$ 个 $j$ ⇒ $O(n^2 m)$，正好达标。

**优化（可选，降到 $O(nm)$）**：因为 $a$ 已排序，满足 $a_j \le a_i - k$ 的 $j$ 是一个前缀 $j \le p(i)$，用二分 $O(\lg n)$ 求出 $p(i)$；再对每个 $s$ 维护前缀和 $P[i][s] = \sum_{j \le i} f[j][s]$，则

```math
f[i][s] = \left[\, a_i = s \,\right] + P[\,p(i)\,][\,s - a_i\,]
```

每次 $O(1)$，总计 $O(nm)$。

> **为什么排序是必须的**：不排序时「$a_i$ 是最大元素」无从定义，同一个子集会被按不同顺序重复计数。排序把「子集」变成「递增序列」，每个子集恰有一种递增表示。
>
> **为什么 $m$ 出现在复杂度里而不是 $\lg m$**：这是**伪多项式**算法 —— 依赖的是目标和的数值大小 $m$ 而非其位数。Subset Sum 的经典 DP 正是这一形式，本题只是多了一个 $|a - b| \ge k$ 的间隔约束。

## 第 13 页 — Problem 10：A Feast for Crowns

### Problem 10. [18 points] A Feast for Crowns（王冠盛宴，1 小题）

> Ted Snark is arranging a feast for the Queen of Southeros and her guests, and has been tasked with seating them along one side of a long banquet table.
>
> - Ted has a list of the $2n$ guests, where each guest $i$ has a known distinct positive integer $f_i$ denoting the guest's favor with the Queen.
> - Ted must seat the guests respectfully: the Queen must be seated in the center with $n$ guests on either side so that guests' favor monotonically decreases away from the Queen, i.e., any guest seated between a guest $i$ and the Queen must have favor larger than $f_i$.
> - Additionally, every guest hates every other guest: for every two guests $i, j$, Ted knows the positive integer mutual hatred $d(i, j) = d(j, i)$ between them.
>
> Given Ted's guest information, describe an $O(n^3)$-time algorithm to determine a respectful seating order that minimizes the sum of mutual hatred between pairs of guests seated next to each other. Significant partial credit will be awarded to correct $O(n^4)$-time algorithms.
>
> （Ted Snark 在为 Southeros 女王及其宾客筹办盛宴，任务是把他们安排在一条长宴桌的一侧就座。
>
> - Ted 有 $2n$ 位宾客的名单，每位宾客 $i$ 有一个已知的、互不相同的正整数 $f_i$，表示该宾客受女王宠爱的程度。
> - Ted 必须**恭敬地**安排就座：女王坐在正中，两侧各 $n$ 位宾客，且宾客的宠爱程度**自女王向外单调递减** —— 即任何坐在宾客 $i$ 与女王之间的宾客，其宠爱度必须大于 $f_i$。
> - 此外，每位宾客都憎恨其他所有宾客：对任意两位宾客 $i, j$，Ted 知道他们之间互为正整数的憎恨度 $d(i, j) = d(j, i)$。
>
> 给定 Ted 掌握的信息，请给出一个 $O(n^3)$ 时间算法，找出一个恭敬的座次，使**相邻就座宾客对的憎恨度之和**最小。正确的 $O(n^4)$ 算法可得可观的步骤分。）

**参考解答**：

按宠爱度降序把宾客重排为 $g_1, g_2, \dots, g_{2n}$（$f_{g_1} \gt f_{g_2} \gt \cdots \gt f_{g_{2n}}$）。核心结构事实：

> 若按 $g_1, g_2, \dots$ 的顺序依次入座，则前 $i$ 个入座者必然占据女王左右两侧**紧邻的一段连续座位**。理由：「自女王向外单调递减」要求每侧都是递减序列；$g_i$ 是当前最小者，若把它放到某侧的外端之外还有已入座者，则它到女王之间会存在比它宠爱度更小的宾客 —— 矛盾。所以它只能放到某一侧的最外端。

于是座次等价于一个「每人放左还是放右」的序列。DP 需要记住的只有两侧的**最外端是谁** —— 因为新放的人只与最外端发生一对新的相邻关系。

关键剪枝：$g_1, \dots, g_i$ 全部放好时，$g_i$（最后放的那个）必然是某一侧的最外端。所以二维就够。定义两个表：

```math
A[i][j] = \text{已放 } g_1..g_i \text{、左端为 } g_j \text{、右端为 } g_i \text{（最后放在右侧）的最小憎恨和}
```

```math
B[i][k] = \text{已放 } g_1..g_i \text{、左端为 } g_i \text{、右端为 } g_k \text{（最后放在左侧）的最小憎恨和}
```

下标 $0$ 表示该侧还没有人：此时新放者紧邻女王，而女王不是宾客、相邻对只在宾客之间计憎恨，故代价为 $0$。

转移（把 $g_{i+1}$ 放到某一侧的外端，四项取 $\min$）：

- 由 $A[i][j]$ 放右（与右端 $g_i$ 相邻）：$A[i+1][j] \gets \min\bigl(A[i+1][j],\ A[i][j] + d(g_{i+1}, g_i)\bigr)$；
- 由 $A[i][j]$ 放左（与左端 $g_j$ 相邻）：$B[i+1][i] \gets \min\bigl(B[i+1][i],\ A[i][j] + d(g_{i+1}, g_j)\bigr)$，$j = 0$ 时代价取 $0$；
- 由 $B[i][k]$ 放左（与左端 $g_i$ 相邻）：$B[i+1][k] \gets \min\bigl(B[i+1][k],\ B[i][k] + d(g_{i+1}, g_i)\bigr)$；
- 由 $B[i][k]$ 放右（与右端 $g_k$ 相邻）：$A[i+1][i] \gets \min\bigl(A[i+1][i],\ B[i][k] + d(g_{i+1}, g_k)\bigr)$，$k = 0$ 时代价取 $0$。

初始 $A[1][0] = B[1][0] = 0$（$g_1$ 单独坐在某一侧、紧邻女王，此时还没有任何相邻的宾客对）。答案：

```math
\min\left(\min_{j \le 2n} A[2n][j],\ \min_{k \le 2n} B[2n][k]\right)
```

复杂度：$A$、$B$ 各有 $O(n^2)$ 个状态（$i \le 2n$，另一端编号 $\le i$），每个状态 $O(1)$ 转移 ⇒ **$O(n^2)$ 时间、$O(n^2)$ 空间**（滚动数组可降到 $O(n)$）。这已经优于题目要求的 $O(n^3)$。

> **为什么这个 DP 能覆盖所有可行座次**：任取一个可行座次，把宾客按宠爱度降序逐个「剥掉」—— 每步剥掉的那个必是当前剩余里的最小者，而它必定在某侧最外端（否则它到女王之间会有宠爱度更小的宾客，违反单调递减）。所以「从大到小逐个放到某一侧外端」是可逆的一一对应，DP 的搜索空间恰好是全部恭敬座次。
