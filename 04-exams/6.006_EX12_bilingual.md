## 一、范围与复习框架（Scope & Recursive Framework）

**原文概述：**

- Quiz 1 与 Quiz 2 的内容仍然算数，但明确**不作为重点**（fair game but explicitly not emphasized）。
- 重点为 4 讲动态规划（Dynamic Programming, DP）：L15–L18，对应 2 个 Problem Set（PS7–PS8）。
- 递归框架（Recursive Framework）：SRTBOT。
- DP 核心思想：子问题依赖（subproblem dependencies）相互重叠（overlap），构成一个有向无环图（DAG，Directed Acyclic Graph）。

### 递归框架 SRTBOT（六步法）

**1. Subproblem definition（子问题定义）**
- 用参数 $x \in X$ 的语言描述子问题的含义。
- 常见子集形态：前缀（prefix）、后缀（suffix）、序列的连续子串（contiguous substring）。
- 常常在多个输入上取多重可能的子集。
- 常常通过维护辅助状态（auxiliary state，即 expansion，扩展）来“记住”信息。
- 常常根据问题空间中整数的状态进行扩展（可能对应伪多项式 pseudopolynomial）。

**2. Relate recursively（递归关联）**
- 递归地把子问题解关联起来：$x(i) = f(x(j), \dots)$，其中若干个 $j < i$。
- 找出一个关于子问题解的“问题”，其答案能让你归约（reduce）到更小的子问题；然后在局部枚举（brute-force）该问题的所有可能答案。

**3. Topological order（拓扑序）**
- 论证该关联关系是无环的（acyclic），即它定义了“更小”的子问题，所有子问题构成 DAG。

**4. Base cases（基本情况）**
- 对关联关系失效的所有（可达的）独立子问题，直接给出解。

**5. Original problem（原问题）**
- 展示如何由子问题的解算出原问题的解。
- 可能需要用父指针（parent pointers）恢复实际解，而不仅是目标函数值。

**6. Time analysis（时间分析）**
- 总时间为 $\sum_{x \in X} \text{work}(x)$；若对任意 $x \in X$ 有 $\text{work}(x) = O(W)$，则总时间为 $|X| \cdot O(W)$。
- 其中 $\text{work}(x)$ 衡量关联式中**非递归**的工作量；递归调用本身按 $O(1)$ 时间处理。

## 二、Problem 1. Future Investing（未来投资）

> 改编自 S18 PS9。

### 题目

Tiffany Bannen 捡到一张来自未来的时间旅行者掉落的彩票图（lottery chart），上面列出了未来 $n$ 天每天的中奖号码和正整数的现金派彩（cash payout）。她想利用这些信息赚钱，但担心如果每天玩中奖号码，彩票主办方（lottery organizers）会起疑。于是她决定**低频**地玩彩票：**在任意七天的时间窗口内至多玩两次**。

请描述一个 $O(n)$ 时间的算法，确定 Tiffany 在未来 $n$ 天内通过低频玩彩票能获得的最大中奖金额。

### 解答

**核心思路：带约束的子序列选择问题，可用滑动窗口（sliding window）+ DP 解决。**

设第 $i$ 天的派彩为 $a_i$（正整数，$1 \le i \le n$）。约束是：任意连续 $7$ 天窗口内，选择的天数 $\le 2$。

这个约束等价于：**任意两个被选中天数之间至少相隔 $3$ 天**（即在时间轴上，若第 $i$ 天和第 $j$ 天都被选中且 $i < j$，则必须 $j - i \ge 3$，否则一个 7 天窗口内会出现超过 2 次选择）。

> 论证：考虑任意连续 7 天窗口。若选中了 3 个日子 $i < j < k$ 且 $k - i \le 6$，则违反约束。最紧的情形是 $j - i = 3$、$k - j = 3$ 时 $k - i = 6$，恰好仍在 7 天窗口内，仍违反。因此每两个相邻选中日之间距离必须 $\ge 4$，即 $j - i \ge 4$ 时，任何长度为 7 的窗口内至多含 2 个选中日。

> 精确等价关系：约束“任意 7 天窗口内至多 2 次”$\iff$“任意相邻两次选中间隔至少 4 天”。（因为若间隔 $\le 3$，则窗口 $[i, i+6]$ 内会含 3 次及以上。）

**DP 定义：**

令 $\text{dp}[i]$ = 在前 $i$ 天内（第 $1\dots i$ 天）能获得的最大派彩，且第 $i$ 天为最后一个被选中的日子（或前 $i$ 天的最优值）。

状态转移（选与不选第 $i$ 天）：

- **不选第 $i$ 天**：$\text{dp}[i] = \text{dp}[i-1]$。
- **选第 $i$ 天**：上一个选中日必须是 $i-4$ 天或更早，即 $\text{dp}[i] = a_i + \max_{j \le i-4} \text{dp}[j]$。

因此：

```math
\text{dp}[i] = \max\left(\text{dp}[i-1],\ a_i + \max_{j \le i-4}\text{dp}[j]\right)
```

初始条件：$\text{dp}[i] = a_i$（当 $i \le 4$ 时，前面无法再选，只能选自身或更早的）。

直接枚举 $j$ 会得到 $O(n^2)$。为达到 $O(n)$，维护一个前缀最大值（prefix maximum）：

```math
\text{pref}[i] = \max_{1 \le j \le i} \text{dp}[j]
```

于是转移变为：

```math
\text{dp}[i] = \max\left(\text{dp}[i-1],\ a_i + \text{pref}[i-4]\right)
```

其中 $\text{pref}[i-4] = 0$（当 $i \le 4$ 时，即 $i-4 \le 0$）。

**伪代码：**

```text
FutureInvest(a[1..n]):
    pref[0..n] = 0        // pref[i] = max_{1..i} dp
    dp[1..n] = 0

    for i = 1 to n:
        if i <= 4:
            best_prev = 0        // 前面没有可选的前一天
        else:
            best_prev = pref[i - 4]
        dp[i] = max(dp[i-1], a[i] + best_prev)
        pref[i] = max(pref[i-1], dp[i])

    return dp[n]           // 或 pref[n]
```

**复杂度分析：**

每个 $i$ 只做 $O(1)$ 次比较与赋值，共 $n$ 次迭代，因此时间复杂度为 $\Theta(n)$，空间复杂度为 $\Theta(n)$（可用滚动变量优化到 $O(1)$ 额外空间，因为只依赖 $i-1$ 与 $i-4$ 两处）。

## 三、Problem 2. Oh Charlie, Where Art Thou?（查理何在）

> 改编自 S18 PS9。

### 题目

富裕的一家三口 Alice、Bob 和幼子 Charlie 环游世界时遭遇暴风雨，Charlie 落水失踪，被认为溺亡。二十年后，一个男人找到 Alice 和 Bob 自称是 Charlie。夫妇二人既激动又怀疑，于是向基因检测公司 46AndThee 订购 DNA 匹配测试。给定三条长度为 $n$ 的 DNA 序列（分别来自 Alice、Bob、Charlie），检测中心按如下方式判定血缘：**若 Charlie 的 DNA 能被划分（partition）成两个等长的子序列（subsequence，不必连续），其中一个子序列是 Alice 的 DNA 的子序列，另一个是 Bob 的 DNA 的子序列，则判定 Charlie 是他们的儿子。**

例如：Alice 的 DNA 为 `AATT`，Bob 的为 `CCGG`。若 Charlie 的 DNA 是 `CATG`，则匹配成功——`CATG` 可划分为互不相交的子序列 `CG` 与 `AT`，分别对应 Alice 与 Bob 的子序列。但若 Charlie 的 DNA 是 `AGTC`，则判定为冒名者（imposter）。

请描述一个 $O(n^4)$ 时间的算法，判断 Charlie 是否是冒名者（fraud）。

### 解答

**核心思路：判断 Charlie 是否可拆成两个等长子序列，分别与 Alice、Bob 的某两个子序列匹配。这是一个三维 LCS（最长公共子序列）类的 DP。**

设三序列：Alice $A = a_1 \dots a_n$，Bob $B = b_1 \dots b_n$，Charlie $C = c_1 \dots c_n$。

Charlie 是儿子 $\iff$ 存在一个分割，把 $C$ 分成两个**不相交、各自保持原相对顺序**的子序列 $C_1, C_2$，满足 $|C_1| = |C_2|$，且 $C_1$ 是 $A$ 的子序列、$C_2$ 是 $B$ 的子序列。

等价地，可以这样理解：把 $C$ 的每个字符依次“指派”给 Alice 一侧或 Bob 一侧，要求 Alice 侧选出的字符整体上构成 $A$ 的一个子序列，Bob 侧构成 $B$ 的一个子序列，且两侧选出的字符数相等（都等于 $\tfrac{|C|}{2}$，故 $|C|$ 必须为偶数）。

**DP 定义：**

令 $\text{dp}[i][j][k]$ 为一个布尔值，表示：

> 考虑 $A$ 的前 $i$ 个字符、$B$ 的前 $j$ 个字符、$C$ 的前 $k$ 个字符，是否存在一种指派方式，使得 $C$ 的前 $k$ 个字符被分成 Alice 侧与 Bob 侧两部分，分别成为 $A[1..i]$ 与 $B[1..j]$ 的子序列，并且**两侧长度之差**（Alice 侧减去 Bob 侧）恰好为某个固定值。

为处理“两侧等长”约束，需要把“Alice 侧字符数 $-$ Bob 侧字符数”这个差值也编码进状态。定义四维 DP：

```math
\text{dp}[i][j][k][d]
```

其中 $d = (\text{Alice 侧已用字符数}) - (\text{Bob 侧已用字符数})$，$d$ 的范围为 $[-n, n]$。

$\text{dp}[i][j][k][d] = \text{true}$ 表示：前 $i$ 个 $A$ 字符、前 $j$ 个 $B$ 字符、前 $k$ 个 $C$ 字符下，能够达到差值 $d$。

**状态转移（考虑第 $k$ 个 Charlie 字符 $c_k$ 的三种去向）：**

1. **赋给 Alice 侧**：需要 $c_k$ 匹配 $A$ 的某个字符 $a_i$（即 $c_k = a_i$），则
   $\text{dp}[i][j][k][d] \leftarrow \text{dp}[i-1][j][k-1][d-1]$。
2. **赋给 Bob 侧**：需要 $c_k = b_j$，则
   $\text{dp}[i][j][k][d] \leftarrow \text{dp}[i][j-1][k-1][d+1]$。
3. **跳过 $A$ 的一个字符**：$\text{dp}[i][j][k][d] \leftarrow \text{dp}[i-1][j][k][d]$。
4. **跳过 $B$ 的一个字符**：$\text{dp}[i][j][k][d] \leftarrow \text{dp}[i][j-1][k][d]$。

初始：$\text{dp}[0][0][0][0] = \text{true}$。

最终答案：Charlie 是儿子 $\iff$ $\text{dp}[n][n][n][0] = \text{true}$。

**伪代码：**

```text
IsSon(A[1..n], B[1..n], C[1..n]):
    if n is odd:
        return false          // |C| = n 必须为偶数才能等分

    dp[0..n][0..n][0..n][-n..n] = false
    dp[0][0][0][0] = true

    for i = 0 to n:
        for j = 0 to n:
            for k = 0 to n:
                for d = -n to n:
                    if not dp[i][j][k][d]:
                        continue
                    // 传播到更大的状态
                    if i < n:
                        dp[i+1][j][k][d] = true          // 跳过 A 字符
                    if j < n:
                        dp[i][j+1][k][d] = true          // 跳过 B 字符
                    if k < n and i < n and C[k+1] == A[i+1]:
                        dp[i+1][j][k+1][d+1] = true      // 赋给 Alice 侧
                    if k < n and j < n and C[k+1] == B[j+1]:
                        dp[i][j+1][k+1][d-1] = true      // 赋给 Bob 侧

    return dp[n][n][n][0]
```

（注：上述“跳过”传播配合“匹配赋值”能正确覆盖“子序列”语义——子序列允许跳过父序列中任意字符，但两侧各字符的相对顺序必须保持。）

**复杂度分析：**

状态数为 $(n+1)^3 \times (2n+1) = O(n^4)$，每个状态做 $O(1)$ 次转移。因此时间复杂度为 $\Theta(n^4)$，空间复杂度也为 $\Theta(n^4)$（可滚动 $k$ 维优化空间，但本题只要求时间 $O(n^4)$）。

> 补充：这本质上是判断两个 LCS 能否“同时”覆盖 $C$ 且等分。若不要求等长，可退化为三维 DP；等长约束引入了差值维 $d$，从而升到四维。

## 四、Problem 3. Sweet Tapas（甜蜜小食）

> 改编自 S18 Final。

### 题目

Obert Ratkins 在一家高档西班牙小食酒吧（tapas bar）用餐，要点很多小盘菜。菜单上有 $n$ 盘食物，第 $i$ 盘的信息由三元组非负整数 $(v_i, c_i, s_i)$ 给出：体积 $v_i$、卡路里 $c_i$、甜度 $s_i \in \{0,1\}$（$s_i = 1$ 表示甜，$s_i = 0$ 表示不甜）。Obert 在节食：一餐摄入不超过 $k$ 卡路里，但想尽量填饱肚子。同时他要点**恰好 $s < n$ 盘甜食**，且同一道菜不能点两次。

请描述一个 $O(nks)$ 时间的算法，求出 Obert 在节食约束下能吃的最大食物体积。

### 解答

**核心思路：带双重约束（卡路里上限 $k$ + 恰好 $s$ 盘甜食）的 0/1 背包（Knapsack）变体。**

每个盘子是 0/1 决策：选或不选。两个约束维度：

1. 总卡路里 $\le k$（容量维）。
2. 甜食数量恰好 $= s$（计数维）。

目标：最大化总体积 $\sum v_i$。

**DP 定义：**

令 $\text{dp}[i][c][t]$ = 考虑前 $i$ 个盘子（$i = 0 \dots n$），在总卡路里不超过 $c$（$c = 0 \dots k$）、甜食数量恰好为 $t$（$t = 0 \dots s$）的前提下，能获得的最大总体积。

**状态转移（对第 $i$ 个盘子选/不选）：**

- **不选**：$\text{dp}[i][c][t] = \text{dp}[i-1][c][t]$。
- **选**（需 $c \ge c_i$ 且 $t \ge s_i$，因为选甜食会占用一个甜食名额）：
  $\text{dp}[i][c][t] = \max(\dots,\ \text{dp}[i-1][c - c_i][t - s_i] + v_i)$。

综上：

```math
\text{dp}[i][c][t] = \max\Big(\text{dp}[i-1][c][t],\ \text{dp}[i-1][c-c_i][t-s_i] + v_i\Big)
```

初始：$\text{dp}[0][c][0] = 0$（对所有 $c$），其余 $t \ne 0$ 的状态为 $-\infty$（表示“恰好 $t$ 盘甜食”尚不可达）。

答案：$\text{dp}[n][k][s]$。

**伪代码：**

```text
SweetTapas(plates[1..n], k, s):
    // plates[i] = (v_i, c_i, s_i)
    dp[0..n][0..k][0..s] = -infinity
    for c = 0 to k:
        dp[0][c][0] = 0

    for i = 1 to n:
        (v, c, sweet) = plates[i]
        for cap = 0 to k:
            for t = 0 to s:
                best = dp[i-1][cap][t]          // 不选第 i 盘
                if cap >= c and t >= sweet:
                    best = max(best, dp[i-1][cap - c][t - sweet] + v)
                dp[i][cap][t] = best

    return dp[n][k][s]
```

（可滚动第一维 $i$ 以节省空间；容量维与甜食维需反向遍历以避免同一盘被重复使用。）

**复杂度分析：**

状态数为 $(n+1)(k+1)(s+1) = O(nks)$，每个状态 $O(1)$ 次转移，故时间复杂度 $\Theta(nks)$。这是伪多项式（pseudopolynomial）时间，因为 $k$ 以数值而非位长衡量。

## 五、Problem 4. Gokemon Po（宝可梦·Go）

> 改编自 S18 Final。

### 题目

Kash Etchum 想玩一款新的增强现实游戏（augmented reality game）Gokemon Po。目标是在她的城镇里捕获（catch）$n$ 只怪兽，它们居住在特定位置。怪兽必须按特定顺序获得：在获得怪兽 $m_i$ 之前，必须先已获得所有怪兽 $m_j$（$j < i$）。要获得怪兽 $m_i$，Kash 既可以花正整数 $c_i$ 美元在游戏内直接购买，也可以免费地从该怪兽的位置捕获。若她不在怪兽的位置，就必须付钱叫网约车（ride share）载她过去。从怪兽 $m_i$ 的位置到怪兽 $m_j$ 的位置，网约车的最小可能费用记为正整数 $s(i, j)$。

给定游戏内购买价格与所有怪兽两两之间的网约车费用表，请描述一个 $O(n^2)$ 时间的算法，确定 Kash 捕获全部 $n$ 只怪兽所需的最小花费，假设她从怪兽 $m_1$ 的位置出发。

### 解答

**核心思路：按顺序遍历怪兽，DP 状态记录“当前身处哪只怪兽的位置”，在“购买”与“乘车去捕获”两种获取方式之间取最小。**

由于怪兽必须按 $1, 2, \dots, n$ 的顺序获得，我们只需按 $i = 1 \dots n$ 依次决定如何获得 $m_i$。

**关键观察**：获得 $m_i$ 时，Kash 的“当前物理位置”一定停留在某只已获得的怪兽 $m_j$（$j \le i$）的位置。获得 $m_{i+1}$ 时有两种方式：

1. **购买**：花 $c_{i+1}$，位置不变（仍停在 $m_j$ 处）。
2. **乘车去捕获**：花 $s(j, i+1)$ 从当前 $m_j$ 位置乘车到 $m_{i+1}$ 位置，然后免费捕获，位置变为 $m_{i+1}$。

**DP 定义：**

令 $\text{dp}[i][j]$ = 已按顺序获得前 $i$ 只怪兽（$m_1 \dots m_i$），且当前身处怪兽 $m_j$ 的位置（$1 \le j \le i$）时的最小花费。

初始：$\text{dp}[1][1] = 0$（她已从 $m_1$ 位置出发，$m_1$ 视为已获得，费用 0）。其余为 $+\infty$。

**状态转移（由 $i \to i+1$）：**

考虑已获得前 $i$ 只、身处 $m_j$（$j \le i$）的状态，去获得 $m_{i+1}$：

1. **购买 $m_{i+1}$**：花 $c_{i+1}$，位置仍为 $m_j$：
   ```math
   \text{dp}[i+1][j] = \min\big(\text{dp}[i+1][j],\ \text{dp}[i][j] + c_{i+1}\big)
   ```
2. **乘车去捕获 $m_{i+1}$**：花 $s(j, i+1)$，位置变为 $m_{i+1}$：
   ```math
   \text{dp}[i+1][i+1] = \min\big(\text{dp}[i+1][i+1],\ \text{dp}[i][j] + s(j, i+1)\big)
   ```

最终答案：$\min_{1 \le j \le n} \text{dp}[n][j]$。

**伪代码：**

```text
GokemonPo(n, c[1..n], s[1..n][1..n]):
    dp[1..n][1..n] = +infinity
    dp[1][1] = 0

    for i = 1 to n-1:
        for j = 1 to i:
            // 方式 1：购买 m_{i+1}，位置不变
            dp[i+1][j] = min(dp[i+1][j], dp[i][j] + c[i+1])
            // 方式 2：乘车去 m_{i+1} 位置并免费捕获
            dp[i+1][i+1] = min(dp[i+1][i+1], dp[i][j] + s[j][i+1])

    ans = +infinity
    for j = 1 to n:
        ans = min(ans, dp[n][j])
    return ans
```

**复杂度分析：**

外层 $i$ 从 $1$ 到 $n-1$，内层 $j$ 从 $1$ 到 $i$，总迭代次数为 $\sum_{i=1}^{n-1} i = \Theta(n^2)$，每次 $O(1)$。故时间复杂度 $\Theta(n^2)$，空间复杂度 $\Theta(n^2)$（可用滚动数组降到 $\Theta(n)$）。

> 说明：题目要求 $O(n^2)$，上述 $\Theta(n^2)$ 满足；之所以不需要更高维，是因为“顺序约束”天然地把状态限制在 $i \times j$ 的三角区域。
