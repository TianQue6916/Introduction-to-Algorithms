## Problem 2. Exact Edges（恰含 k 条边）〔16 分〕

### 题目

给定一个带权有向图 $G=(V,E,w)$（边权可正可负），以及一个特定顶点 $v\in V$。请描述一个 $O(k|E|)$ 时间的算法，返回**包含顶点 $v$ 且恰好含 $k$ 条边**的任意环（cycle）的最小权重；若不存在这样的环则返回「不存在」。注意环可以重复经过顶点/边。

### 思路

关键：把「恰好 $k$ 条边」这一约束编码到图的**分层结构（layered graph）**中，使路径长度与层数一一对应，从而把「找环」转化为「DAG 上的最短路」。

### 解答

**Step 1（剪枝）**：假设 $G$ 中所有顶点都从 $v$ 可达，从而 $|V|=O(|E|)$；否则先用 BFS 或 DFS 做单源可达性（single source reachability），把 $G$ 替换为从 $v$ 可达的子图，耗时 $O(|E|)$。

**Step 2（构造分层图 $G'=(V',E')$）**：

- 对每个顶点 $v\in V$，建立 $k+1$ 个副本 $v_i$，$i\in\{0,\dots,k\}$；
- 对每条边 $(u,v)\in E$，建立 $k$ 条边 $(u_{i-1}, v_i)$，$i\in\{1,\dots,k\}$。

$G'$ 有 $(k+1)|V|=O(k|E|)$ 个顶点、$k|E|$ 条边，分为 $k+1$ 层。其核心性质是：

> 从 $v_0$ 到 $v_k$ 的路径，与「$G$ 中经过 $v$、恰好含 $k$ 条边、且权重相同」的环，存在一一对应（one-to-one correspondence）。因为每上升一层恰好走一条边。

**Step 3（求最短路）**：在 $G'$ 中从 $v_0$ 求到 $v_k$ 的最短路（SSSP）。由于 $G'$ 的边始终是「下标递增」，$G'$ 是一个 DAG（有向无环图），可用 DAG relaxation（DAG 松弛）在线性时间内求出 SSSP。

**总复杂度**：剪枝 $O(|E|)$ + 构造 $O(k|E|)$ + DAG 最短路 $O(k|E|)$，合计 $O(k|E|)$。

### 伪代码

```text
EXACT-K-CYCLE(G, w, v, k):
    1  prune:  compute vertices reachable from v via BFS/DFS
               restrict G to that subgraph              # 保证 |V| = O(|E|)
    2  build G': V' = { u_i : u in V, i in 0..k }
                 E' = { (u_{i-1}, v_i) : (u,v) in E, i in 1..k }
                 weight(u_{i-1}, v_i) = w(u, v)
    3  D = DAG-SHORTEST-PATHS(G', source = v_0)        # 按拓扑序松弛
    4  if D[v_k] < infinity:
           return D[v_k]                               # 即最小权环
       else:
           return "no such cycle"
```

### 复杂度分析

- 构造 $G'$：$|V'|=(k+1)|V|$，$|E'|=k|E|$，线性于 $k|E|$。
- DAG 上 SSSP 通过**拓扑排序 + 松弛**，每个顶点与每条边处理一次，时间 $O(|V'|+|E'|)=O(k|E|)$。
- 故总时间 $O(k|E|)$。这里 $k$ 是参数（不是变量规模），作为乘数因子保留。

### 常见错误（Common Mistakes）

- 用 BFS 检测有向图环（应改用 DFS）；
- 尝试枚举所有长度 $k$ 的路径/环（可能指数级）；
- 用 Bellman-Ford 但未去除零权边（可能走少于 $k$ 条边）；
- 误用 $k-1$ 条边而非 $k$ 条边找环；
- 误以为要「找负权环」（理解错题目）；
- 未做可达性剪枝。

## Problem 3. Color Cost（换色代价）〔18 分〕

### 题目

一个图的 **3-color labeling（三色标注）** 把每条边映射为 red / green / blue 三色之一。一条被三色标注的路径的 **color cost（换色代价）** = 路径权重之和 + 每当路径「换色」一次就额外加一个正整数 $w_c$。

例如：顶点 $\{a,b,c,d\}$，蓝色边 $(a,b)$ 权 $w_1$、红色边 $(b,c)$ 权 $w_2$、蓝色边 $(c,d)$ 权 $w_3$，则路径 $(a,b,c,d)$ 的 color cost 为 $w_1+w_2+w_3+2w_c$（换色两次）。

给定一个连通、带权、无向图 $G=(V,E,w)$（仅含正权边）的三色标注 $c:E\to\{\text{red},\text{green},\text{blue}\}$，以及两个顶点 $s,t\in V$，请描述一个高效算法，返回 $s$ 到 $t$ 之间 color cost 最小的路径。越快正确得分越高。

### 思路

「换色」这一代价发生在**顶点处**（前后两条边颜色不同）。把每个顶点拆成 3 个副本（分别代表「经红/绿/蓝边到达该顶点」），副本之间加一条权 $w_c$ 的边来「支付换色代价」，于是问题转化为普通的最短路。

### 解答

**构造新图 $G'=(V',E')$**：

- **顶点复制（vertex 副本）**：每个 $v\in V$ 建 3 个顶点 $v_i$，$i\in\{\text{red},\text{green},\text{blue}\}$，表示「经由颜色 $i$ 的边到达 $v$」。
- **vertex-edges（顶点内换色边）**：每个 $v\in V$ 建 3 条无向边 $\{v_{\text{red}},v_{\text{blue}}\},\{v_{\text{green}},v_{\text{red}}\},\{v_{\text{blue}},v_{\text{green}}\}$，权均为 $w_c$。走这条边即支付一次「换色」代价。
- **edge-edges（原边）**：对每条无向边 $\{u,v\}\in E$（权 $w$、色 $c(u,v)$），建无向边 $\{u_{c(u,v)},\,v_{c(u,v)}\}$，权 $w$。

$G'$ 有 $3|V|$ 个顶点、$3|V|+|E|$ 条边。核心性质：

> $G'$ 中从任意 $s_i$ 到任意 $t_j$（$i,j\in\{\text{red},\text{green},\text{blue}\}$）的最小权重路径，等于 $G$ 中 $s$ 到 $t$ 的最小 color cost 路径。因为在顶点处换色，恰好等价于走一条权 $w_c$ 的 vertex-edge。

**求解**：分别从三个 $s_i$ 出发跑 3 次 Dijkstra（因 $G'$ 边权全正），取到任一 $t_j$ 的最小值；再按 lecture 中的 parent pointer 回溯出实际路径。

**复杂度**：Dijkstra 一次 $O(|E'|+|V'|\log|V'|)$，3 次仍是 $O(|V|+|E|+|V|\log|V|)$。

> 注：可用一个 supernode（超级源点）避免跑 3 次 Dijkstra，但只省常数因子；也可不加 vertex-edge、改为对每条边按颜色加 3 条「定向到同色副本」的边，但那样边需定向。

### 伪代码

```text
MIN-COLOR-COST(G, w, c, w_c, s, t):
    1  build G' as described:
           V' = { v_red, v_green, v_blue : v in V }
           E' = vertex-edges {v_a, v_b} of weight w_c (3 per vertex)
                ∪ edge-edges {u_c, v_c} of weight w    (1 per edge)
    2  best = infinity
    3  for each color i in {red, green, blue}:
           dist = DIJKSTRA(G', source = s_i)
           for each color j in {red, green, blue}:
               best = min(best, dist[t_j])
    4  reconstruct path via parent pointers
    5  return best
```

### 复杂度分析

$|V'|=3|V|$，$|E'|=3|V|+|E|$。Dijkstra（二叉堆实现）复杂度 $O(|E'|+|V'|\log|V'|)$，跑 3 次为常数倍，故总复杂度 $O(|V|+|E|+|V|\log|V|)$。

### 常见错误

- 试图修改 Dijkstra 去「记录状态」（应通过图变换处理）；
- 找不到（或找错）SSSP 的源点；
- 复制图中边的定向或加权错误。

## Problem 4. Orkscapade（奥克大冒险）〔18 分〕

### 题目

游侠 Raargorn 需把信从家乡 Tina's Mirth 送到 Riverdell，但 Midgard 的城镇已被一支 $k$ 个 Orks（兽人）的军队侵占。她有一张含 $n$ 个城镇、$3n$ 条道路的地图，每条道路双向连通一对城镇。侦察兵已确定每个城镇 $i$ 驻扎的兽人数 $r_i\ge 1$（每个城镇至少 1 个兽人）。请描述一个 $O(k)$ 时间的算法，找一条从 Tina's Mirth 到 Riverdell 的路径，使沿途**在城镇中遇到的兽人总数**最少。

正确但更慢的算法（如 $O(k\log k)$、$O(nk)$）可获部分分。

### 思路

本题是「点权最短路」（vertex-weighted shortest path）。把每个城镇的 $r_v$ 个兽人「展开」成一条长为 $r_v$ 的链，经过该城镇就必须走完这条链，从而把点权转化为边数（无权的 hop count），再用 BFS。

### 解答

**构造图 $G=(V,E)$**：

- **城镇链**：对每个城镇 $v$，建一条含 $r_v$ 个顶点的链 $(v_1,\dots,v_{r_v})$，用 $r_v-1$ 条无权有向边 $(v_i,v_{i+1})$（$i\in\{1,\dots,r_v-1\}$）连接；
- **道路边**：对每条连接城镇 $u,v$ 的道路，建两条无权有向边 $(u_{r_u},v_1)$ 和 $(v_{r_v},u_1)$。

图 $G$ 有 $\sum_v r_v = k$ 个顶点，$2(3n)+\sum_v(r_v-1)=6n+(k-n)=5n+k$ 条边。因每镇至少 1 兽人，$k\ge n$，故 $G$ 规模为 $O(k)$。

核心性质：

> 从 $s_1$（Tina's Mirth 对应链的起点）到 $t_{r_t}$（Riverdell 对应链的终点）的任意路径，与「从 Tina's Mirth 到 Riverdell 的真实路径」对应，且走过边的数目等于沿途在城镇中遇到的兽人总数。因为沿任一道路从 $u_1$ 到 $v_1$，必须先走完 $v$ 的 $r_v$ 条链边。

**求解**：在 $G$ 上用 BFS 求从 $s_1$ 到 $t_{r_t}$ 的无权 SSSP，$O(k)$ 时间；再沿 parent pointers 回溯出实际经过的城镇序列。

### 伪代码

```text
MIN-ORKS(G, r, s_town, t_town):
    1  build G':
           for each town v:  chain v_1 -> v_2 -> ... -> v_{r_v}
           for each road (u,v): add edges (u_{r_u} -> v_1), (v_{r_v} -> u_1)
    2  dist, parent = BFS(G', source = s_1)          # 无权 BFS
    3  if dist[t_{r_t}] == infinity: return "unreachable"
    4  reconstruct town sequence by parent pointers
    5  return path
```

### 复杂度分析

$|V'|=\sum_v r_v = k$，$|E'|=6n+(k-n)=5n+k=O(k)$（因 $k\ge n$）。无权图 BFS 时间 $O(|V'|+|E'|)=O(k)$。故总复杂度 $O(k)$。

### 常见错误

- 未把点权定向、或图定义不清；
- 把权展开到所有边上，导致 $O(nk)$ 的膨胀（如一个 $\Theta(k)$ 兽人的镇可能连接 $\Theta(n)$ 条路）；
- 用未修改的 Dijkstra（只能得 $O(k\log k)$）；
- 点权展开错误（链长写成 $r_i$ 而非 $r_i-1$）；
- 在 BFS/DFS 树上找最短路（树上不一定含最短路）。

## Problem 5. Count Cycles（计数负环）〔18 分〕

### 题目

一个 **cycle-sparse graph（环稀疏图）** 是任意带权有向简单图 $G=(V,E,w)$，满足：每个顶点 $v\in V$ 至多从一个简单（simple）负权环可达。（简单环 = 不重复访问任何顶点的环。）

给定一个 cycle-sparse graph，请描述一个 $O(|V|^3)$ 时间的算法，返回 $G$ 中负权环的**数量**。

### 思路

第一步用 Bellman-Ford 找出「所有可达自某个负环的顶点」；第二步利用「每个顶点至多从一个简单负环可达」这一稀疏性，把「负环」与「这些顶点的连通分量」一一对应，从而用连通分量计数代替负环计数。

### 解答

**Step 1（超级源点 + Bellman-Ford）**：构造 $G'$，在 $G$ 上加一个 supernode $x$，并对每个 $v\in V$ 加零权有向边 $(x,v)$。从 $x$ 在 $G'$ 上跑 Bellman-Ford，给每个 $v\in V$ 标上最短路距离 $\delta(x,v)$。

对每个 $v$，$\delta(x,v)=-\infty$ 当且仅当 $v$ 可从某个负权环到达（加 $x$ 不会新增或删除任何环）。

**Step 2（同环判定）**：对任意有向边 $(u,v)$，若 $\delta(x,u)=\delta(x,v)=-\infty$，则 $u,v$ 各自都从**同一个**简单负环可达（因为 $v$ 从 $u$ 可达，且每个顶点至多从一个简单负环可达）。

**Step 3（构连通图并计数）**：在「$\delta(x,v)=-\infty$」的顶点集上构造无向图 $G''$：若 $u,v$ 在 $G$ 中共享一条有向边，则在 $G''$ 中连一条无向边。

核心性质：

> $G''$ 中连通分量（connected component）的个数 = $G$ 中负权环的个数。

用 Full-BFS 或 Full-DFS 数出 $G''$ 的连通分量数并返回。

### 伪代码

```text
COUNT-NEG-CYCLES(G, w):
    1  build G' = G + supernode x with zero-weight edges (x, v) for all v
    2  dist = BELLMAN-FORD(G', source = x)          # 标记 delta(x, v)
    3  S = { v in V : dist[v] == -infinity }        # 可达负环的顶点
    4  build undirected G'' on vertices S:
           edge {u, v} if (u,v) in E or (v,u) in E
    5  return NUMBER-OF-CONNECTED-COMPONENTS(G'')   # Full-BFS / Full-DFS
```

### 复杂度分析

- 构造 $G'$：$O(|V|+|E|)$；
- Bellman-Ford：$O(|V||E|)$（$|V|-1$ 轮，每轮松弛 $|E|$ 条边）；
- 构造 $G''$：$O(|V|+|E|)$；
- 数连通分量：$O(|V|+|E|)$。

故总复杂度 $O(|V||E|)=O(|V|^3)$（因为 $|E|=O(|V|^2)$，在最坏意义下取上界）。

### 常见错误

- 算法描述笼统、缺乏精度；
- 尝试枚举所有路径/环（可能指数级）；
- 反复运行 Bellman-Ford，得到 $|V|\cdot O(|V||E|)=O(|V|^4)$；
- 误称 $|E|=O(|V|)$（一般有向图无此界）；
- 混淆连通分量与强连通分量（strongly connected component）。

## Problem 6. Bellham's Fjord（贝尔汉的峡湾）〔18 分〕

### 题目

Gralexandra Bellham 要开着电动车从 Oslo 的 $s$ 到峡湾 $t$。她有挪威 $n$ 个地点及连接它们的 $O(n)$ 条单行道（one-way roads）的地图。

- 每个地点 $x$ 标有（可正可负的）整数海拔 $h(x)$（above sea-level）。
- 车有再生制动（regenerative braking），下坡能发电。每条从 $x$ 到 $y$ 的路标有整数能量 $J(x,y)$：正为消耗、负为产生。
- 物理定律保证 $J(x,y)$ 恒大于 $x,y$ 间势能差，即 $J(x,y) > m\cdot g\cdot(h(y)-h(x))$，其中 $m,g$ 分别为车质量与重力加速度。

电池容量 $b>2nk$，$k=\max|J(x,y)|$。假设她从 $s$ 出发时电量为 $\lfloor b/2\rfloor$（half capacity），请描述一个 $O(n\log n)$ 时间算法，确定到达 $t$ 时电池**最多**能有多少能量。

更慢的正确算法（如 $O(n^2)$）可获部分分。

### 思路

把「最小化总能量消耗」转化为「求最小权路径」，再利用题干给出的**顶点势能（vertex potential）** 做类似 Johnson 算法的 re-weighting（重新赋权），把边权变正后即可用 Dijkstra 在 $O(n\log n)$ 内完成。

### 解答

**Step 1（建模）**：构造图 $G$，每个地点一个顶点，每条路一条有向边 $(u,v)$，权 $J(u,v)$。则 $\lfloor b/2\rfloor$ 减去「$s$ 到 $t$ 最小权路径」的权，即到达 $t$ 时的最大能量——前提是途中既不会耗尽也不会超出电池。

**Step 2（证明最小权路径是 simple path）**：只需证 $G$ 中每个有向环权重为正。考虑环 $(c_0,\dots,c_{k-1},c_k=c_0)$，其权：

```math
\sum_{i=1}^{k} J(c_{i-1}, c_i) > \sum_{i=1}^{k} m\,g\,(h(c_i)-h(c_{i-1})) = m\,g\,(h(c_k)-h(c_0)) = 0
```

（最后一步是望远镜求和 telescoping sum 抵消，$h(c_k)=h(c_0)$。）故每个环权重为正。

**Step 3（有界性）**：任何 simple path 至多走 $n-1$ 条边，其权的绝对值 $\le (n-1)k < b/2$。故 $\lfloor b/2\rfloor$ 减去任意 simple path 的权，恒 $>0$ 且 $\lt b$，即沿 simple path 行驶不会耗尽或超出电池。

**Step 4（重赋权 + Dijkstra）**：直接 Bellman-Ford 需 $O(n^2)$，太慢。利用顶点势能，把 $G$ 改为 $G'$：其余不变，仅把每条边 $(u,v)$ 的权改为

```math
J(u,v) - m\,g\,(h(v)-h(u)) > 0
```

这是正的。此变换保持最短路（shortest paths 不变）：因为任意从 $a$ 到 $b$ 的路径，其权整体都改变同一个量 $m\,g\,(h(b)-h(a))$。于是可在 $G'$ 上跑 Dijkstra，求出 $s$ 到 $t$ 的最小权 $D$，返回：

```math
\lfloor b/2 \rfloor - \big(D - m\,g\,(h(t)-h(s))\big)
```

（把 $G'$ 中算出的距离「回退」到 $G$ 的真实权。）

### 伪代码

```text
MAX-ENERGY(J, h, m, g, b, s, t):
    1  build G:  vertex per location, edge (u,v) weighted J(u,v)
    2  build G': same as G but weight'(u,v) = J(u,v) - m*g*(h(v)-h(u))
                 # 由题意 weight'(u,v) > 0
    3  D = DIJKSTRA(G', source = s)                  # 到 t 的最短距离
    4  real_D = D - m*g*(h(t)-h(s))                  # 回退到原始权
    5  return floor(b/2) - real_D
```

### 复杂度分析

- 构造 $G$：$O(n)$（边数 $O(n)$）；
- 重赋权得 $G'$：$O(n)$；
- Dijkstra（二叉堆）：$O(n\log n)$（$|V|=n$，$|E|=O(n)$）。

故总复杂度 $O(n\log n)$。

### 常见错误（S1 续）

- 直接用 Bellman-Ford，得 $O(n^2)$（可得一半分）；
- 用 Bellman-Ford 去求新权，仍 $O(n^2)$；
- 权重用 $-J$ 而非 $J$（符号错）；
- 按 $b$ 做图复制（低效，$b$ 可能远大于 $n$）。
