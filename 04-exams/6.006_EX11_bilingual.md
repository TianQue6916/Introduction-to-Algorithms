## Problem 3. [17 points] Number Scrabble（数字拼字）

### 题意

Number Scrabble 是一个单人游戏（one-player game），玩一个数组 $T = [t_0,\dots,t_{n-1}]$（$n$ 个正整数）。另有一张列表 $P = \{(p_0, v(p_0)),\dots,(p_{m-1}, v(p_{m-1}))\}$，包含 $m$ 个互不相同的可玩词（playable words），其中每个可玩词 $p_i$ 是一个**长度至多 10** 的非空正整数数组，$v(p_i)$ 是其正整数价值。

目标：找到一个游戏过程（gameplay）$S$ —— 一组互不重叠的 $T$ 的子数组（subarrays，即子串 substrings），每个都是某个可玩词 —— 使总价值 $\sum_{s \in S} v(s)$ 最大。

例：$T=[1,5,2,4,1]$，$P=\{([2],3),([1],1),([5,2],8),([1,2],12),([1,5],2)\}$。则 $S_1=([1,5],[2],[1])$、$S_2=([1],[5,2],[1])$、$S_3=([1],[2],[1])$ 都是合法 gameplay，总价值分别为 6、10、5。注意可玩词 $[1,2]$ 不能出现在任何 gameplay 中，因为 $[1,2]$ 不是 $T$ 的连续子数组。

给定 $T$ 和 $P$，描述一个 $O(n+m)$ 时间的算法，返回总价值最大的 gameplay。

### 解答

**核心思想**：把「在 $T$ 的某个位置 $i$ 结束、匹配到某个可玩词 $p$」视作一次可选的覆盖。这是典型的一维 DP，用 `dp[i]` 表示只考虑前 $i$ 个元素（下标 $0..i-1$）时能获得的最大总价值。

关键观察：每个可玩词长度 $\le 10$，所以对于 $T$ 的每个结束位置，只有**常数（最多 10）种可能**的子串需要检查其是否是可玩词。这样就能在线性时间内完成。

**算法步骤：**

1. **预处理词典为哈希表**：把 $P$ 中每个可玩词映射到其价值。由于词是整数数组，可把数组编码为元组（tuple）作为哈希键，值即 $v(p)$。这一步 $O(m)$ 时间（每个词长度 $\le 10$，编码也是常数时间）。

2. **DP 递推**：定义 `dp[i]`（$i \in \{0,\dots,n\}$）为「只用 $T[0..i-1]$ 这个前缀，能得到的最大总价值」。

   - 递推：对于位置 $i$（表示考虑是否有一个词在 $i-1$ 处结束），枚举所有以 $i-1$ 结尾、长度 $1\dots 10$ 的子数组 $T[i-\ell .. i-1]$，若它在词典中（价值为 $v$），则候选值为 `dp[i-ℓ] + v`；同时始终有「不使用任何在 $i$ 处结束的词」的选项 `dp[i-1]`。

   ```math
   dp[i] = \max\Big(\; dp[i-1],\ \max_{\ell \in [1,10],\ T[i-\ell..i-1]\in P} \big(dp[i-\ell] + v(T[i-\ell..i-1])\big)\;\Big)
   ```

3. **恢复方案（reconstruct）**：为返回实际 gameplay 而非仅总价值，维护 parent 指针 `choice[i]`，记录 `dp[i]` 是来自哪个 `dp[i-ℓ]`（或空），回溯即可得到一组不重叠的词。

**伪代码：**

```text
Build-Partial-Suffix-Dictionary(P):
    dict = empty hash map  // 词数组 -> 价值
    for each (word, val) in P:
        dict[tuple(word)] = val
    return dict

Number-Scrabble(T, P):
    n = len(T)
    dict = Build-Partial-Suffix-Dictionary(P)   // O(m) 时间

    dp[0..n] = array of zeros
    choice[0..n] = array of "none"

    for i = 1 to n:
        // 选项 A：位置 i 处不结束任何词
        dp[i] = dp[i-1]
        choice[i] = none

        // 选项 B：尝试一个在 i-1 处结束、长度 <= 10 的词
        word = empty list
        for ell = 1 to min(10, i):
            word = prepend(T[i - ell], word)   // 从右往左构词
            if word in dict:
                cand = dp[i - ell] + dict[word]
                if cand > dp[i]:
                    dp[i] = cand
                    choice[i] = ell            // 记录词长，用于回溯

    // 回溯得到 gameplay
    S = empty list
    i = n
    while i > 0:
        if choice[i] == none:
            i = i - 1
        else:
            ell = choice[i]
            append word T[i-ell .. i-1] to S
            i = i - ell

    return reverse(S), dp[n]
```

**正确性（Correctness）**：对 $i$ 做归纳。`dp[i]` 覆盖了「只在前 $i$ 个元素上选取互不重叠的词」的所有合法方案：任何最优方案要么在位置 $i$ 处没有词结束（对应 `dp[i-1]` 分支），要么有一个词在 $i-1$ 处结束（对应某个 $\ell$ 分支，其前缀部分由 `dp[i-ℓ]` 的最优值给出，而 `dp[i-ℓ]` 已由归纳假设最优）。因为每个词长度 $\le 10$，枚举 $\ell=1..10$ 已经穷尽了所有可能结束在 $i-1$ 处的词。故 `dp[n]` 即全局最优，回溯得到的 $S$ 合法且总价值等于 `dp[n]`。

**复杂度分析**：

- 构建词典：$O(m)$（每词 $O(\text{len}) = O(10) = O(1)$）。
- DP 主体：外层 $i$ 循环 $n$ 次，内层 $\ell$ 循环至多 10 次，每次查哈希 + 构词 $O(1)$，故 $O(n \cdot 10) = O(n)$。
- 回溯：$O(n)$。

总时间 $O(n + m)$，空间 $O(n + m)$（词典 $O(m)$，DP 数组 $O(n)$）。✅ 满足题目要求的 $O(n+m)$。

> 注：这是**多项式**时间算法（关于 $n$ 和 $m$ 都是线性的），与 Problem 2 的判断一致。

## Problem 4. [19 points] Limited-Unlimited（受限-无限制序列）

### 题意

给定两个整数集合 $A$ 和 $B$。定义「limited-unlimited sequence（受限-无限制序列）」$S$ 为：$S$ 是一个整数序列，每个元素 $s \in S$ 要么出现在 $A$、要么出现在 $B$；且若 $s$ 出现在 $A$，则 $s$ 在 $S$ 中**至多出现一次**（$B$ 中的元素可无限次重复使用）。

给定目标总和 $m$ 以及两个**不相交**集合 $A$、$B$，每个集合恰好含 $n$ 个不同的正整数。描述一个 $O(nm)$ 时间算法，判断是否存在某个 limited-unlimited sequence $S$，使得 $m = \sum_{s \in S} s$。

### 解答

**核心思想**：这是一个带「0/1 约束（$A$ 元素至多用一次）」与「完全背包约束（$B$ 元素可无限用）」混合的**子集和（subset sum）** DP。由于 $A$ 元素每个至多一次、$B$ 元素每个无限次，可合并成一个二维 DP，容量为 $m$，物品数为 $n+n=2n$。

设 $A = \{a_1,\dots,a_n\}$，$B = \{b_1,\dots,b_n\}$。定义布尔 DP：

```math
dp[i][j] = \text{能否用 } \{a_1..a_i\} \text{（每个至多一次）与 } B \text{（可无限次）凑出和 } j
```

不过更简洁的做法是两阶段：先对 $B$ 做完全背包，再对 $A$ 做 0/1 背包，合并判断。但直接用一个二维递推最直观，下面给出单一递推：

对 $i$ 从 $0$ 到 $n$（依次决定是否使用 $a_i$），对 $j$ 从 $0$ 到 $m$：

```math
dp[i][j] = dp[i-1][j] \;\text{（不用 } a_i\text{）} \quad\text{或}\quad (a_i \le j \text{ 且 } dp[i-1][j - a_i]) \;\text{（用 } a_i\text{，至多一次）}
```

同时，$B$ 的完全背包部分需要在每个 $i$ 层都「把 $B$ 的无限使用能力」传递下来。一种等价且清晰的写法是：先只对 $B$ 做完全背包得到 `reachB[j]`（是否能用 $B$ 元素凑出 $j$，每个元素无限次），再对 $A$ 做 0/1 背包，容量维里允许先取 `reachB` 作为「基础可达集」。

**最终递推（两阶段合并视角）**：

1. `base[j]`（$j=0..m$）= 能否用 $B$ 中元素（无限次）凑出 $j$。这是标准完全背包（unbounded knapsack / coin change）：

```math
base[j] = \begin{cases}
\text{true}, & j=0 \\
\bigvee_{b \in B,\ b \le j} base[j-b], & j>0
\end{cases}
```

2. 在 `base` 之上，对 $A$ 做 0/1 背包。设 `f[j]` 为「用 $B$ 无限次 + $A$ 中元素每个至多一次」能否凑出 $j$。初始 `f = base`，然后对每个 $a \in A$ 从大到小更新 `f`：

```math
\text{for each } a \in A:\quad f[j] \mathrel{\lor}= f[j-a],\quad j = m \text{ downto } a
```

最终答案为 `f[m]`。

**伪代码：**

```text
Limited-Unlimited(A, B, m):
    n = |A|
    base[0..m] = array of false
    base[0] = true

    // 阶段 1：B 完全背包（元素可无限次使用）
    for j = 1 to m:
        for b in B:
            if b <= j and base[j - b]:
                base[j] = true
                break

    // 阶段 2：A 0/1 背包（每个元素至多一次）
    f[0..m] = base[0..m]
    for a in A:
        for j = m downto a:
            if f[j - a]:
                f[j] = true

    return f[m]
```

**正确性（Correctness）**：

- 阶段 1：对 $j$ 归纳，`base[j]` 为真当且仅当存在 $B$ 中元素的非负多重组合（每个元素不限次数）和为 $j$。递推把「最后一个使用 $B$ 中哪个元素 $b$」作为分情形，穷尽所有可能，故正确。

- 阶段 2：$f$ 初始为「仅用 $B$」的可达集；对每个 $a \in A$，倒序更新保证 $a$ 至多被使用一次（因为倒序时 `f[j-a]` 用的是**尚未加入本 $a$** 的旧值，避免同一 $a$ 被重复使用）。归纳可得 `f[j]` 为真当且仅当存在 $B$ 无限次 + $A$ 中某子集（每个至多一次）凑出 $j$。

- 因此 `f[m]` 精确刻画了题目所问的 limited-unlimited sequence 存在性。✅

**复杂度分析**：

- 阶段 1：$j$ 循环 $m$ 次，每次内层 $B$ 循环 $n$ 次，$O(nm)$。
- 阶段 2：$A$ 循环 $n$ 次，每次 $j$ 倒序 $O(m)$，$O(nm)$。

总时间 $O(nm) + O(nm) = O(nm)$，空间 $O(m)$（可用滚动数组）。✅ 满足题目要求。

> 注：这是**伪多项式**时间算法——时间关于 $m$（目标和的**数值**）是多项式，但关于输入编码长度 $\log m$ 是指数的。这与 Problem 2 的判断 (b) 一致。

## Problem 5. [19 points] Office Hour Optimization（答疑时段优化）

### 题意

课程 0.660（Algorithms for Introductions）举办线上答疑（online office hours），帮助学生在三个问题 $a,b,c$ 对应的三个分组讨论室（breakout rooms）上。TA 想开发一个「Sort Bot」在答疑开始时把每个学生分配到**恰好一个**房间。假设有 $3n$ 个学生，每个学生 $i$ 对分配到问题 $a,b,c$ 的房间有已知的**非负整数收益**（benefit）$a_i, b_i, c_i$。

描述一个 $O(n^3)$ 时间算法，判断是否能**等额**分配学生到三个房间（即每个房间 $n$ 个学生），同时给每个学生提供**严格正**的帮助（strictly positive help）；若可行，返回任意这类分配中的**最大总收益**（maximum total benefit）。注意：分配不得把一个学生分到其收益为零的房间。

### 解答

**核心思想**：由于每个房间必须恰好 $n$ 个学生、且 $a_i, b_i, c_i$ 都是非负整数，这是一个带两个独立容量维的 DP。设两个容量维分别为「已分给 $a$ 房间的学生数」和「已分给 $b$ 房间的学生数」（第三个房间数由总数 $3n$ 自动确定），即可用三维 DP 完成。

定义子问题：

```math
dp[i][x][y] = \text{在前 } i \text{ 个学生中，将 } x \text{ 个分到房间 } a、y \text{ 个分到房间 } b \text{（其余分到 } c\text{），}\\
\text{且所有被分配的学生都得到严格正收益时，能获得的最大总收益；若不可行则为 } -\infty
```

其中 $i \in \{0,\dots,3n\}$，$x, y \in \{0,\dots,n\}$。

**递推（Relate）**：对第 $i$ 个学生（下标 $i-1$），他有三种去向（分配到 $a$、$b$、$c$），但必须保证对应收益严格为正（$>0$）：

```math
dp[i][x][y] = \max\begin{cases}
dp[i-1][x-1][y] + a_{i}, & \text{if } x>0 \text{ and } a_{i} > 0 \\
dp[i-1][x][y-1] + b_{i}, & \text{if } y>0 \text{ and } b_{i} > 0 \\
dp[i-1][x][y] + c_{i}, & \text{if } c_{i} > 0 \text{（分配到 } c \text{ 房间）}
\end{cases}
```

**基例（Base cases）**：

```math
dp[0][0][0] = 0,\qquad dp[0][x][y] = -\infty \quad (x>0 \text{ 或 } y>0)
```

（前 0 个学生时，只有「未分配任何人」是合法且收益为 0 的状态。）

**原问题（Original problem）**：答案是 $dp[3n][n][n]$ —— 因为分配完所有 $3n$ 个学生，且 $a$ 房间 $n$ 人、$b$ 房间 $n$ 人，则 $c$ 房间必为 $3n - n - n = n$ 人。若 $dp[3n][n][n] = -\infty$，则不可行；否则返回该最大值。

**拓扑序（Topological order）**：子问题 $dp[i][\cdot][\cdot]$ 只依赖 $dp[i-1][\cdot][\cdot]$，即 $i$ 严格递减，因此是无环的（acyclic），可按 $i$ 递增、$x,y$ 任意顺序递推。

**伪代码：**

```text
Office-Hour-Optimization(a[1..3n], b[1..3n], c[1..3n], n):
    NEG = -infinity

    // dp[i][x][y]，规模 (3n+1) x (n+1) x (n+1)
    dp[0][0][0] = 0
    all other dp[0][x][y] = NEG

    for i = 1 to 3n:
        for x = 0 to n:
            for y = 0 to n:
                best = NEG
                // 分到房间 a
                if x > 0 and a[i] > 0:
                    best = max(best, dp[i-1][x-1][y] + a[i])
                // 分到房间 b
                if y > 0 and b[i] > 0:
                    best = max(best, dp[i-1][x][y-1] + b[i])
                // 分到房间 c（此时 c 房间已用 (i-1) - (x+y) 个位置，需保证不超 n）
                cCount = (i-1) - (x + y)
                if c[i] > 0 and cCount < n:
                    best = max(best, dp[i-1][x][y] + c[i])
                dp[i][x][y] = best

    if dp[3n][n][n] == NEG:
        return "impossible"
    else:
        return dp[3n][n][n]
```

> 说明：分配去向 $c$ 时，房间 $c$ 已占用人数 = 前 $i-1$ 个学生中去 $c$ 的人数 = $(i-1) - x - y$；必须 $< n$ 才能再往 $c$ 放人。由于最终目标 `dp[3n][n][n]` 下 $c$ 房间人数自动为 $n$，该剪枝等价于保证所有房间容量不超限。

**正确性（Correctness）**：

对 $i$ 归纳，`dp[i][x][y]` 精确等于「前 $i$ 个学生中，$x$ 人去 $a$、$y$ 人去 $b$（剩余 $(i - x - y)$ 人去 $c$），且每个被分配学生对应房间收益严格为正」的最大总收益。归纳步穷尽了第 $i$ 个学生的三种可能去向，并仅在对应收益 $>0$ 时允许，故「严格正收益」约束被完整保留；容量维 $x,y$ 保证各房间人数恰好。故 `dp[3n][n][n]` 即题目所求最大值，$-\infty$ 表示无可行分配。✅

**复杂度分析**：

- 子问题数量：$O(3n \cdot n \cdot n) = O(n^3)$。
- 每个子问题的非递归工作量（work）：$O(1)$（三种去向各常数时间）。

总时间 $O(n^3)$，空间 $O(n^3)$（可滚动 `dp[i]` 只依赖 `dp[i-1]`，优化为 $O(n^2)$，但题目不要求）。✅ 满足题目要求。

> 注：这是**多项式**时间算法（关于 $n$ 是三次的），与 Problem 2 的判断 (c) 一致。
