## 二、图问题总览 Graph Problems

### 1. 基本能力清单

- **Graph reachability by BFS or DFS in $O(|E|)$ time** —— 用广度优先搜索 BFS（Breadth-First Search，按层逐层向外扩展的图遍历）或深度优先搜索 DFS（Depth-First Search，沿一条路径一直向下直到不能再深入再回溯）在 $O(|E|)$ 时间内判定图的**可达性**（reachability，即从一个顶点能否沿边到达另一顶点）。
- **Graph exploration / connected components via Full-BFS or Full-DFS** —— 通过 Full-BFS / Full-DFS（对未访问顶点不断重启遍历，直到所有顶点都被访问）进行图的遍历与**连通分量**（connected component，图中互相可达的极大顶点子集）的求解。
- **Topological sort / Cycle detection via DFS** —— 通过 DFS 做**拓扑排序**（topological sort，把有向无环图的顶点排成线性序列，使每条边的起点都排在终点之前）与**环检测**（cycle detection，判断图中是否存在回路）。
- **Negative-weight cycle detection via Bellman-Ford** —— 通过 Bellman-Ford 算法检测**负权环**（negative-weight cycle，边权之和为负的回路）。
- **Single Source Shortest Paths (SSSP)** —— **单源最短路径**（SSSP，Single Source Shortest Paths，求从单一源点 $s$ 到其他所有顶点的最短路径）。

### 2. SSSP 算法选择表 Restrictions

原文给出了一个「SSSP 算法选择表」，其中「General Any」一行的 Running Time 碎片被拆散，按数学意义重建如下。表中每一行对应图类型与边权类型下应使用的算法及运行时间：

| 图 Graph | 权 Weights | 算法 Name | 运行时间 $O(\cdot)$ |
|---|---|---|---|
| DAG | Any（任意） | DAG Relaxation（DAG 松弛） | $\lvert V\rvert+\lvert E\rvert$ |
| General（一般） | Unweighted（无权） | BFS | $\lvert V\rvert+\lvert E\rvert$ |
| General（一般） | Non-negative（非负） | Dijkstra | $\lvert V\rvert\log\lvert V\rvert+\lvert E\rvert$ |
| General（一般） | Any（任意） | Bellman-Ford | $\lvert V\rvert\cdot\lvert E\rvert$ |

> 表格原 PDF 中「Dijkstra / Bellman-Ford」两列与两个运行时间碎片被交错打散，此处按「算法—复杂度」的语义对应关系重建：Dijkstra（Dijkstra 算法，用优先队列维护当前最短距离估计，每次取出距离最小的未确定顶点）配合非负权得到 $O(\lvert V\rvert\log\lvert V\rvert+\lvert E\rvert)$；Bellman-Ford（对每条边反复松弛 $\lvert V\rvert-1$ 轮，可处理负权并检测负权环）配合任意权得到 $O(\lvert V\rvert\cdot\lvert E\rvert)$。此对应关系由两个复杂度各自的数学形式唯一确定，无第二种可能。

### 3. 全对最短路径 APSP

**All Pairs Shortest Paths (APSP)** —— **全对最短路径**（APSP，All Pairs Shortest Paths，求图中任意两顶点之间的最短路径）。

- Run a SSSP algorithm $|V|$ times —— 对每个顶点作为源点分别跑一次 SSSP 算法，共 $\lvert V\rvert$ 次。
- Johnson’s solves APSP with negative weights in $O(|V|^2\log|V| + |V||E|)$ —— Johnson 算法（Johnson’s algorithm，先用一次 Bellman-Ford 引入顶点势能函数重标定边权以消除负权，再对每个顶点跑 Dijkstra）在 $O(\lvert V\rvert^2\log\lvert V\rvert+\lvert V\rvert\lvert E\rvert)$ 时间内解决带负权的 APSP。

### 4. 图问题解题策略 Graph Problem Strategies

- Be sure to explicitly describe a graph in terms of problem parameters —— 一定要用问题的参数**显式描述**所构造的图（顶点、边、权各对应问题的什么量）。
- Convert problem into finding a shortest path, cycle, topo. sort., conn. comps., etc. —— 把原问题**转化**为求最短路径、环、拓扑排序、连通分量等经典图问题。
- May help to duplicate graph vertices to encode additional information —— 有时需要**复制顶点**来编码额外信息（例如「当前处于第 $k$ 步」「当前位于某状态」）。
- May help to add auxiliary vertices/edges to graph —— 有时需要在图中**添加辅助顶点/边**（例如虚拟源点、超级汇点）。
- May help to pre-process the graph (e.g., to remove part of the graph) —— 有时需要对图做**预处理**（例如删去图的一部分以简化问题）。

## 三、图问题常见错误 Graph Problem Common Mistakes

- **Define your graphs!** Specify vertices, edges, and weights clearly (and count them!) —— **一定要定义你的图！** 清楚地说明顶点、边、权分别是什么（并且**数清楚它们的数量**）。
  - 例：construct graph $G=(V,E)$ with a vertex for each … and a directed edge $(u,v)$ with weight $w$ for each … —— 例：构造图 $G=(V,E)$，为每一个 … 设一个顶点，为每一个 … 设一条权为 $w$ 的有向边 $(u,v)$。
- **State the problem you are solving**, not just the algorithm you use to solve it —— **说明你在解决的「问题」是什么**，而不只是你使用的算法。
  - 例：solve SSSP from $s$ by running DAG Relaxation … —— 例：通过运行 DAG Relaxation（DAG 松弛，按拓扑序依次松弛顶点出边的过程）来解决从 $s$ 出发的 SSSP。
- **Connect the graph problem you solve back to the original problem** —— 把你解决的图问题**连接回原问题**。
  - 例：the weight of a path from $s$ to $t$ in $G$ corresponds to the sum of tolls paid along a driving route, so a path of minimum weight corresponds to a route minimizing tolls —— 例：$G$ 中从 $s$ 到 $t$ 的路径权值对应行车路线沿途支付的路费之和，因此权值最小的路径就对应路费最少的路线。

### Problem 1. Counting Blobs（数 Blob 个数，S18 Quiz 2）

**题干（逐字译全）：**

An image is a 2D grid of black and white square pixels where each white pixel is contained in a blob. —— 一幅图像是一个由黑色与白色方形像素组成的二维网格，其中每个白色像素都包含在某个 blob 中。

Two white pixels are in the same blob if they share an edge of the grid. —— 若两个白色像素共享网格的一条边（即上下左右相邻），则它们属于同一个 blob。

Black pixels are not contained in blobs. —— 黑色像素不包含在任何 blob 中。

Given an $n\times m$ array representing an image, describe an $O(nm)$-time algorithm to count the number of blobs in the image. —— 给定一个表示图像的 $n\times m$ 数组，请描述一个 $O(nm)$ 时间的算法，统计图像中 blob 的数量。

**（概念）** blob 即「白色像素的连通块」，两白像素通过共享边的相邻关系连通；本问题等价于求二维网格图上由白色像素构成的**connected component（连通分量）**个数。

**解答：**

**（本质 idea）** 把每个像素看作一个顶点，把「共享一条边的两个相邻白色像素」之间连一条无向边，则问题归结为**求这个图上白色像素连通分量的个数**。用一次 Full-DFS / Full-BFS 遍历所有白色像素即可。

**（算法 pseudocode，LaTeX）**

```math
\begin{aligned}
&\text{COUNT-BLOBS}(A, n, m)\\
1.\quad &count \leftarrow 0 \\
2.\quad &visited \leftarrow \text{一个 } n\times m \text{ 的布尔数组，全部初始化为 False} \\
3.\quad &\textbf{for } i \leftarrow 1 \textbf{ to } n \\
4.\quad &\quad \textbf{for } j \leftarrow 1 \textbf{ to } m \\
5.\quad &\quad\quad \textbf{if } A[i][j] = \text{white 且 } visited[i][j] = \text{False} \\
6.\quad &\quad\quad\quad count \leftarrow count + 1 \\
7.\quad &\quad\quad\quad \text{DFS}(A, visited, i, j) \\
8.\quad &\textbf{return } count
\end{aligned}
```

其中 DFS 从 $(i,j)$ 出发，标记该像素为已访问，并递归访问它的四个上下左右相邻且为白色、尚未访问的像素。

**（正确性论证，循环不变式）**

设第 5–7 行的双重循环。**loop invariant（循环不变式）：** 在每一轮外层/内层迭代开始时，`count` 恰好等于「已扫描过的像素范围内，已完整发现的 blob 个数」，且每个已发现 blob 的所有白色像素都已被标记为 visited。

- **初始：** 循环开始前 `count = 0`，没有任何像素被访问，不变式成立。
- **保持：** 当遇到一个白色且未访问的像素 $(i,j)$ 时，它必属于一个尚未被统计的新 blob（因为它未被访问，而 DFS 只会在前几轮标记掉与已发现 blob 相连的像素）。`count` 加 1 后，DFS 会沿边遍历并标记这个 blob 的全部白色像素。由于 DFS 恰好覆盖「与起点共享边可达的全部白色像素」，而共享边可达正是「同一 blob」的定义，故 DFS 恰好标记了这整个 blob，不遗漏也不越界到别的 blob。于是本轮结束后不变式仍成立。
- **终止：** 循环结束于所有 $nm$ 个像素都被扫描完毕，此时每个白色像素都被标记过；每个 blob 恰在其第一次被遇到时使 `count` 加 1，之后该 blob 的像素不会再触发计数（已被标记）。故 `count` 恰为 blob 总数。

**（复杂度分析，写出递推式并求解）**

DFS 对每个像素至多访问一次，每条「相邻白像素对」至多被检查常数次；外层双重循环对 $nm$ 个像素各做常数次判断。总时间为

```math
T(nm) = O(nm) + O(\text{DFS 总遍历量}) = O(nm) + O(nm) = O(nm)
```

（无需主定理：这不是递归分治，而是「每个顶点/每条边常数次」的线性遍历。）空间为 $O(nm)$（visited 数组）。满足题目要求的 $O(nm)$ 时间。

### Problem 2. Unicycles（单环图，S18 Quiz 2）

**题干（逐字译全）：**

Given a connected undirected graph $G=(V,E)$ with strictly positive weights $w:E\to\mathbb{Z}^{+}$ where $|E|=|V|$, describe an $O(|V|)$-time algorithm to determine a path from vertex $s$ to vertex $t$ of minimum weight. —— 给定一个连通的无向图 $G=(V,E)$，边权严格为正 $w:E\to\mathbb{Z}^{+}$，且 $\lvert E\rvert=\lvert V\rvert$。请描述一个 $O(\lvert V\rvert)$ 时间的算法，求出从顶点 $s$ 到顶点 $t$ 的最小权路径。

**（概念）** Unicycle（单环图）：一个连通无向图若满足 $\lvert E\rvert=\lvert V\rvert$，则它恰好含**一个环**（cycle，回边组成的回路），其余部分构成若干棵树挂在这个环上。这是本题结构的关键。

**（本质 idea）** 连通且 $\lvert E\rvert=\lvert V\rvert$ 的无向图必是「单环图」：去掉环上的某条边后即成为一棵树。由于所有边权为正，$s$ 到 $t$ 的最短路径要么完全不走环（走树上的唯一路径），要么绕环走某一段。关键观察是：最短路径绕环时最多用环的「整圈减一条边」，因此可以在线性时间内枚举环上被「跳过的边」。具体地，先找出唯一的环，再在「把环去掉一条边得到的树」上求 $s$–$t$ 路径，并枚举去掉环上哪条边取最小。

**（算法 pseudocode，LaTeX）**

```math
\begin{aligned}
&\text{UNICYCLE-SHORTEST-PATH}(G, s, t)\\
1.\quad &\text{用一次 DFS 找出 } G \text{ 中唯一的环 } C\text{（DFS 树中的回边即环，}\\
&\quad \text{环上顶点构成序列 } v_0, v_1, \ldots, v_{k-1}\text{）} \\
2.\quad &best \leftarrow \infty \\
3.\quad &\textbf{for 环 } C \text{ 上的每条边 } e = (v_i, v_{i+1 \bmod k}) \\
4.\quad &\quad \text{令 } G' \leftarrow G - e\text{（删除边 } e\text{，}G' \text{ 是一棵树）} \\
5.\quad &\quad \text{在树 } G' \text{ 中求 } s\text{--}t \text{ 的唯一简单路径及其权和 } w' \\
6.\quad &\quad best \leftarrow \min(best, \; w') \\
7.\quad &\textbf{return } best
\end{aligned}
```

**（正确性论证）**

先证引理：连通且 $\lvert E\rvert=\lvert V\rvert$ 的图恰含一个环。对一棵树有 $\lvert E\rvert=\lvert V\rvert-1$；在此基础上每多加一条边，环数增加 1（由欧拉公式 $\lvert E\rvert=\lvert V\rvert-1+c$，其中 $c$ 为环数，此处 $\lvert E\rvert=\lvert V\rvert$ 得 $c=1$）。因此恰有一个环，删去该环上任意一条边后 $\lvert E\rvert=\lvert V\rvert-1$ 且仍连通，故成为一棵树。

再证主结论（**归纳/枚举完备性**）：任意一条从 $s$ 到 $t$ 的简单路径（正权图下最短路径必是简单路径）在环 $C$ 上要么不经过环的边，要么经过环上的一条连续弧。若它绕环走，则环上必然**至少有一条边**未被这条路径使用（否则路径会重复经过顶点，形成非简单路径）。反过来，对每一条「未被使用的环边 $e$」，这条路径完全落在 $G-e$（一棵树）中。因此**任意 $s$–$t$ 最短路径必是某个 $G-e$ 中的 $s$–$t$ 树路径**。我们枚举了环上所有边 $e$，故必覆盖到某条被最短路径跳过的边，从而 $best$ 不会错过真正的最短路径；又 $best$ 取的是所有候选中的最小值，故 `best` 恰为最短路径权值。论证成立。

**（复杂度分析，写出递推式并求解）**

- 找环的 DFS：$O(\lvert V\rvert+\lvert E\rvert)=O(\lvert V\rvert)$（因 $\lvert E\rvert=\lvert V\rvert$）。
- 环上边数 $k\le \lvert V\rvert$，共枚举 $k$ 次；每次在树上求 $s$–$t$ 路径需 $O(\lvert V\rvert)$（树中两点路径唯一，一次 DFS/预处理 LCA 即可线性求）。

总时间

```math
T(|V|) = O(|V|) + \sum_{e \in C} O(|V|) = O(|V|) + O(k \cdot |V|) = O(|V|^2)
```

> 注意：上述朴素枚举的复杂度是 $O(\lvert V\rvert^2)$，尚未达到题目要求的 $O(\lvert V\rvert)$。为达到线性，需改进第 3–6 步：不逐边重建树，而是**先对树 $T=G-e_0$（任删环上一条边 $e_0$）预处理**，得到每个顶点到环上「挂载点」的距离，以及环上任意两挂载点沿环两方向走的前缀和。于是 $s$–$t$ 的候选路径只有 $O(1)$ 条：直接走树路径（不绕环），或绕环沿顺时针/逆时针各一种。这样对每个 $s,t$ 只需 $O(1)$ 时间比较，整体为

```math
T(|V|) = O(|V|) + O(|V|) + O(1) = O(|V|)
```

满足题目要求的 $O(\lvert V\rvert)$ 时间。空间 $O(\lvert V\rvert)$。

### Problem 3. Doh!-nut（甜甜圈绕行，S18 Quiz 2）

**题干（逐字译全）：**

Momer has just finished work at the FingSprield power plant at location $p$, and needs to drive to his home at location $h$. —— Momer（荷马·辛普森）刚在位于地点 $p$ 的 FingSprield 发电厂结束工作，需要开车回位于地点 $h$ 的家。

But along the way, if his driving route ever comes within driving distance $k$ of a doughnut shop, he will stop and eat doughnuts, and his wife, Harge, will be angry. —— 但一路上，如果他的行车路线在任一时刻进入某家甜甜圈店的行驶距离 $k$ 以内，他就会停车吃甜甜圈，他的妻子 Harge（玛姬·辛普森）会生气。

Momer knows the layout of FingSprield, which can be modeled as a set of $n$ locations, with two-way roads of known driving distance connecting some pairs of locations (you may assume that no location is incident to more than five roads), as well as the locations of the $d$ doughnut shops in the city. —— Momer 知道 FingSprield 的布局，可建模为 $n$ 个地点的集合，双向道路（two-way roads，即无向边）以已知行驶距离连接某些地点对（可假设每个地点关联的道路不超过 5 条），同时知道城市中 $d$ 家甜甜圈店的位置。

Describe an $O(n\log n)$-time algorithm to find the shortest driving route from the power plant back home that avoids driving within driving distance $k$ of a doughnut shop (or determine no such route exists). —— 请描述一个 $O(n\log n)$ 时间的算法，求出从发电厂回家的最短行驶路线，要求途中**避免**进入任何甜甜圈店的行驶距离 $k$ 以内（或者判定这样的路线不存在）。

**（概念）** 本题是「带障碍约束的最短路径」：障碍是「距任意甜甜圈店的距离 $\le k$ 的地点」，需要先标记出这些危险地点，再在剩余安全地点上求最短路。

**（本质 idea）** 分两步。第一步：从 $d$ 家甜甜圈店同时做一次**多源 Dijkstra**，求出每个地点到最近甜甜圈店的最短距离 $dist(v)$；把 $dist(v)\le k$ 的地点标记为「危险」，其余为「安全」。第二步：在由安全地点及其间的边构成的子图上，从 $p$ 跑一次 Dijkstra 求到 $h$ 的最短路。若 $h$ 不可达（或 $p$、$h$ 本身危险），则无解。

**（算法 pseudocode，LaTeX）**

```math
\begin{aligned}
&\text{AVOID-DONUTS}(G=(V,E,w),\; shops, \; p, \; h, \; k)\\
1.\quad &\text{建立虚拟源点 } s_0\text{，对每个甜甜圈店 } q \in shops \text{ 加零权边 } (s_0, q) \\
2.\quad &\text{以 } s_0 \text{ 为源跑一次 Dijkstra，得到 } dist(v) = \text{距最近店的最短距离} \\
3.\quad &V_{safe} \leftarrow \{\, v \in V \mid dist(v) > k \,\} \\
4.\quad &\textbf{if } p \notin V_{safe} \textbf{ 或 } h \notin V_{safe} \\
5.\quad &\quad \textbf{return } \text{“不存在安全路线”} \\
6.\quad &\text{在由 } V_{safe} \text{ 诱导的子图上，从 } p \text{ 跑一次 Dijkstra 求到 } h \text{ 的最短路} \\
7.\quad &\textbf{return } \text{最短路线及其权值（不可达则返回“不存在”）}
\end{aligned}
```

**（正确性论证，循环不变式）**

第一步的正确性：多源 Dijkstra 与「虚拟源点 $s_0$ 连零权边到所有店」的等价性由 Dijkstra 的**标准循环不变式**保证——任意时刻，已确定集合中顶点的 $dist$ 值是它们到最近甜甜圈店的真实最短距离，且 $dist(v)$ 单调不减地向外扩展。因为所有边权非负（行驶距离），Dijkstra 正确。故第 3 步的 $V_{safe}$ 精确等于「到任意店距离 $>k$」的地点集合，即**安全**地点集合。

第二步的正确性：任何一条满足「途中从不进入店 $k$ 距离以内」的路线，其上的每个顶点都必须满足 $dist(v)>k$，即属于 $V_{safe}$。反过来，任何一条只经过 $V_{safe}$ 中顶点的路线也自动安全。因此「安全路线」与「$V_{safe}$ 诱导子图中 $p$ 到 $h$ 的路径」一一对应。第二步 Dijkstra 在该子图上求出权值最小的路径，即对应最短安全路线。若 $p$ 或 $h$ 不在 $V_{safe}$，则起点/终点本身已不安全，必无解；若 $h$ 在子图中不可达，也无解。论证成立。

**（复杂度分析，写出递推式并求解）**

第一步多源 Dijkstra：边数 $\lvert E\rvert\le 5n/2$（每个顶点度数 $\le 5$，无向图每条边被两顶点共享），顶点数 $n+d\le 2n$。用二叉堆实现：

```math
T_1 = O((|V|+|E|)\log |V|) = O((n + 5n/2)\log n) = O(n \log n)
```

第二步 Dijkstra 同理：

```math
T_2 = O((|V_{safe}|+|E|)\log |V_{safe}|) = O(n \log n)
```

总时间

```math
T(n) = T_1 + T_2 = O(n \log n) + O(n \log n) = O(n \log n)
```

满足题目要求的 $O(n\log n)$。空间 $O(n)$。

### Problem 4. Long Shortest Paths（含至少 $|V|$ 条边的最短路径）

**题干（逐字译全）：**

Given directed graph $G=(V,E)$ having arbitrary edge weights $w:E\to\mathbb{Z}$ and two vertices $s,t\in V$, describe an $O(|V|^3)$-time algorithm to find the minimum weight of any path from $s$ to $t$ containing at least $|V|$ edges. —— 给定有向图 $G=(V,E)$，边权为任意整数 $w:E\to\mathbb{Z}$，以及两个顶点 $s,t\in V$。请描述一个 $O(\lvert V\rvert^3)$ 时间的算法，求出从 $s$ 到 $t$ 的、**包含至少 $\lvert V\rvert$ 条边**的任意路径的最小权值。

**（概念）** 这是**带边数下界约束的最短路径**问题。注意：若路径至少含 $\lvert V\rvert$ 条边，则在 $\lvert V\rvert$ 个顶点上它必有重复顶点，即包含一个环。在**任意整数权**（可负）下，这本质上要求考虑负权环的收益，且须避免正权环带来的无限绕行。

**（本质 idea）** 核心观察：一条含至少 $\lvert V\rvert$ 条边的路径，其边数多出的部分对应「在某处绕了环」。用**动态规划**（dynamic programming，把问题分解为子问题并用子问题最优解递推得到整体最优解）按「边数」分层：定义 $d^{(k)}(v)$ 为从 $s$ 到 $v$ 恰好含 $k$ 条边的最短路径权值，用矩阵/数组递推求出 $d^{(\lvert V\rvert)}(t)$。更进一步，由于我们要的是「至少 $\lvert V\rvert$ 条边」而非「恰好」，需在到达 $\lvert V\rvert$ 条边后，再允许通过若干轮「闭包」松弛捕捉负环带来的进一步下降——这可用 Floyd–Warshall 的思想或「repeated squaring（重复平方）」处理任意整数权。

**（算法 pseudocode，LaTeX）**

采用动态规划（按边数分层 + 闭包）：

```math
\begin{aligned}
&\text{LONG-SHORTEST-PATH}(G, s, t)\\
1.\quad &n \leftarrow |V| \\
2.\quad &\text{初始化 } d^{(0)}(s) \leftarrow 0;\quad d^{(0)}(v) \leftarrow \infty \;(v \neq s) \\
3.\quad &\textbf{for } k \leftarrow 1 \textbf{ to } n \\
4.\quad &\quad \textbf{for } v \in V \\
5.\quad &\quad\quad d^{(k)}(v) \leftarrow \min_{u \in V}\Big( d^{(k-1)}(u) + w(u,v) \Big) \\
6.\quad &\text{// 此时 } d^{(n)}(t) \text{ 是“恰好 } n \text{ 条边”的最短路径权值} \\
7.\quad &\text{// 对“至少 } n \text{ 条边”，再用 Floyd–Warshall 的闭包松弛捕捉负环收益：} \\
8.\quad &\textbf{for } k \leftarrow 1 \textbf{ to } n \\
9.\quad &\quad \textbf{for } i \in V \\
10.\quad &\quad\quad \textbf{for } j \in V \\
11.\quad &\quad\quad\quad dist[i][j] \leftarrow \min\Big( dist[i][j],\; dist[i][k]+dist[k][j] \Big) \\
12.\quad &\textbf{return } d^{(n)}(t) \text{（结合负环判定与松弛后结果）}
\end{aligned}
```

> 更简洁且严谨的做法：把问题归约为「在 $n$ 个顶点上做 $n$ 轮 Bellman-Ford 式松弛」。由于任意含至少 $n$ 条边的 $s$–$t$ 路径在**不存在可达负环**时可去掉正环而不增加权值，其最优值等于「恰好 $n$ 条边」的最短路径；若存在沿路径可达的**负环**，则可无限绕环使权值趋近 $-\infty$，此时答案是 $-\infty$（无有限最短路）。因此正确算法是：(i) 用 $n$ 轮松弛求 $d^{(n)}(\cdot)$；(ii) 用第 $n+1$ 轮检测负环；若存在沿 $s$ 到 $t$ 可达的负环则返回 $-\infty$，否则返回 $d^{(n)}(t)$。上述第 3–5 步的 $n$ 轮 DP 正是「恰好 $n$ 条边」的最短路径（等价于 Bellman-Ford 的第 $n$ 轮）。

**（正确性论证，归纳假设）**

对第 3–5 步的 DP，归纳假设：**对任意 $k$，在完成第 $k$ 轮后，$d^{(k)}(v)$ 等于从 $s$ 到 $v$ 的、恰好含 $k$ 条边的最短路径权值（若不存在则为 $\infty$）。**

- **基例 $k=0$：** $d^{(0)}(s)=0$，其余 $\infty$，正确。
- **归纳步：** 任意恰好含 $k$ 条边的 $s$–$v$ 路径，其最后一条边必为某 $(u,v)$，而前半段是恰好 $k-1$ 条边的 $s$–$u$ 路径。故「恰好 $k$ 条边的最短路径」= $\min_{u}(d^{(k-1)}(u)+w(u,v))$，这正是递推式。由归纳假设 $d^{(k-1)}(u)$ 最优，取最小得 $d^{(k)}(v)$ 最优。归纳成立。

对于「至少 $n$ 条边」与负环的处理：任何含至少 $n$ 条边的简单-非简单路径，若其 $s$–$t$ 可达部分存在负环，则可无限绕环使权值任意小，答案无下界（$-\infty$）；若不存在可达负环，则最短的「至少 $n$ 条边」路径可通过删除正环、且把多余边数压缩到恰好 $n$ 条而不增加权值（每条被删除的环权值 $\ge 0$），故其最优值等于 $d^{(n)}(t)$。这完成了从「恰好 $n$ 条」到「至少 $n$ 条」的正确性衔接。

**（复杂度分析，写出递推式并求解）**

第 3–5 步：$n$ 轮，每轮对每个 $v$ 枚举所有 $u$，即 $O(n)$ 每顶点、$O(n^2)$ 每轮。递推式：

```math
T_1(n) = n \cdot O(n^2) = O(n^3)
```

第 8–11 步（Floyd–Warshall 闭包）同为三重循环 $O(n^3)$。总时间：

```math
T(n) = O(n^3) + O(n^3) = O(n^3) = O(|V|^3)
```

满足题目要求的 $O(\lvert V\rvert^3)$。空间 $O(n^2)$（存 $d^{(k)}$ 的滚动数组或 dist 矩阵）。
